## 1. Executive summary

[저자 보고] 이 연구는 여러 이미지에 흩어진 단서를 차례로 찾아야 하는 검색에서, 언어모델의 추론 능력뿐 아니라 **중간 증거를 제대로 전달하지 못하는 검색 도구 자체가 병목**이라는 문제를 다룬다(p.2, Figure 2). 2609.38743v2  
이를 위해 저자들은 난도를 통제할 수 있는 시각 검색 벤치마크 **VHop**과, 정답 경로 학습·오류 복구 학습·최종 정답 보상 학습을 결합한 검색기 **VHop-Router**를 제안한다(pp.4–7, Figure 3). 2609.38743v2  
기본 설정에서 독립 검색기의 L4 3단계 검색 성공률은 가장 강한 기존 검색 기준선의 **3.7%에서 76.3%**로 높아졌다(p.8, Table 4). 2609.38743v2  

같은 Gemini 3.5 Flash 에이전트의 검색 도구만 교체하면 성공률이 **32.7%에서 85.4%로, 52.7퍼센트포인트 상승**했다(p.8, Table 4). 2609.38743v2  
한 번에 후보 이미지 50장을 반환하는 Qwen3 기준선과 비교해도 더 높은 성공률을 보고하면서, 반환 이미지 수는 약 23배, 대화 이력의 반복 전송까지 포함한 이미지 입력 횟수는 약 35배 줄였다(p.9, Figure 4·Table 6). 2609.38743v2  
다만 학습하지 않은 난도에서의 상당수 결과는 **모델 선택에도 사용된 개발용 데이터**의 점수이므로 독립적인 일반화 성능 추정치로 읽어서는 안 된다(p.20, Appendix D.1). 2609.38743v2  

학습 범위를 넘는 4단계 검색에서는 기본 모델의 정확도가 **1.0%**로 떨어져, 더 긴 검색으로의 일반화는 입증되지 않았다(p.31, Table 16). 2609.38743v2  
사람이 작성한 현실적 질의에서도 기본 에이전트 시스템의 **정답 이미지 발견률은 34.0%지만 최종 답 정확도는 20.0%**이며, 평가는 재렌더링한 이미지와 50개 질의에 한정된다(pp.31–32, Table 17). 2609.38743v2 2609.38743v2  
[해석] 따라서 이 논문의 가장 강한 기여는 **“통제된 시각 검색 환경에서 검색 도구에 순차적 의사결정을 학습시키면 큰 이득을 얻는다”는 실증**이며, 이를 곧바로 **“임의의 실제 이미지 집합에서 일반적으로 작동하는 검색 알고리즘을 학습했다”**는 주장으로 확대할 근거는 부족하다. 2609.38743v2

> **용어 풀이**  
> **에이전트:** 검색 도구를 호출하고 결과를 검토하여 다음 행동이나 최종 답을 결정하는 모델

## 2. 연구의 목적과 필요성

### 2.1 해결하려는 문제: “잘 생각하는 모델”도 전달받지 못한 증거는 활용할 수 없다

**[저자 보고]** 기존 방식에서는 에이전트가 이미지를 보고 중간 단서를 문장으로 표현한 다음, 일반 검색기에 다음 질의를 보냅니다. 여기에는 서로 다른 두 문제가 있습니다.

첫째, 물체의 독특한 무늬나 형태를 정확한 문장으로 표현하기 어렵고, 이미지 설명문이 작은 물체를 누락할 수 있습니다. 둘째, 필요한 이미지가 검색 순위에서 밀리면 에이전트가 그 이미지를 관찰할 기회 자체를 잃습니다. Figure 2에서는 다음 단계에 필요한 이미지가 **39위**로 밀려 상위 5개 결과에 포함되지 않습니다. **근거: p.2, Figure 2.** 2609.38743v2

**[해석]** 두 번째 문제는 단순한 추론 오류와 구분해야 합니다. 에이전트를 더 큰 모델로 바꾸더라도 필요한 증거가 입력에 없으면 해결되지 않을 수 있습니다. 이 논문은 검색과 추론을 모두 에이전트에 맡기기보다, **이미지 연결 관계를 따라가는 부분을 검색기 내부로 옮기는 역할 분담**을 실험합니다. 다만 이 결과는 특정 시각 검색 과제에서의 근거이지, 모든 검색 문제에서 에이전트 개선보다 검색기 개선이 우월하다는 일반 법칙은 아닙니다. **근거: pp.2–3, §2; p.9, Table 5.** 2609.38743v2 2609.38743v2

### 2.2 왜 새로운 벤치마크가 필요한가?

**[저자 보고]** VHop의 문제는 “처음 주어진 물체와 닮은 이미지를 찾기”에 그치지 않습니다. 중간 이미지에서 새로운 물체를 발견하고, 그 물체를 다음 검색의 단서로 삼아야 합니다. 검색 중 그럴듯하지만 정답으로 이어지지 않는 가지를 선택하면 되돌아가야 합니다. **근거: pp.3–4, §3·Figure 3.** 2609.38743v2 2609.38743v2

| 난도 | 추가되는 요구 | 실제로 평가하는 능력 |
|---|---|---|
| L1 | 같은 물체의 재식별 | 시점·장면이 달라도 동일한 물체를 찾기 |
| L2 | 공간 관계 | 같은 물체가 있어도 좌우 관계가 틀린 이미지를 배제하기 |
| L3 | 색상 조건 | 물체 일치와 함께 지시된 색상을 확인하기 |
| L4 | 막다른 가지 | 국소적으로 맞아 보이지만 완성할 수 없는 경로에서 복구하기 |
| L5 | 매우 닮은 다른 물체 | 종류와 색상이 같아도 실제로 다른 개체를 구별하기 |

**표의 근거: p.16, Table 9; p.17, Figure 8.** L6 로고 일치와 L7 인쇄 문자열 일치는 부록에서 추가로 평가합니다. 2609.38743v2 2609.38743v2

> **용어 풀이**  
> **재식별·개체 수준 인식:** “모두 의자”라는 종류를 맞히는 것이 아니라 “바로 그 의자”인지 구분하는 것  
> **막다른 가지(dead end):** 현재 단계의 조건은 만족하지만 끝까지 진행하면 정답에 도달할 수 없는 선택지  
> **디스트랙터(distractor):** 정답과 혼동하도록 넣은 방해 후보

### 2.3 데이터 생성의 장점과 한계

**[저자 보고]** 먼저 물체·색상·공간 관계·정답 경로를 구조화된 기록으로 생성하고, 독립 검증기로 전체 이미지 집합에서 조건을 만족하는 경로를 검사합니다. 정확한 지시문은 정답 경로가 하나인지 확인하고, 모호한 지시문은 가능한 정답을 모두 기록합니다. 이후 이미지를 렌더링하고 물체 정체성·색상·관계가 기록과 일치하는지 점검합니다. **근거: p.4, §3; p.17, Algorithm 2.** 2609.38743v2 2609.38743v2

**[해석]** 이는 정답 라벨의 논리적 일관성을 확보하는 좋은 설계입니다. 그러나 **기록상 정답이 유일하다는 사실과, 실제 픽셀에서 모든 구분이 명확하다는 사실은 다릅니다.** 저자들도 기호 검증기만으로 렌더링 충실도나 모든 설명문 기반 편법을 보증할 수 없다고 명시합니다. **근거: p.18, Appendix B.3–C.** 2609.38743v2

> **용어 풀이**  
> **기호적 검증:** 이미지를 직접 이해하는 대신, “A는 B의 왼쪽에 있다” 같은 구조화된 사실을 검사하는 방식  
> **렌더링 충실도:** 생성된 이미지가 그 구조화된 사실을 실제로 정확히 표현하는 정도

## 4. 제안 방법과 모델 구조: 수식 중심 설명

### 4.1 전체 구조: 에이전트를 바꾸지 않고 검색기를 학습한다

**[저자 보고]** VHop-Router는 **Qwen3-VL-Embedding-2B**를 기반으로 하며, 다음 구성요소를 사용합니다.

- 지시문과 지금까지 유지된 이미지 경로를 읽는 **상태 인코더**.
- 후보 이미지를 각각 벡터로 바꾸는 **행동 인코더**.
- 계속 검색할지, 되돌아갈지, 종료할지 결정하는 **두 개의 게이트**.

두 인코더는 동결된 기반 모델에 서로 다른 LoRA 어댑터를 사용합니다. 부록의 설정은 LoRA rank 32, scaling 32, 마지막 토큰 풀링, 2,048차원 정규화 임베딩입니다. 행동 인코더는 SFT 이후 동결하여 후보 이미지의 임베딩을 재사용합니다. **근거: p.6, §4.2; p.20, Appendix D.2.** 2609.38743v2 2609.38743v2

> **용어 풀이**  
> **인코더:** 입력 이미지·문장을 계산용 표현으로 바꾸는 신경망  
> **LoRA:** 원래 모델의 대부분을 고정하고 작은 추가 행렬만 학습하는 방식  
> **풀링:** 여러 토큰의 정보를 하나의 벡터로 대표시키는 처리

**[해석]** 여기서 “시각 잠재공간에서 검색한다”는 것은 **언어를 전혀 사용하지 않는다**는 뜻이 아닙니다. 최초 텍스트 지시문은 계속 사용하고, 각 단계에서 이미지 경로도 다시 인코딩합니다. 생략하는 것은 **중간 검색마다 에이전트가 새로운 텍스트 질의를 작성하는 과정**입니다. 또한 도구 한 번이 경로를 반환한다는 뜻이지, 전체 과제를 반드시 한 번의 도구 호출로 끝낸다는 뜻도 아닙니다. 기본 에이전트 시스템은 평균 2.1회 도구를 호출합니다. **근거: p.6, §4.2; p.9, Table 6.** 2609.38743v2 2609.38743v2

### 4.2 상태와 행동 — 원문 식 (1)

검색 시점 $t$의 상태는 최초 지시문과 현재 유지 중인 이미지 스택으로 구성됩니다.

$$
\sigma_t=(q_0,q_1,\ldots,q_{d_t}),
\qquad
s_t=E_s(x,\sigma_t),
\qquad
e_a=E_a(a),
\qquad
\|s_t\|_2=\|e_a\|_2=1.
$$

**기호 설명:** $x$는 텍스트 지시문, $q_0$는 시작 이미지, $q_1,\ldots,q_{d_t}$는 되돌리기 후에도 유지된 검색 이미지, $\sigma_t$는 그 순서 있는 목록, $d_t$는 현재 검색 깊이입니다.  
$E_s$와 $E_a$는 각각 상태·행동 인코더이고, $s_t$와 $e_a$는 그 출력 벡터입니다. $a$는 이미지 집합 $\mathcal C$에 속한 후보 이미지이며, $\|\cdot\|_2$는 벡터 길이입니다. **근거: p.6, 식 (1).** 2609.38743v2

행동은 다음 세 종류입니다.

$$
a_t\in
\{\text{Select}(a):a\in\mathcal C\}
\cup
\{\text{Backtrack},\text{Stop}\}.
$$

**기호 설명:** $a_t$는 시점 $t$에서 선택한 행동입니다. Select(a) 는 이미지 $a$를 스택에 추가하고, $\text{Backtrack}$은 마지막 검색 이미지를 제거하며, $\text{Stop}$은 검색을 끝냅니다. 시작 이미지 $q_0$는 제거하지 않습니다. **근거: p.6, §4.2.** 2609.38743v2

> **용어 풀이**  
> **스택:** 마지막에 넣은 항목부터 꺼내는 자료구조로, 여기서는 현재 탐색 경로를 표현  
> **자기회귀적 검색:** 이전에 검색한 결과에 조건을 두고 다음 검색 결과를 순차적으로 결정하는 방식

**구현상 중요한 보충:** 인코더가 읽는 활성 스택과 전체 탐색 기록은 다릅니다. 되돌리기로 제거한 이미지는 이후 인코더 입력에서 빠지지만, 이전 행동 기록은 남습니다. 후보 제외 규칙과 부모 상태의 검색 점수도 별도로 관리됩니다. 따라서 실제 검색 제어 전체를 단일 벡터 하나만의 동작으로 이해하면 부정확합니다. **근거: p.20, Appendix D.1.** 2609.38743v2

### 4.3 다음 이미지 선택 — 원문 식 (2)

```math
z_t(a)=s_t^\top e_a,
\qquad
\pi_\theta^{\text{sel}}(a\mid s_t,\mathcal C_t)
=
\frac{\exp(z_t(a)/\tau)}
{\sum_{a'\in\mathcal C_t}\exp(z_t(a')/\tau)}.
```

**기호 설명:** $z_t(a)$는 현재 상태와 후보 이미지의 유사도입니다. 두 벡터가 단위 길이이므로 내적은 코사인 유사도와 같습니다. $\mathcal C_t$는 부적격 이미지를 제외한 뒤 남긴 상위 $K$개 후보, $\tau$는 선택 확률의 집중도를 조절하는 온도, $\pi_\theta^{\text{sel}}$은 후보 선택 확률, $\theta$는 학습되는 매개변수입니다. $a'$는 분모에서 합산하는 다른 후보를 뜻합니다. **근거: p.6, 식 (2).** 2609.38743v2

> **용어 풀이**  
> **코사인 유사도:** 두 벡터가 얼마나 같은 방향을 가리키는지 측정하는 값  
> **소프트맥스:** 후보 점수들을 합이 1인 확률로 바꾸는 함수  
> **온도:** 작을수록 높은 점수의 후보에 확률을 집중시키는 조절값

**[해석]** 이 설계는 검색기의 질의 표현을 매 단계 갱신한다는 점이 핵심입니다. 그렇다고 후보 누락 문제가 원리적으로 사라지는 것은 아닙니다. 학습·확률적 탐색에는 여전히 상위 $K$개 제한이 있고, 잘못된 표현 때문에 필요한 후보가 낮게 평가될 가능성도 남습니다. **근거: p.6, 식 (2); p.21, Online IL 설정.** 2609.38743v2 2609.38743v2

### 4.4 되돌리기와 종료 — 원문 식 (3)–(4)

```math
p_t^{\text{stop}}
=
\text{sigmoid}
\left(
\frac{g_{\text{stop}}([s_t;c_t])}{\tau_g}
\right),
\qquad
p_t^{\text{bt}}
=
\text{sigmoid}
\left(
\frac{g_{\text{bt}}([s_t;c_t])}{\tau_g}
\right).
```

**기호 설명:** $p_t^{\text{stop}}$과 $p_t^{\text{bt}}$는 종료·되돌리기 확률입니다. $g_{\text{stop}}$과 $g_{\text{bt}}$는 각각 두 층의 MLP이며, $[s_t;c_t]$는 상태 벡터와 검색 통계를 이어 붙인 입력입니다. $\tau_g$는 게이트 온도입니다. $c_t$의 네 항목은 현재 최고 점수, 1·2위 점수 차이, 부모 상태의 최고 점수, 현재와 부모 최고 점수의 차이입니다. **근거: p.6, 식 (3); p.21, Appendix D.3.** 2609.38743v2 2609.38743v2

원문 식 (4)를 읽기 쉬운 경우별 표현으로 다시 쓰면 다음과 같습니다.

$$
\pi_\theta(a_t\mid s_t)=
\begin{cases}
p_t^{\text{stop}},
& a_t=\text{Stop},\\[4pt]
(1-p_t^{\text{stop}})p_t^{\text{bt}},
& a_t=\text{Backtrack},\\[4pt]
(1-p_t^{\text{stop}})
(1-p_t^{\text{bt}})
\pi_\theta^{\text{sel}}(a\mid s_t,\mathcal C_t),
& a_t=\text{Select}(a).
\end{cases}
$$

**기호 설명:** $\pi_\theta$는 세 행동을 합친 전체 정책입니다. 나머지 기호는 위와 같습니다. 평가에서는 확률적으로 행동을 뽑지 않고, 종료 확률이 0.5 이상이면 종료하고, 그렇지 않으면서 되돌리기 확률이 0.5 이상이면 되돌리며, 둘 다 아니면 최고 점수 이미지를 선택합니다. **근거: p.6, 식 (4) 및 평가 규칙.** 2609.38743v2

> **용어 풀이**  
> **게이트:** 어떤 행동을 실행할지 통제하는 작은 결정 모듈  
> **MLP:** 여러 층의 계산을 거쳐 입력 특징을 출력 점수로 바꾸는 기본적인 신경망  
> **정책(policy):** 현재 상태에서 어떤 행동을 선택할지 정하는 규칙 또는 확률분포

### 4.5 1단계 학습: 정답 경로를 따라가는 SFT — 원문 식 (6)

```math
s_{k-1}=E_s(x,(q_0,g_{1:k-1})),
\qquad
\mathcal L_k
=
-\log
\frac{\exp(s_{k-1}^{\top}e_{g_k}/\tau)}
{\sum_{a\in\mathcal C}\exp(s_{k-1}^{\top}e_a/\tau)}.
```

**기호 설명:** $g_{1:H}$는 길이 $H$의 정답 이미지 경로, $k$는 현재 홉, $g_{1:k-1}$은 그 이전의 정답 경로, $g_k$는 다음 정답 이미지입니다. $\mathcal L_k$는 해당 홉의 손실이며, 다른 기호는 앞서 정의한 인코더·유사도·온도입니다. **근거: p.7, 식 (6).** 2609.38743v2

**[저자 보고]** 먼저 상태 인코더만 학습하고, 그다음 행동 인코더도 함께 조정합니다. 두 번째 단계에서는 막다른 가지와 관계 위반 이미지 같은 어려운 오답 후보를 활용합니다. Figure 9는 초기 준비 학습이 없는 경우보다 학습이 안정적인 사례를 보여줍니다. **근거: p.20, Figure 9·D.2.** 2609.38743v2

> **용어 풀이**  
> **SFT:** 정답 예시를 제공해 모델을 미세조정하는 학습  
> **InfoNCE:** 정답의 점수는 높이고 오답 후보의 점수는 낮추도록 하는 대조학습 손실  
> **어려운 오답 후보(hard negative):** 정답과 매우 비슷하거나 일부 조건만 만족해 혼동하기 쉬운 후보

**[해석]** SFT는 올바른 경로에서 다음 이미지를 고르는 데 도움이 되지만, 모델이 실수로 잘못된 경로에 들어간 뒤 무엇을 해야 하는지는 충분히 가르치지 못합니다. 다음 학습 단계가 필요한 이유입니다. **근거: p.7, §4.3.1–4.3.2; p.35, Figure 15.** 2609.38743v2 2609.38743v2

### 4.6 2단계 학습: 잘못 들어간 길에서 복구하는 Online IL — 원문 식 (7), (9)

```math
\ell_t
=
-(1-y_t^{\text{bt}})(1-y_t^{\text{stop}})
\log \pi_\theta^{\text{sel}}(g_t\mid s_t,\mathcal C_t)
+
B_t(y_t^{\text{bt}})
+
S_t(y_t^{\text{stop}}),
```

```math
B_t(y)
=
-w_+y\log p_t^{\text{bt}}
-(1-y)\log(1-p_t^{\text{bt}}),
\qquad
S_t(y)
=
-y\log p_t^{\text{stop}}
-(1-y)\log(1-p_t^{\text{stop}}).
```

**기호 설명:** $\ell_t$는 방문한 상태 하나의 학습 손실입니다. $y_t^{\text{bt}}$와 $y_t^{\text{stop}}$는 정답 행동이 되돌리기·종료인지 나타내는 0 또는 1의 라벨이며, $g_t$는 정답 행동이 이미지 선택일 때의 목표 이미지입니다. $B_t$와 $S_t$는 각 게이트의 이진 분류 손실이고, $w_+=4$는 드물게 등장하는 되돌리기 정답에 더 큰 가중치를 주는 값입니다. **근거: p.7, 식 (7); p.21, 식 (9).** 2609.38743v2 2609.38743v2

**[저자 보고]** 현재 정책으로 새 경로를 수집하되 초기에는 정답 행동을 섞고, 일부러 막다른 가지로 들어가는 경험도 제공합니다. 방문한 상태마다 정답 행동을 붙여 상태 인코더와 게이트를 학습합니다. 정답 다음 이미지가 상위 후보에 없으면 학습 후보에 추가합니다. **근거: pp.20–21, Appendix D.3.** 2609.38743v2

> **용어 풀이**  
> **온라인 모방학습:** 모델이 실제로 방문한 상태에서 전문가의 올바른 행동을 받아 배우는 방식  
> **오라클(oracle):** 이 실험에서는 정답 경로를 알고 올바른 행동을 알려주는 절차  
> **분포 이동:** 학습 중 본 상태와 실제 실행 중 마주치는 상태가 달라지는 현상

**주의:** 저자들은 이 알고리즘을 DAgger라고 부르지 않습니다. 이전 반복에서 모은 데이터를 계속 누적하지 않고 **현재 반복의 상태만** 학습에 사용하므로, DAgger의 이론적 보장을 그대로 적용하지 않는다고 명시합니다. **근거: p.16, Appendix A.** 2609.38743v2

### 4.7 3단계 학습: 최종 정답으로 강화학습 — 원문 식 (11)–(12)

```math
r_g
=
\mathbf 1
\left[
a_{g,T_g}=\text{Stop}
\;\land\;
\text{top}(\sigma_{g,T_g})\in\mathcal A
\right],
\qquad
A_g
=
r_g-\frac{1}{G-1}\sum_{g'\ne g}r_{g'}.
```

**기호 설명:** 같은 질의에 대해 $G$개의 탐색 경로를 생성하며, $g$는 그중 하나를 가리킵니다. $T_g$는 마지막 행동 시점, $r_g$는 성공하면 1인 보상, $\mathbf 1[\cdot]$는 조건이 참일 때 1이 되는 함수입니다. $\mathcal A$는 검증된 허용 정답 집합이고, $\text{top}(\sigma)$는 스택의 마지막 이미지입니다. $A_g$는 다른 경로들의 평균 보상보다 해당 경로가 얼마나 좋은지를 나타내는 이점 값입니다. **근거: p.21, 식 (11)–(12).** 2609.38743v2

> **용어 풀이**  
> **롤아웃(rollout):** 검색 시작부터 종료 또는 예산 소진까지의 행동 기록  
> **RLVR:** 자동으로 정답 여부를 확인할 수 있는 보상을 이용하는 강화학습  
> **RLOO·leave-one-out 기준선:** 현재 경로를 제외한 다른 경로들의 평균을 비교 기준으로 사용하는 방식  
> **이점(advantage):** 같은 질의의 다른 시도보다 이번 시도가 상대적으로 얼마나 좋았는지 나타내는 값

**[해석]** 이 보상은 **마지막 정답만** 검사합니다. 따라서 보상을 받았다는 사실만으로 중간 경로가 모든 물체·색상·공간 관계 조건을 지켰다고 보장할 수는 없습니다. 잘못된 경로를 거쳐 우연히 정답에 도달하는 경우를 보상 정의만으로 배제할 수 없다는 뜻이지, 실제로 그런 편법이 발생했다고 입증되었다는 뜻은 아닙니다. **근거: p.21, 식 (11).** 2609.38743v2

### 4.8 실제 강화학습 목적함수: 일반적인 PPO와의 중요한 차이

저자들은 선택·되돌리기·종료에서 **실제로 선택한 분기의 확률 항만** 사용합니다. 그 확률을 $p_{g,t}$, 경로 수집 당시의 저장된 확률을 $\bar p_{g,t}$라 하면 다음과 같습니다.

$$
\omega_{g,t}=\frac{p_{g,t}}{\bar p_{g,t}},
$$

```math
\mathcal J_{g,t}
=
-w(A_g)
\min
\left[
\omega_{g,t}A_g,\;
\text{clip}
\left(\omega_{g,t},1-\epsilon_{\text{lo}},1+\epsilon_{\text{hi}}\right)A_g
\right],
```

$$
w(A)=
\begin{cases}
1,& A\ge 0,\\
\lambda_{\text{neg}},& A<0,
\end{cases}
$$

```math
\mathcal L_{\text{RL}}
=
\frac{1}{N_{\text{roll}}}
\sum_{g\in\mathcal B}\sum_{t=0}^{T_g}\mathcal J_{g,t}
+
\beta_{\text{beh}}\mathcal K_{\text{beh}}
+
\beta_{\text{ref}}(i)\mathcal K_{\text{ref}}.
```

**기호 설명:** $\omega_{g,t}$는 현재와 수집 당시 확률의 비율이고, $\text{clip}$은 그 비율을 지정된 범위로 제한합니다. $\epsilon_{\text{lo}}$와 $\epsilon_{\text{hi}}$는 아래·위쪽 제한 폭이며, 기준 실행에서는 각각 0.2와 0.3입니다. $\lambda_{\text{neg}}=0.5$는 음의 이점을 갖는 항의 비중입니다. $\mathcal B$는 이점이 0이 아닌 경로들의 집합, $N_{\text{roll}}$은 이점이 0인 경로까지 포함한 전체 경로 수입니다. $\mathcal K_{\text{beh}}$와 $\mathcal K_{\text{ref}}$는 각각 데이터를 수집한 정책과 초기 Online IL 정책에서 지나치게 멀어지는 것을 억제하는 KL 벌점이며, $\beta$들은 그 가중치, $i$는 학습 반복 번호입니다. 학습 필터에서 제외되는 상태는 정책 손실에 기여하지 않습니다. **근거: pp.22–23, 식 (13)–(17)·Table 10.** 2609.38743v2

> **용어 풀이**  
> **PPO식 클리핑:** 한 번의 학습에서 행동 확률이 지나치게 바뀌지 않도록 제한하는 방법  
> **KL 벌점:** 두 확률분포의 차이가 커질 때 부과하는 벌점  
> **분기별 신용 할당:** 최종 성패를 선택·되돌리기·종료의 어떤 결정에 반영할지 정하는 방식

**매우 중요한 제한:** 이미지 선택에서는 전체 행동 확률에 포함된 두 게이트의 거절 확률을, 되돌리기에서는 종료 거절 확률을 정책 손실에서 생략합니다. 저자들은 이 때문에 **전체 정책에 대한 정확한 정책기울기와 비교하면 편향된 대리 목적함수**라고 직접 인정합니다. 이는 방법이 무효라는 뜻은 아니지만, “표준 정책기울기를 그대로 최적화했다”거나 관련 이론적 보장이 그대로 성립한다고 설명하면 부정확합니다. **근거: p.22, Branch-local credit assignment.** 2609.38743v2

### 4.9 탐색 길이에 대한 벌점

$$
\tilde r_g=r_g-\lambda|\rho_g|.
$$

**기호 설명:** $\tilde r_g$는 수정 보상, $\rho_g$는 탐색 경로, $|\rho_g|$는 이미지 선택·되돌리기·종료를 모두 포함한 행동 수, $\lambda$는 행동 하나의 비용입니다. **근거: p.10, §6.1; pp.23–24, 길이 벌점 설정.** 2609.38743v2 2609.38743v2

**[해석]** 약한 벌점은 불필요한 탐색을 줄일 가능성이 있지만, 너무 강하면 정답을 찾기 전에 탐색을 포기하도록 만들 수 있습니다. 논문의 결과는 이 절충을 보여주는 탐색적 근거이며, 일반화 개선이나 동등 정확도를 통계적으로 확립한 결과는 아닙니다. **근거: p.11, Figure 7; p.29, Appendix E.4.** 2609.38743v2 2609.38743v2

## 5. 이론적 주장은 어디까지 성립하는가?

### 5.1 직접 검색의 한계는 조건부 정리다

부록의 직접 검색 상한은 다음 형태입니다.

$$
P(\text{direct top-1 answer is correct})
\le \frac{1}{m+1}.
$$

**기호 설명:** $P$는 정답 확률이며, $m+1$은 질의에 명시된 정답 속성을 공유하는 후보 이미지 수의 하한입니다. 이 상한은 후보들이 검색기가 관찰할 수 있는 정보 아래에서 정답일 가능성이 대칭적이고, 검색기가 **질의와 후보 한 장만** 사용하며, 중간 증거·전체 코퍼스 특징·역할 메타데이터를 사용하지 않는 경우에 적용됩니다. **근거: p.19, Theorem 3 및 선행 가정.** 2609.38743v2

**[해석]** “질의에서 물체 이름을 빼면 어떤 임베딩 검색기도 실패한다”는 무조건적 정리가 아닙니다. 저자들도 이름을 숨기는 것만으로 대칭성 가정이 성립하지는 않는다고 명시합니다. 중간 이미지를 읽거나 전체 집합의 정보를 활용하는 방법에는 이 상한이 그대로 적용되지 않습니다. 2609.38743v2

### 5.2 되돌아갈 예산이 없으면 잘못된 가지 선택이 누적된다

원문의 분기 수 기호를 앞의 스택 깊이와 혼동하지 않도록 $b_j$로 바꾸면 다음과 같습니다.

$$
P(\text{complete }H\text{-hop chain within }H\text{ retrievals})
\le
\prod_{j:b_j>0}\frac{1}{1+b_j}.
$$

**기호 설명:** $H$는 정답 경로 길이이자 허용된 이미지 검색 횟수이고, $b_j$는 분기점 $j$에 있는 잘못된 가지 수입니다. 정답 가지를 현재 정보만으로 구분할 수 없고 잘못된 가지로는 정답 경로를 완성할 수 없다는 조건이 필요합니다. **근거: p.19, Proposition 1.** 2609.38743v2

**[해석]** 이 결과는 복구할 여유가 있는 탐색의 필요성을 설명합니다. 그러나 더 큰 예산을 사용하는 검색, 반환된 집합 어딘가에서 정답만 찾는 평가, 정답 이미지를 직접 추측하는 경우까지 제한하지는 않습니다. 또한 이 정리의 예산은 **이미지 검색 횟수**이고, 실제 Router의 예산은 되돌리기·종료까지 포함한 **행동 수**라는 차이가 있습니다. 2609.38743v2

### 9.2 차별성에 대한 평가

**[해석] 가장 설득력 있는 차별점은 세 요소의 결합입니다.**

**첫째, 검색 단위를 “정답과 비슷한 이미지”에서 “다음 증거로 가는 행동”으로 바꿉니다.** 다단계 검색 자체는 MDR·Q-RAG에 선행하지만, VHop은 새 시각 단서를 찾아가며 선택·복구·종료를 함께 학습합니다. **대상 논문 근거: pp.3, 6–7.** 2609.38743v2 2609.38743v2

**둘째, 생성 모델의 능력 향상과 검색 정책의 능력 향상을 분리해 연구할 수 있습니다.** Search-R1처럼 에이전트를 학습하는 방향과 경쟁시키기만 할 것이 아니라, 두 모듈을 함께 학습했을 때의 추가 이득과 불안정성을 검증할 필요가 있습니다. 이것은 후속 연구 제안이며 이 논문이 직접 검증한 결과는 아닙니다. [arXiv](https://arxiv.org/abs/2503.09516) 2609.38743v2

**셋째, 종료와 답 선택이 새로운 핵심 연구 문제가 됩니다.** 2026년의 *Uncertainty Quantification for Multimodal Retrieval Augmented Generation*은 검색·시각 이해·생성에서 생기는 불확실성을 함께 다루는 LeMUQ를 제안합니다. 이 방향은 Router의 종료 판단과 에이전트의 답 선택을 개선하는 데 참고할 만하지만, 그 방법을 Router에 적용하면 개선된다는 실험은 아직 제시되지 않았습니다. [arXiv](https://arxiv.org/abs/2605.29956)

> **용어 풀이**  
> **불확실성 추정:** 모델이 단순히 자신 있다고 말하는지를 넘어, 실제로 정답일 가능성을 신뢰할 만하게 추정하는 것

**RELER의 발표가 대상 논문 v2보다 뒤라는 점도 구분해야 합니다.** 여기서는 최신 연구 지형을 비교하기 위해 포함했으며, VHop이 RELER에 직접 영향을 주었다거나 반대의 계승 관계가 확인되었다고 주장하지 않습니다. [arXiv](https://arxiv.org/abs/2609.38743v2)

## 11. 결론과 후속 연구 방향

### 11.1 저자들이 제시한 시사점과 계획

**[저자 보고]** 저자들은 시각적 다단계 검색을 검색 도구로 옮기면 에이전트를 미세조정하지 않고도 과제 성공률과 증거 전달 효율을 개선할 수 있다고 결론 내립니다. 동시에 명시적 관계에 의존하는 데이터 생성의 확장성과, 학습한 홉 수를 넘는 일반화가 한계라고 인정합니다. 제시한 후속 계획은 **VHop·VHop-Router의 규모 확대와 실제 데이터 도입**입니다. **근거: p.11, §7.** 2609.38743v2

### 11.2 추가 제안 ①: 더 긴 검색의 일반화를 먼저 분리 검증해야 한다

**[제안]** 가장 우선할 실험은 **홉 수·코퍼스 크기·분기 수를 각각 독립적으로 바꾸는 교차 실험**입니다. 예를 들어 코퍼스 크기를 고정하고 3→4→6홉을 비교한 다음, 홉 수를 고정하고 코퍼스만 키워야 합니다. 현재 4홉 실험이 이 요인들을 함께 바꾼다는 점을 해결하기 위한 설계입니다. **출발 근거: pp.30–31, F.2.** 2609.38743v2

그다음에는 다양한 길이·분기·되돌리기 깊이를 포함하는 학습을 하되, **학습하지 않은 더 긴 길이를 최종 시험으로 남겨야** 합니다. 4홉 데이터를 추가해 4홉 성능을 복구하는 것은 유용하지만, 그것만으로 길이 일반화를 입증하지는 못합니다. 저자들도 4홉 학습으로 성능이 복구되는지는 아직 확인하지 않았다고 밝힙니다. 2609.38743v2

### 11.3 추가 제안 ②: 시각 인식과 검색 제어를 분해해서 개선해야 한다

**[제안]** 로고·문자열·물체 수 증가의 실패를 해결하기 전에 다음 세 조건을 비교하는 것이 좋습니다.

**정확한 다음 단서를 알려주는 조건**, **다음 정답 이미지를 후보에 보장하는 조건**, **정답 도달 시 종료를 보장하는 조건**입니다. 각각 인식·검색 순위·종료 제어의 병목을 분리할 수 있습니다. 이는 논문에서 실패 원인을 분리하지 못한 부분을 직접 겨냥한 진단 실험입니다. **출발 근거: p.30, F.1; p.33, F.4.** 2609.38743v2 2609.38743v2

인식이 병목이라면 전체 이미지 벡터만 사용하는 대신, 물체 영역과 세부 무늬를 함께 비교하는 방법을 검토할 수 있습니다. ILIAS가 배경 혼잡에서 국소 특징의 중요성을 보고했다는 점이 이러한 방향을 뒷받침하지만, VHop에서의 개선량은 별도 실험이 필요합니다. [arXiv](https://arxiv.org/abs/2502.11748)

### 11.4 추가 제안 ③: 모호한 질의·종료·답 선택을 공동 학습해야 한다

**[제안]** 정확한 지시문과 모호한 지시문을 별개의 모델로만 다루기보다, 표현 방식이 달라도 동일한 검색 문제를 가리키는 학습 예시를 함께 사용하는 것이 타당합니다. 복수 정답을 허용하는 경우에는 단일 시연 경로만 강제하기보다 **허용되는 행동·정답 집합을 반영하는 학습**을 비교해야 합니다. Figure 20은 그 필요성을 보여주는 사례입니다. 2609.38743v2

종료 확률이 높다는 사실을 정답 가능성이 높다는 뜻으로 간주해서도 안 됩니다. 종료 판단의 신뢰성을 별도로 검증하고, 정답이 없거나 증거가 부족할 때 보류하는 선택을 추가해야 합니다. 현실적 질의의 **발견률 34–36%와 최종 정확도 20%의 차이**는 이러한 연구의 직접적인 목표가 될 수 있습니다. 2609.38743v2

### 11.5 추가 제안 ④: “정확도–비용–일반화”를 같은 평가 체계에 놓아야 한다

**[제안]** 후속 연구는 최종 정답 정확도, 유효한 전체 경로 비율, 정답 발견률을 함께 보고하고, 동일한 계산·이미지 처리 예산에서 비교해야 합니다. 비용에는 에이전트 토큰뿐 아니라 **상태 인코더 실행, 이미지 인코딩, 인덱스 생성, 지연시간, 실제 전송량**을 포함하는 것이 바람직합니다. 현재 논문이 이미지 등장 횟수와 총비용을 구분하고 있다는 점을 더 발전시키는 방향입니다. **출발 근거: pp.26–28, E.2–E.3.** 2609.38743v2 2609.38743v2

또한 개발셋과 최종 시험셋을 분리하고, 새로운 월드뿐 아니라 여러 학습 시드에서도 반복해야 합니다. 길이 벌점이나 특정 게이트의 효과를 주장할 때는 메모리 제한·후보 수·학습량도 함께 고정해야 합니다. **출발 근거: p.20, D.1; pp.24, 29, 길이 벌점 주의사항.** 2609.38743v2 2609.38743v2 2609.38743v2

### 최종 평가

**[해석] 이 논문은 “추론을 모두 큰 에이전트에 맡기지 말고, 검색 도구에도 과제 수준의 의사결정을 학습시키자”는 방향을 설득력 있게 보여줍니다.** 특히 L4에서의 큰 성능 향상과 이미지 전달량 감소는 후속 연구 가치가 높습니다. 그러나 더 긴 경로, 새로운 연결 규칙, 복잡한 장면, 원본 실제 사진으로의 일반화에는 큰 공백이 남습니다. **근거: pp.8–11, Tables 4–8; pp.31–33, Tables 16–18.** 2609.38743v2 2609.38743v2 2609.38743v2 2609.38743v2

따라서 앞으로의 핵심 질문은 **“76.3%를 조금 더 높일 수 있는가”보다 “학습한 길이·시각 규칙·데이터 생성 방식이 달라져도 같은 검색 원리가 작동하는가”**입니다. 이 질문에 답할 때 VHop-Router가 특정 벤치마크에 잘 맞춘 검색기를 넘어, 범용 시각 검색 정책으로 발전했는지 판단할 수 있습니다.
