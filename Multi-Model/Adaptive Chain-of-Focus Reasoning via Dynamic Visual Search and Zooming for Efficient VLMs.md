# Adaptive Chain-of-Focus Reasoning via Dynamic Visual Search and Zooming for Efficient VLMs

> **참고 자료**: Zhang et al., "Adaptive Chain-of-Focus Reasoning via Dynamic Visual Search and Zooming for Efficient VLMs," arXiv:2505.15436v3, 2025.
> **GitHub**: https://github.com/xtong-zhang/Chain-of-Focus

---

## 1. Executive Summary (10문장 이내)

Vision-Language Models(VLMs)는 이미지 줌인을 통해 시각적 세부 정보를 탐색하는 "think-with-image" 패러다임에서 성과를 거두었으나, 불필요한 줌인으로 인한 과도한 계산 비용과 전역적 이해 저하라는 딜레마가 존재한다.  
이 논문은 VLM이 시각적 단서와 질문에 따라 **필요할 때만** 줌인을 수행하도록 학습시키는 **Adaptive Chain-of-Focus(Adaptive-CoF)** 프레임워크를 제안한다.  
학습은 (1) 시각 탐색 에이전트로 구축한 MM-Adaptive-CoF SFT 데이터셋을 이용한 지도학습(SFT), (2) 적응형 그룹-인식 보상(AGAR)을 활용한 강화학습(RL)의 2단계로 구성된다.  
SFT 데이터셋은 5K 샘플로 구성되며, RL 데이터셋은 10K 샘플로 구성된다.  
베이스 모델은 Qwen2.5-VL-7B이며, LoRA를 활용해 효율적으로 파인튜닝된다.  
V⋆ 벤치마크에서 DeepEyes 대비 줌인 횟수를 75% 감소시키면서도 동등하거나 더 나은 정확도를 달성했다.  
HR-Bench 4K에서는 DeepEyes 대비 시각 토큰 사용량을 약 5.4% 수준으로 줄이고 줌인 횟수를 77.8% 감소시켰다.  
기반 모델 대비 V⋆ Bench에서 18.9%, MME-RealWorld-Lite에서 8.6% 성능 향상을 달성했다.  
Adaptive-CoF는 동일한 피크 성능에 도달하기 위해 기준 모델 대비 약 50% 적은 시각 토큰만을 사용하는 높은 효율성을 보인다.  
이 연구는 정확도와 계산 효율성을 동시에 달성하는 새로운 VLM 패러다임을 제시한다.

### 1-1. 연구의 목적과 필요성

**문제 배경**: OpenAI-o3, DeepEyes, Pixel Reasoner 등 "think-with-image" 모델들은 추론 중 이미지를 능동적으로 줌인하여 세밀한 시각 정보를 획득한다. 그러나 이 접근법은 두 가지 심각한 문제를 내포한다.

> **⚠️ 용어 설명 — "think-with-image" 패러다임**: 모델이 텍스트 추론 중간에 이미지 영역을 동적으로 크롭·줌인하여 새로운 시각적 증거를 획득하고, 이를 추론에 통합하는 방식. 기존의 "이미지를 한 번 보고 텍스트로만 추론"하는 방식과 대조됨.

| 문제 | 설명 |
|------|------|
| **계산 비효율** | 불필요한 줌인으로 과도한 시각 토큰 생성 |
| **전역 이해 손상** | 반복적 줌인으로 긴 컨텍스트에서 전체 맥락 상실 위험 |

**필요성**: 지능적인 VLM은 현재 시각 증거가 충분한지 동적으로 판단하여 **필요한 경우에만** 줌인을 수행해야 한다. 이는 정확도와 효율성의 균형 문제이며, 기존 연구들이 해결하지 못한 핵심 과제이다.

## 2-1. 상세 설명

### 해결하고자 하는 문제

기존 "think-with-image" 모델(DeepEyes, Pixel Reasoner)들은 RL로 **적극적(proactive) 줌인**을 장려하여 불필요한 줌인이 빈번히 발생한다. 이로 인해:
- 과도한 시각 토큰 생성 → 높은 계산 비용
- 긴 컨텍스트에서 전역적 이해 저하
- 단순한 질문에도 줌인을 시도하는 비효율

### 제안하는 방법 및 수식

#### 3.1 문제 정형화 (Eq. 1, p.7)

$$\max \pi_\theta(r_i, o_i | I, q, h_i) $$

**기호 설명**:
- $\pi_\theta$: 파라미터 $\theta$를 갖는 VLM 정책
- $I$: 입력 이미지
- $q$: 입력 쿼리
- $h_i$: $i$번째 스텝까지의 히스토리 $h_i = [r_1, o_1, t_1, \ldots, r_{i-1}, o_{i-1}, t_{i-1}]$
- $r_i$: $i$번째 스텝에서 생성된 키 영역 바운딩 박스 $[[x_1,y_1,x_2,y_2],\ldots]$
- $o_i$: $i$번째 스텝에서의 텍스트 응답 (최종 답변 또는 중간 추론)
- $t_j$: $j$번째 스텝의 시각 임베딩 토큰

> **⚠️ 용어 설명 — 바운딩 박스(Bounding Box)**: 이미지 내 관심 영역을 직사각형으로 표현하는 좌표 집합. $(x_1, y_1)$은 좌상단, $(x_2, y_2)$는 우하단 좌표.

#### SFT 단계 손실 함수 (Eq. 2, p.16)

$$\min_\theta \mathbb{E}_{(I,q,O)\sim\mathbb{D}} \left[ -\sum_{i=1}^{n} \log \pi_\theta\left(r_i, o_i \Big| I, q, \{r_j, o_j, t_j\}_{j=1}^{j=i-1}\right) \right] $$

**기호 설명**:
- $\mathbb{D}$: MM-Adaptive-CoF SFT 데이터셋
- $O = \{r_1, o_1, t_1, \ldots, r_n, t_n\}$: $n$단계 추론 궤적
- 표준 **크로스 엔트로피 손실**로 모델이 일관된 추론 흔적을 생성하도록 학습

> **⚠️ 용어 설명 — 크로스 엔트로피 손실(Cross-Entropy Loss)**: 모델이 예측한 확률 분포와 실제 정답 분포 간의 차이를 측정하는 손실 함수. 분류 문제에서 가장 널리 사용됨. $-\log p(\text{정답})$ 형태로 정답 토큰의 log 확률을 최대화함.

#### RL 단계 — GRPO 목적 함수 (Eq. 3, p.16)

$$\mathcal{J}_{\text{GRPO}}(\theta) = \mathbb{E}_{(I,q)\sim\mathbb{U},\{O_i\}_{i=1}^G \sim \pi_{\text{old}}(\cdot|I,q)} \left[ \frac{1}{G} \sum_{i=1}^{G} \left( \frac{1}{\sum_{t=1}^{|O_i|} \mathbb{1}(O_{i,t})} \sum_{t=1}^{|O_i|} \mathbb{1}(O_{i,t}) \cdot \min\left(p_{i,t}\hat{A}_{i,t},\ \text{clip}(p_{i,t}, 1-\epsilon, 1+\epsilon)\hat{A}_{i,t}\right) \right) \right] - \beta \mathbb{D}_{\text{KL}}[\pi_\theta \| \pi_{\text{ref}}] $$

**기호 설명**:
- $\mathbb{U}$: MM-Adaptive-CoF RL 데이터셋 (10K 샘플)
- $G$: 샘플링된 롤아웃 그룹 크기
- $O_i$: $i$번째 추론 궤적
- $\pi_{\text{old}}$: 업데이트 이전의 구 정책
- $\pi_{\text{ref}}$: 참조 정책 (KL 정규화 기준)
- $p_{i,t} = \frac{\pi_\theta(O_{i,t}|I,q,O_{i, < t})}{\pi_{\text{old}}(O_{i,t}|I,q,O_{i, < t})}$: $t$번째 토큰의 확률 비율
- $\hat{A}_{i,t}$: 어드밴티지 추정값
- $\epsilon$: 클리핑 파라미터
- $\beta$: KL 페널티 가중치
- $\mathbb{D}_{\text{KL}}$: KL 발산 (정책이 참조 정책에서 너무 멀어지는 것을 방지)

> **⚠️ 용어 설명 — GRPO(Group Relative Policy Optimization)**: DeepSeekMath에서 제안된 강화학습 알고리즘. 동일 입력에서 여러 응답을 샘플링하고, 그룹 내 상대적 보상 순위를 기반으로 정책을 업데이트함. 별도의 가치 함수(Critic) 없이 작동하여 PPO 대비 메모리 효율적.

> **⚠️ 용어 설명 — KL 발산(KL Divergence)**: 두 확률 분포 간의 차이를 측정하는 지표. RL에서 정책이 참조 정책에서 너무 크게 벗어나는 것을 방지하는 정규화 항으로 사용.

#### 어드밴티지 추정값 (Eq. 4, p.16)

$$\hat{A}_{i,t} = \frac{r_i - \mu_r}{\sigma_r + \varepsilon} $$

**기호 설명**:
- $r_i$: $i$번째 롤아웃의 보상
- $\mu_r$: 그룹 보상의 평균
- $\sigma_r$: 그룹 보상의 표준편차
- $\varepsilon$: 수치 안정성을 위한 소수 상수

> **⚠️ 용어 설명 — 어드밴티지(Advantage)**: 특정 행동이 평균 대비 얼마나 더 좋은지를 나타내는 값. 그룹 상대적 정규화를 통해 계산하여 각 응답이 그룹 평균보다 얼마나 좋은지 비교함.

#### 인디케이터 함수 (Eq. 5, p.17)

$$\mathbb{1}(O_{i,t}) = \begin{cases} 1, & \text{if } O_{i,t} \text{ is a text reasoning token} \\ 0, & \text{if } O_{i,t} \text{ is a vision token or padding token} \end{cases} $$

**설명**: 정책 그래디언트가 텍스트 추론 토큰에만 적용되도록 하는 마스킹 함수. 시각 토큰이나 패딩은 최적화에서 제외.

> **⚠️ 용어 설명 — 정책 그래디언트(Policy Gradient)**: 강화학습에서 정책을 직접 최적화하는 방법. 높은 보상을 받은 행동의 확률을 높이는 방향으로 파라미터를 업데이트함.

#### 올바름 지표 및 포맷 지표 (Eq. 6, p.17)

$$c_i = \begin{cases} 1, & \text{if the answer is correct} \\ 0, & \text{otherwise} \end{cases}, \quad f_i = \begin{cases} 1, & \text{if the response format is valid} \\ 0, & \text{otherwise} \end{cases} $$

#### 적응형 그룹-인식 보상 AGAR (Eq. 7, p.18)

$$r_i = c_i\left(d_i \cdot 1 + z_i \cdot (1 - \delta \cdot g)\right) + (1 - c_i) \cdot (\gamma \cdot f_i) $$

**기호 설명**:
- $c_i \in \{0,1\}$: 정답 여부 지표
- $d_i = \mathbb{1}_{\{\text{format}(y_i)=\text{direct}\}}$: 직접 답변 전략 지표
- $z_i = \mathbb{1}_{\{\text{format}(y_i)=\text{zoom-in}\}}$: 줌인 전략 지표
- $g$: 그룹 내 정확한 직접 답변이 존재하면 1, 아니면 0
- $\delta = 0.2$: 줌인에 대한 페널티 계수
- $\gamma = 0.1$: 오답이지만 포맷이 유효할 때의 소액 보상

**보상 구조 해석**:
- 정확한 직접 답변: 최대 보상 $r_i = 1$ (가장 효율적)
- 정확한 줌인 답변 (효율적 직접 해법 존재 시): $r_i = 1 - \delta = 0.8$
- 정확한 줌인 답변 (직접 해법 부재 시): $r_i = 1$ (줌인이 필요한 경우)
- 오답이나 유효 포맷: $r_i = \gamma \cdot f_i = 0.1$

#### MITE 효율 지표 (Eq. 8, p.25)

$$\text{MITE} = \frac{\Delta\text{Accuracy}}{\Delta\text{Tokens}} \times 100 $$

**기호 설명**:
- $\Delta\text{Accuracy}$: 기준 모델 대비 정확도 향상
- $\Delta\text{Tokens}$: 기준 모델 대비 추가 시각 토큰 수
- **높을수록** 토큰 비용 대비 성능 향상이 효율적

> **⚠️ 용어 설명 — MITE(Marginal Improvement in Token Efficiency)**: 이 논문이 제안하는 새로운 효율 지표. 추가적인 100개의 시각 토큰당 정확도 향상을 측정하여 계산 비용 대비 성능 효율을 정량화함.

### 모델 구조

```
입력 이미지(I) + 쿼리(q)
        ↓
[ViT 시각 인코더] → 시각 토큰
        ↓
[MLP 프로젝터] → 언어 공간으로 투영
        ↓
[Qwen2.5-7B LLM]
        ↓
    ┌──────────────────┐
    │  충분한 시각 정보?  │
    └──────────────────┘
    YES ↓              NO ↓
  직접 답변          바운딩 박스 생성
                    → 영역 크롭
                    → 2배 확대
                    → 시각 인코더 재처리
                    → 시각 토큰 컨텍스트 추가
                    → 반복 (최대 N스텝)
```

> **⚠️ 용어 설명 — ViT(Vision Transformer)**: 이미지를 패치로 분할하여 Transformer 구조로 처리하는 시각 인코더. "An Image is Worth 16x16 Words" 논문에서 제안됨.

> **⚠️ 용어 설명 — LoRA(Low-Rank Adaptation)**: 대형 모델의 일부 파라미터만 저차원 행렬로 근사하여 효율적으로 파인튜닝하는 기법. 전체 파라미터를 업데이트하지 않아 메모리와 계산 비용을 크게 절감함.

> **⚠️ 용어 설명 — MLP 프로젝터(Multilayer Perceptron Projector)**: 시각 토큰을 언어 모델이 처리할 수 있는 임베딩 공간으로 변환하는 2층 완전연결 신경망.

### 성능 향상

| 벤치마크 | 기반 모델(Qwen2.5-VL-7B) | Adaptive-CoF | 향상 |
|----------|--------------------------|--------------|------|
| V⋆ Bench | 71.2 | 90.1 | **+18.9%** |
| MME-RealWorld-Lite | 42.3 | 50.9 | **+8.6%** |
| POPE (할루시네이션) | 85.9 | 89.3 | **+3.4%** |
| TallyQA | 68.6 | 75.0 | **+6.4%** |
| SpatialScore | 15.2 | 20.6 | **+5.4%** |

> **⚠️ 용어 설명 — 할루시네이션(Hallucination)**: AI 모델이 실제로 존재하지 않는 내용을 마치 사실인 것처럼 생성하는 현상. VLM에서는 이미지에 없는 객체를 있다고 답하는 경우가 대표적.

### 한계점

- **단일 이미지 QA에 한정**: 현재는 한 장의 이미지에 대한 질문-답변 작업만 지원
- **시각 토큰 최적화 미완성**: Pixel Reasoner처럼 min_pixels 파라미터 최적화가 부재
- **데이터셋 편향**: SA_1B 기반 데이터셋으로, 자연 이미지 외 도메인 일반화 불확실
- **소규모 SFT 데이터**: 5K SFT 샘플은 다양성 측면에서 제한적
- **바운딩 박스 정확도**: 잘못된 영역에 줌인 시 오히려 성능 저하 가능

## 4. 저자 보고 결과 vs. 해석 분리

### 4-1. 저자가 직접 보고한 결과

**연구 주제**: VLM의 적응형 시각 탐색 및 줌인을 통한 효율적 멀티모달 추론

**방법 (저자 직접 기술)**:
- 2단계 학습 파이프라인: SFT(5K 데이터) + RL(10K 데이터, AGAR 보상)
- SA_1B에서 4K 해상도로 업스케일한 360개 이미지 기반 데이터 구축
- GPT-4.1-mini 기반 ReAct 프레임워크 시각 탐색 에이전트 활용
- GRPO 알고리즘으로 적응 전략 강화학습

**결과 (저자 직접 보고)**:
- V⋆ Bench: 90.1 (DeepEyes 89.0 대비 +1.1%, 기반 모델 대비 +18.9%)
- HR-Bench 4K: 73.5 (DeepEyes 73.3 대비 +0.2%)
- DeepEyes 대비 줌인 77.8% 감소, 시각 토큰 94.6% 절감 (HR-Bench 4K)
- Qwen2.5-VL-7B 대비 약 50% 적은 토큰으로 동일 피크 성능 달성
- MITE 점수 최대 30.8 (1024px 이상 고해상도)

### 4-2. 리뷰어(필자)의 해석

**긍정적 해석**:
- **효율성 혁신**: 단순 줌인 횟수 감소를 넘어, 토큰 효율성을 새로운 메트릭(MITE)으로 정량화한 점은 VLM 연구 평가 기준을 확장하는 기여임.
- **AGAR의 설계 타당성**: 그룹 내 직접 답변이 가능한 경우에만 줌인에 페널티를 부과하는 구조는 '불필요한 줌인 억제'라는 목표에 정확히 부합함.
- **데이터 구축 방법론**: SA_1B 이미지를 다중 해상도(×224~×4K)로 리사이즈하여 동일 쿼리의 줌인 필요성을 해상도에 따라 동적으로 레이블링한 것은 창의적 데이터 엔지니어링.

**주의가 필요한 해석**:
- V⋆ Bench에서 Adaptive-CoF(90.1) vs DeepEyes(89.0)의 차이는 **+1.1%**로, 이를 "SOTA"로 강조하는 것은 맥락에 따라 과장될 수 있음.
- HR-Bench 8K에서 DeepEyes(69.3) > Adaptive-CoF(67.6)로 **역전**됨 — 저자들이 이를 명시하나 덜 강조함.
- 모든 실험이 Qwen2.5-VL-7B 기반이므로, 다른 기반 모델에서의 일반화 가능성은 미검증.
- MITE 점수가 672px에서 **-5.1**로 음수가 나오는 것은 저자도 명시하지만, 이는 특정 해상도에서 오히려 역효과가 있음을 시사함.

## 6. 문서가 답하지 않는 질문

1. **다른 기반 모델 적용 가능성**: Qwen2.5-VL-7B 외 LLaMA, InternVL 등 다른 기반 모델에서도 동일한 효과가 나타나는가?

2. **줌인 실패 케이스 분석**: 잘못된 영역에 줌인했을 때 모델이 어떻게 회복하는가? 최악의 케이스는 무엇인가?

3. **RL 학습 안정성**: GRPO 학습 과정에서 보상 해킹(reward hacking)이나 정책 붕괴(policy collapse)가 발생하지 않았음을 어떻게 보장하는가?

4. **AGAR 하이퍼파라미터 민감도**: $\delta=0.2$, $\gamma=0.1$ 값이 최적임을 어떻게 결정했는가? 민감도 분석은?

5. **추론 지연(latency)**: 줌인 작업 자체의 지연 시간이 얼마나 되는가? 실시간 응용에 적합한가?

6. **비영어권 언어 일반화**: 데이터가 영어 위주인데, 한국어 등 다른 언어 질문에도 적응 능력이 유지되는가?

7. **바운딩 박스 오류 전파**: 초기 바운딩 박스가 부정확할 경우, 이후 단계에서 어떻게 복구되는가?

8. **비디오/멀티이미지 확장**: 단일 이미지 외 비디오나 다중 이미지에 적용 시 어떤 추가 문제가 발생하는가?

9. **SA_1B 데이터 편향**: 훈련 데이터가 SA_1B에 편중되어 있어 의료 이미지, 위성 이미지 등 특수 도메인에서의 성능은?

10. **RL 데이터 10K의 충분성**: RL 학습에 10K 샘플이 충분한가? 더 많은 데이터로 스케일 업 시 성능은?

## 7. 가장 중요한 그림 5개 해석

### Figure 1 (p.3) — Adaptive-CoF 개요

**설명**: 세 가지 대표 케이스를 통해 적응형 추론을 시각화.
- **케이스 1** (개를 쓰다듬는 사람): 이미지에서 바로 "No one"임을 확인 → 줌인 없이 직접 답변 (효율성 극대화)
- **케이스 2** (병 브랜드): 텍스트가 불명확 → 1회 줌인으로 "Plasticola" 확인
- **케이스 3** (농구 선수 번호): 선수 위치 파악 → 1차 줌인 → 번호 확인 → 2차 줌인 → "8" 확인

**필자 해석**: 이 그림은 Adaptive-CoF의 핵심 아이디어를 직관적으로 보여주며, 질문 복잡도에 따라 0~2회의 줌인이 동적으로 결정됨을 시연함. 특히 불필요한 줌인을 완전히 생략하는 케이스 1이 기존 모델과의 차별점을 명확히 제시함.

---

### Figure 2 (p.7) — Adaptive Chain-of-Focus 아키텍처

**설명**: 2단계(STEP 1, STEP 2) 추론 과정의 토큰 흐름을 시각화. 이미지 토큰(노란색), 텍스트 토큰(파란색), 바운딩 박스 토큰(빨간색), 답변 토큰(주황색)으로 구분.

**필자 해석**: 
- STEP 1에서 "I need to focus on the door..." 텍스트 토큰이 생성된 후, 바운딩 박스 토큰이 생성되고, 해당 영역이 크롭·인코딩되어 시각 토큰으로 추가됨.
- STEP 2에서 축적된 컨텍스트(이전 시각 토큰 포함)를 바탕으로 더 정밀한 영역에 재집중.
- 이 구조는 기존 VLM 아키텍처를 유지하면서 "툴 콜링"만 추가하므로 범용 적용이 용이함.

---

### Figure 7 (p.14) — MM-Adaptive-CoF SFT 데이터셋 통계

**설명**: 세 개의 막대 그래프로 데이터셋 특성 분석.
- **(a) 해상도별 샘플 수**: 224~3840px 전 범위에서 350~939개로 비교적 균형 잡힘
- **(b) 해상도별 줌인 비율**: 224px에서 70.8% → 3840px에서 4.6%로 급감 (해상도 증가에 따른 줌인 필요성 감소를 실증)
- **(c) 추론 턴 분포**: 1턴 샘플 2201개 >> 9턴 샘플 34개 (대부분 단순 케이스, 소수의 복잡 케이스로 현실 분포 반영)

**필자 해석**: 
- 데이터의 해상도별 균형은 모델이 특정 해상도에 편향되지 않도록 하는 좋은 설계임.
- 줌인 비율의 해상도별 감소 패턴이 모델의 적응 전략 학습에 핵심 신호를 제공함.
- 단일 턴 샘플이 압도적으로 많아 다단계 추론 훈련이 부족할 수 있음 (잠재적 한계).

---

### Figure 8 (p.24) — 효율성 및 적응 행동 분석

**설명**: 
- **(a) 해상도별 평균 줌인 횟수**: 224px에서 2.50회 → 2560px에서 0.51회의 단조 감소 곡선
- **(b) 시각 토큰 수 vs. 정확도**: Qwen2.5-VL-7B는 4000개 이상의 토큰에서 피크 ~80% 달성, Adaptive-CoF는 2000개 토큰 수준에서 동일 성능 초과

**필자 해석**: 
- (a)의 단조 감소 패턴은 모델이 해상도 정보를 실제로 활용하여 줌인 결정을 내린다는 증거. 이는 단순히 "항상 줌인하는" 또는 "항상 직접 답변하는" 전략이 아닌, 진정한 적응적 행동임.
- (b)는 파레토 최적 개선(더 적은 비용으로 더 나은 성능)을 직관적으로 보여주는 핵심 그림. 효율성 주장의 가장 강력한 시각적 증거.
- 두 곡선이 교차하는 지점(~500 토큰)에서 Adaptive-CoF의 낮은 정확도는, 줌인 오버헤드가 효과보다 클 때가 있음을 시사함.

### Figure 5 (p.12) — 시각 탐색 에이전트 작동 예시

**설명**: 노트북 스티커의 글자("cc")를 인식하는 과정에서 에이전트가 6단계 반복 추론을 수행하는 전체 워크플로우를 시각화.

**필자 해석**: 
- **Thought → Code → Observation → Verifier** 루프가 GPT-4.1-mini(에이전트), Qwen2.5-VL-7B(도구), Verifier로 구성된 멀티-에이전트 시스템으로 작동함.
- 4단계에서 "C"(오답) → Verifier가 틀렸다고 판단 → bbox 확장 → 6단계에서 "CC"(정답)로 수정되는 **자기 교정(self-correction)** 메커니즘이 핵심.
- 최종 SFT 데이터는 이 복잡한 탐색 과정을 DeepSeek-V3가 간결한 추론 흔적으로 요약한 것임 — 데이터 품질이 SFT 성능에 직결되므로 이 파이프라인의 신뢰성이 중요함.

## 8. 결론 및 후속 연구

### 8-1. 저자가 제시한 시사점 및 후속 연구 계획

**저자 제시 시사점** (p.29):
- SFT + AGAR RL의 두 단계 학습이 정확도와 효율성을 동시에 달성함을 실증
- "적응형 줌인"이 "전략적 줌인 억제"와 "필요시 줌인"을 모두 학습 가능함을 보임
- 단순 이진 보상보다 그룹-인식 보상이 적응 전략 학습에 필수적임을 확인

**저자 제시 후속 연구** (p.29):
- **시각 대화(Visual Dialogue)**: 단일 이미지 QA에서 대화형 설정으로 확장
- **다중 이미지 추론**: 여러 이미지에 걸친 장면 간 추론으로 확장 (참조: Zhang et al. [52])

### 8-1. 모델의 일반화 성능 향상 가능성

**현재 일반화 제약**:
1. **데이터 편향**: SA_1B 기반 데이터는 자연 이미지 위주. 의료(X-ray, MRI), 위성, 문서 이미지 등 특수 도메인에서의 적응 전략 학습이 부족할 수 있음.
2. **단일 기반 모델 의존**: Qwen2.5-VL-7B에 특화된 학습. LoRA 파라미터는 이 모델 아키텍처에 종속적.
3. **해상도 범위 제한**: 224~4K 범위 외 (예: 고배율 현미경 이미지)에서의 적응 행동 미검증.
4. **언어 다양성**: 데이터가 영어 위주이며, 한국어·중국어 질문에 대한 적응 전략이 동일하게 작동하는지 미검증.

**일반화 향상 가능성 방향**:

| 접근법 | 설명 | 기대 효과 |
|--------|------|-----------|
| **도메인 다양화** | 의료, 위성, 문서 등 다양한 도메인의 데이터 추가 | 특수 도메인에서의 줌인 전략 적응 |
| **멀티링구얼 학습** | 다국어 질문-답변 데이터로 SFT 확장 | 언어 독립적 적응 전략 |
| **모델 독립적 설계** | AGAR 보상을 모델 아키텍처와 분리하여 다른 VLM에 적용 | 범용 학습 프레임워크 |
| **자기 지도 확장** | 검증기(verifier) 없이 자기 일관성으로 데이터 레이블링 | 레이블 비용 절감 |
| **메타 학습** | 새로운 도메인에 소수 샘플로 빠르게 적응하는 few-shot 전략 | 데이터 효율성 향상 |

| **DeepEyes** (2025) [57] | RL 기반 적극적 줌인 | 시각 탐색 능동적 장려 | 비교 대상; 줌인 77.8% 감소 가능 |

> **⚠️ 용어 설명 — Chain-of-Thought(CoT)**: 모델이 최종 답변 전에 중간 추론 단계를 명시적으로 생성하는 기법. "Let's think step by step"과 같은 프롬프트로 활성화되며, 복잡한 문제에서 성능 향상.

> **⚠️ 용어 설명 — ReAct 프레임워크**: "Reasoning and Acting"의 약자. 언어 모델이 추론(Thought) → 행동(Action) → 관찰(Observation) 루프를 반복하며 도구를 사용해 문제를 해결하는 에이전트 프레임워크.

### 향후 연구에 미치는 영향 및 고려 사항

**연구에 미치는 영향**:

1. **"적응형 시각 탐색"의 표준화**: Adaptive-CoF는 무조건적 줌인에서 벗어나 "필요할 때만" 줌인하는 패러다임 전환을 이끌 수 있음. MITE 지표는 후속 연구의 표준 효율 측정 기준이 될 가능성.

2. **AGAR 보상 설계 원칙**: 그룹 내 쉬운 해법 존재 여부에 따라 복잡한 전략에 페널티를 부과하는 설계는, 다른 멀티모달 작업(예: 비디오 이해, 3D 추론)에도 적용 가능한 일반 원칙을 제시.

3. **데이터 파이프라인 혁신**: ReAct 에이전트 + 자기교정 + DeepSeek-V3 요약으로 고품질 추론 궤적 데이터를 자동 생성하는 파이프라인은 데이터 수집 비용을 크게 낮출 수 있음.

**후속 연구 시 고려할 점**:

| 고려 사항 | 권장 접근법 |
|-----------|-------------|
| **보상 설계 민감도** | $\delta$, $\gamma$ 하이퍼파라미터에 대한 체계적 민감도 분석 필요 |
| **공정한 베이스라인 비교** | DeepEyes, Pixel Reasoner와 동일 조건(min_pixels, 학습 데이터 규모)에서 재비교 필요 |
| **통계적 유의성** | 여러 시드에 걸친 반복 실험으로 성능 차이의 통계적 유의성 검증 |
| **실용적 지연 시간** | 줌인 작업 자체의 추론 지연을 토큰 절감과 함께 보고하여 실용성 평가 |
| **도메인 외 일반화** | OCR, 의료, 위성 등 특수 도메인에서의 zero-shot/few-shot 성능 평가 |
| **더 큰 모델 스케일** | 7B 외 13B, 34B 등 다양한 파라미터 스케일에서의 적응 전략 효과 검증 |
| **비디오 확장** | 시간적 차원을 포함한 비디오 이해에서 "언제 프레임을 확대할지" 적응 전략 연구 |
| **보상 해킹 방지** | AGAR 보상의 허점을 이용한 정책 붕괴 방지를 위한 추가 안전장치 설계 |
