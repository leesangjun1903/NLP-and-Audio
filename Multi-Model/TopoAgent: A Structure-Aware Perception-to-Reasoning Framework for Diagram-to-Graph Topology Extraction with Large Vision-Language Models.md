# TopoAgent: A Structure-Aware Perception-to-Reasoning Framework for Diagram-to-Graph Topology Extraction with Large Vision-Language Models

---

## 1. Executive Summary (10문장 이내)

TopoAgent는 구조적 다이어그램 이미지에서 그래프 위상(topology)을 자동으로 추출하는 인식-추론(perception-to-reasoning) 프레임워크입니다.  
기존 대형 비전-언어 모델(VLM)은 세밀한 지각 기반(perceptual grounding)과 전역 위상 일관성(topological consistency)을 동시에 달성하지 못한다는 문제를 해결하기 위해 설계되었습니다.  
이 논문은 180개의 인간 검증 다이어그램-그래프 쌍으로 구성된 **TopoBench-180** 벤치마크를 함께 제안합니다.  
TopoAgent는 지각 기반 → 전역 속성 추론 → 정준 노드 목록 구성 → 노드 중심 관계 추론 → 위상 일관성 강제의 5단계 파이프라인으로 구성됩니다.  
실험 결과, Network-style 다이어그램에서 Edge F1 기준 GPT-4o 대비 +4.6pt, Chain-of-Region 대비 +8.8pt, Qwen2.5-VL-72B 대비 +10.6pt의 성능 향상을 달성하였습니다.  
오류 분석에 따르면 에지 누락(missed edge)이 Network-style에서 가장 빈번한 오류 유형(56.0%)으로 나타났습니다.  
단, 멀티스테이지 파이프라인은 단일 추론 대비 약 14배의 API 호출과 11배의 토큰 비용을 수반합니다.  
이 연구는 다이어그램-그래프 위상 추출이라는 새로운 멀티모달 구조 이해 과제를 최초로 체계적으로 정의하고 평가 체계를 확립하였다는 점에서 의의가 있습니다.

### 1-1. 연구의 목적과 필요성

기술 및 과학 다이어그램은 노드(개체)와 연결선(관계)으로 구성된 풍부한 관계 구조를 담고 있으며, 이를 그래프 형태로 추출하면 그래프 기반 추론, 지식 그래프 구성, 과학적 이해 등 다양한 하위 응용에 활용될 수 있습니다.

그러나 기존 VLM은 두 가지 핵심 문제를 동시에 해결하지 못합니다:

1. **정밀 지각 기반(Fine-grained Perceptual Grounding)**: 텍스트 레이블, 기하학적 요소, 얇은 연결선이 복잡하게 얽힌 고밀도 다이어그램에서 세부 요소를 정확히 인식
2. **전역 일관성 추론(Globally Consistent Reasoning)**: 노드-엣지 할당 전반에 걸쳐 위상 일관성을 유지

또한 이 과제를 위한 **전용 벤치마크가 전무**하였으며, 기존 벤치마크(ChartQA, MMMU 등)는 질의응답이나 캡션 생성에 초점을 두어 전체 그래프 추출 평가에 적합하지 않습니다.

> 💡 **용어 설명**
> - **Perceptual Grounding(지각 기반)**: 시각적 입력의 특정 영역을 의미 있는 개념(노드, 엣지 등)과 연결하는 능력
> - **Topological Consistency(위상 일관성)**: 추출된 그래프가 전역적으로 모순 없는 연결 구조를 가지는 성질

### 2-1. 상세 설명

#### 해결하고자 하는 문제

주어진 구조적 다이어그램 이미지 $I$에서 정준(canonical) 위상 그래프 $G = (V, E)$를 추출하는 문제.
여기서:
- $V$: 다이어그램의 노드(개체) 집합
- $E$: 노드 간 엣지(관계) 집합

각 엣지는 방향성 쌍으로 표현됩니다:

$$e = (\text{source}, \text{target}) $$

양방향/무방향 연결의 경우, $(u,v)$와 $(v,u)$ 모두 포함됩니다.

> 💡 **용어 설명**
> - **Canonical Graph(정준 그래프)**: 중복 없이 표준화된 형식으로 표현된 그래프
> - **Directed Edge(방향성 엣지)**: 출발 노드와 도착 노드가 명확히 구분된 연결선

---

#### 제안하는 방법 (수식 포함)

**[Stage I] 전역 도형 속성 추론**

$$A = \{a_{\text{sem}},\ a_{\text{dir}},\ a_{\text{dens}}\} $$

| 기호 | 설명 |
|------|------|
| $a_{\text{sem}}$ | 도형 의미 유형: `web` / `network` / `structural_diagram` |
| $a_{\text{dir}}$ | 링크 방향성: `one_direction` / `bi_direction` |
| $a_{\text{dens}}$ | 링크 밀도: `single_link` / `multi_link` |

> 💡 **용어 설명**
> - **Global Structural Prior(전역 구조 사전)**: 하위 추론 단계에서 편향을 줄이기 위해 먼저 예측하는 고수준 다이어그램 특성

---

**[Stage II] 정준 노드 목록 구성**

$$V = \{v_i\}_{i=1}^{N} $$

여기서 $v_i$는 텍스트 레이블과 시각적 증거로 기반된 의미 있는 다이어그램 개체입니다.

---

**[Stage III] 노드 중심 로컬→글로벌 관계 추론**

각 포커스 노드 $v_i \in V$에 대한 노드-로컬 엣지 집합:

$$E_i = \mathcal{F}_{\text{rel}}(v_i,\ I,\ \mathcal{S},\ A) $$

| 기호 | 설명 |
|------|------|
| $v_i$ | 현재 추론 대상 포커스 노드 |
| $I$ | 입력 다이어그램 이미지 |
| $\mathcal{S}$ | 지각 단계에서 생성된 영역 수준 구조적 요약 집합 $\{s_i\}_{i=1}^{N}$ |
| $A$ | Stage I에서 예측된 전역 도형 속성 |

모든 노드-로컬 예측을 집계하여 초안 엣지 집합 생성:

$$E_{\text{draft}} = \bigcup_{i=1}^{|V|} E_i $$

> 💡 **용어 설명**
> - **Node-centric Decomposition(노드 중심 분해)**: 전체 그래프를 한 번에 예측하는 대신, 각 노드별로 연결 관계를 개별적으로 예측하는 전략. 밀집 다이어그램에서 세밀한 연결을 놓치는 문제를 완화

---

**[Stage IV] 위상 일관성 강제**

$$G^* = \text{SelfCheck}(V,\ E_{\text{draft}},\ A) $$

| 기호 | 설명 |
|------|------|
| $G^*$ | 최종 정준 위상 그래프 |
| $V$ | Stage II에서 구성된 노드 목록 |
| $E_{\text{draft}}$ | Stage III에서 집계된 초안 엣지 집합 |
| $A$ | Stage I에서 예측된 전역 속성 (방향성, 밀도 등) |

강제 사항:
1. **방향성 일관성**: 양방향 연결 시 $(v_i, v_j)$와 $(v_j, v_i)$ 모두 포함
2. **엔드포인트 유효성**: 모든 엣지 끝점은 $V$에 속해야 함
3. **단일 연결 성분**: 최종 그래프는 하나의 연결 성분으로 제약

---

**[지각 단계] OCR 기반 영역 분해**

이미지를 이진 맵으로 변환:

$$X_{\text{bi}} = \text{Otsu}(X_{\text{im}}) $$

전경/배경 연결 성분 추출:

$$X_{\text{fg}} = \text{CC}(X_{\text{bi}}) $$
$$X_{\text{bg}} = \text{CC}(1 - X_{\text{bi}}) $$

전역 영역 맵 생성:

$$X_{\text{region}} = X_{\text{fg}} + X_{\text{bg}} + \mathbb{I}[X_{\text{bg}} > 0] \cdot \text{offset} $$

영역 분할(unstructured split)을 위한 거리 변환 기반 스케일:

$$T = \left\lfloor \frac{\max(\text{DT}(M_i))}{2} \right\rfloor $$

형태학적 열림(opening) 연산을 통한 서브영역 추출:

$$M_{\text{shape}} = \text{Open}(M_i;\ \text{EllipseKernel}(T, T)) $$

| 기호 | 설명 |
|------|------|
| $X_{\text{im}} \in \mathbb{R}^{H \times W \times 3}$ | 입력 다이어그램 이미지 (높이 $H$, 너비 $W$, 3채널 RGB) |
| $\text{Otsu}(\cdot)$ | 오츠 임계값(Otsu thresholding)을 이용한 이진화 함수 |
| $\text{CC}(\cdot)$ | 8-연결성 기반 연결 성분 레이블링 함수 |
| $\mathbb{I}[\cdot]$ | 지시 함수(indicator function) |
| $\text{offset}$ | 레이블 충돌 방지를 위한 오프셋 값 |
| $M_i$ | $i$번째 영역 마스크 |
| $\text{DT}(\cdot)$ | 유클리드 거리 변환(Euclidean Distance Transform) |

> 💡 **용어 설명**
> - **Otsu Thresholding(오츠 임계값)**: 이미지를 전경(foreground)과 배경(background)으로 자동 분리하는 이진화 방법. 클래스 내 분산을 최소화하는 임계값을 자동 결정
> - **Connected Component Labeling(연결 성분 레이블링)**: 픽셀 연결성에 따라 이미지의 연속된 영역을 개별 성분으로 식별하는 알고리즘
> - **Morphological Opening(형태학적 열림)**: 침식(erosion) 후 팽창(dilation)을 적용하여 좁은 연결을 제거하고 분리된 영역을 확보하는 영상처리 기법

---

**[평가 지표] 노드 및 엣지 F1**

노드 정밀도/재현율/F1:

$$P_{\text{node}} = \frac{|V^{\text{pred}} \cap V^{\text{gt}}|}{|V^{\text{pred}}|} $$

$$R_{\text{node}} = \frac{|V^{\text{pred}} \cap V^{\text{gt}}|}{|V^{\text{gt}}|} $$

$$F1_{\text{node}} = \frac{2 P_{\text{node}} R_{\text{node}}}{P_{\text{node}} + R_{\text{node}}} $$

방향성 엣지 정밀도/재현율/F1:

$$P_{\text{edge}} = \frac{|E^{\text{pred}} \cap E^{\text{gt}}|}{|E^{\text{pred}}|} $$

$$R_{\text{edge}} = \frac{|E^{\text{pred}} \cap E^{\text{gt}}|}{|E^{\text{gt}}|} $$

$$F1_{\text{edge}} = \frac{2 P_{\text{edge}} R_{\text{edge}}}{P_{\text{edge}} + R_{\text{edge}}} $$

| 기호 | 설명 |
|------|------|
| $V^{\text{pred}}$ | 예측된 노드 집합 |
| $V^{\text{gt}}$ | 정답(gold) 노드 집합 |
| $E^{\text{pred}}$ | 예측된 방향성 엣지 집합 |
| $E^{\text{gt}}$ | 정답 방향성 엣지 집합 |

#### 모델 구조

```
입력 다이어그램 이미지 I
         │
         ▼
[지각 & 기반 단계]
  ├─ 이진화 + 연결 성분 분석 (Otsu → CC)
  ├─ 영역 분할 (구조적/비구조적)
  ├─ 영역 병합 (OCR 박스 기반)
  └─ PaddleOCR 텍스트 감지 → 영역-텍스트 쌍 R = {(rᵢ, tᵢ)}
         │
         ▼
[Stage I] 전역 도형 속성 추론 (GPT-4o)
  → A = {a_sem, a_dir, a_dens}
         │
         ▼
[Stage II] 정준 노드 목록 구성 (GPT-4o)
  → V = {vᵢ}ᴺᵢ₌₁ (노드 목록 + 범례 요약)
         │
         ▼
[Stage III] 노드 중심 관계 추론 (GPT-4o × N)
  → Eᵢ = F_rel(vᵢ, I, S, A) for each vᵢ
  → E_draft = ∪ Eᵢ
         │
         ▼
[Stage IV] 위상 일관성 강제 (LLM self-check + 결정론적 후처리)
  → G* = SelfCheck(V, E_draft, A)
         │
         ▼
출력: 구조화된 위상 그래프 JSON
```

> 💡 **용어 설명**
> - **PaddleOCR**: 바이두(Baidu)가 개발한 오픈소스 광학 문자 인식(OCR) 시스템. 다국어 텍스트 감지 및 인식 지원
> - **Chain-of-Region**: 이미지를 지역별로 분해하여 세밀한 시각 정보를 단계적으로 처리하는 VLM 추론 프레임워크 (Li et al., 2025a)

## 4. 저자 보고 결과 vs. 내 해석 분리

### 저자가 직접 보고한 결과

- TopoAgent는 Web-style에서 Node F1 95.6, Edge F1 45.8을 달성 (Table 1)
- Network-style에서 Edge F1 58.1로 모든 기준선 상회 (Table 1)
- Ablation: 모든 4개 모듈이 성능에 기여 (Table 2)
- VLM 백본 일반화: Qwen2.5-VL-7B의 Network-style Edge F1이 29.6 → 43.7로 향상 (Table 4)
- 오류 분석: Network-style에서 누락 엣지가 56.0%로 주요 오류 유형 (Table 7)
- 추론 비용: 단일 패스 대비 약 14배 API 호출, 약 11.5배 총 토큰 소비 (Table 8)

### 내 해석

1. **성능 향상의 실질적 의미**: Edge F1 기준 절대 수치가 전반적으로 낮음 (최고 58.1). 이는 다이어그램-그래프 추출이 현재 VLM 기술로도 여전히 미해결 과제임을 시사합니다. 성능 향상 폭(예: +4.6pt)이 실용적으로 충분한지는 응용 맥락에 따라 다릅니다.

2. **노드 추출이 쉽고 엣지 추출이 어려운 이유**: 노드는 텍스트 레이블을 OCR로 감지하면 되지만, 엣지는 시각적 연결선의 방향과 연결점을 동시에 정확히 해석해야 하므로 근본적으로 더 어렵습니다.

3. **비용 대비 효과**: 약 14배의 API 호출이 Edge F1 기준 약 3~10pt 향상을 가져옵니다. 실용적 배포 시 비용 효율성 검토가 필요합니다.

4. **일반화 주장의 한계**: 벤치마크가 180개에 불과하고 Web-style(54개)과 Network-style(126개)로 구성되어, 실제 세계의 다이어그램 다양성을 충분히 대표하지 못할 수 있습니다.

5. **GPT-4o 의존성**: 저자는 "VLM 백본 독립성"을 주장하지만, 오픈소스 모델로의 성능 격차는 여전히 존재하며 완전한 대체는 어렵습니다.

## 6. 논문이 답하지 않는 질문

1. **비용 효율적 변형의 가능성**: 5단계 파이프라인을 3~4단계로 줄였을 때 성능/비용 트레이드오프는?

2. **오류 전파 정량화**: Stage I의 도형 속성 오분류가 최종 성능에 미치는 구체적 영향은? (오류 전파 분석 미제공)

3. **타 도메인 일반화**: 회로 도면, 유기 화학 구조식, UML 다이어그램 등 완전히 다른 도메인의 다이어그램에도 적용 가능한가?

4. **인간 성능 기준(Human Baseline)**: 사람이 같은 과제를 수행했을 때의 F1은? 현재 모델과 인간 간 성능 격차를 알 수 없음

5. **학습 기반 특화 모델과의 비교**: 프롬프팅 기반 접근 vs. 파인튜닝된 특화 모델 간 성능 비교 미수행

6. **Stage I 도형 분류 정확도**: $A = \{a_{\text{sem}}, a_{\text{dir}}, a_{\text{dens}}\}$ 각 속성의 분류 정확도가 별도로 보고되지 않음

7. **영역 분해 품질 평가**: 지각 단계에서의 영역 분해 및 OCR 정확도가 독립적으로 평가되지 않음

8. **벤치마크 주석자 간 일치도(Inter-annotator Agreement)**: 두 주석자 간의 합의 수준을 수치로 보고하지 않음

9. **한국어·중국어·일본어 등 비영어 다이어그램 처리**: 다국어 다이어그램에 대한 실험 미포함

10. **파인튜닝 전략의 잠재력**: 현재 제로샷(zero-shot) 프롬프팅에 의존하며, 소량 파인튜닝 시 성능 향상 가능성을 탐구하지 않음

## 7. 가장 중요한 그림 5개 해석

### Figure 1 (p.1): 동기 비교 다이어그램

**해석**: 세 가지 접근법을 시각적으로 대비합니다.
- **(A) 일반 VLM**: 세밀한 지각 기반 부재, 위상 일관성 없음 → hallucinated 노드/엣지 생성
- **(B) 정보 집약적 시각 기준선**: 부분적 지각 기반, 여전히 위상 불일관성 존재
- **(C) TopoAgent**: 도구 활용 + 추론 + 검증 → 환각 감소, 일관된 위상

이 그림은 논문의 핵심 동기를 직관적으로 전달하며, TopoAgent의 차별점(지각과 추론의 통합)을 명확히 제시합니다. 그러나 예시 다이어그램이 단순하여 실제 어려운 사례를 대표하지 못할 수 있습니다.

---

### Figure 2 (p.3): TopoBench-180 구축 파이프라인

**해석**: 6,000+개 원시 이미지 → 4,318개(중복 제거) → 741개(VLM 기반 가지치기) → 180개(인간 검증 최종 선별)의 단계적 품질 게이팅 과정을 보여줍니다. GPT-4o가 초안 그래프를 생성하고, 전문가가 교정하는 2단계 주석 과정이 포함됩니다. 이 파이프라인은 데이터 품질을 보장하지만, 최종 180개 샘플이 전체 풀의 3%에 불과하다는 점에서 선택 편향 위험이 있습니다.

> 💡 **용어 설명**
> - **VLM-driven Pruning(VLM 기반 가지치기)**: GPT-4o를 사용하여 벤치마크에 적합하지 않은 다이어그램을 자동 필터링하는 과정

---

### Figure 3 (p.5): TopoAgent 전체 프레임워크 구조

**해석**: 파이프라인의 좌-우 흐름을 시각화합니다. 왼쪽 **지각 & 기반** 블록(영역 분해, OCR 기반, 기본 요소 요약)이 중앙 **위상 추론** 블록(Stage I~IV)에 입력을 제공하고, 최종 오른쪽에 구조화된 JSON 출력이 생성됩니다. 특히 Stage III(노드 중심 추론)가 $N$개의 노드에 대해 반복 실행된다는 점이 추론 비용의 주요 원인임을 시각적으로 확인할 수 있습니다.

---

### Figure 6 (p.16): TopoBench-180 복잡도 분포

**해석**: Web-style과 Network-style 각각의 노드 수, 관계 수, 고유 쌍 밀도 분포를 히스토그램으로 제시합니다. Network-style 다이어그램이 더 넓은 노드/엣지 범위와 더 높은 밀도를 보여 더 어려운 과제임을 확인할 수 있습니다. Web-style은 노드 수가 적지만 방향성 민감도가 높고, Network-style은 위상 완전성과 노드 기반 일관성이 주요 도전임을 보여줍니다. 이는 Table 7의 오류 패턴과 일관됩니다.

> 💡 **용어 설명**
> - **Unique-pair Density(고유 쌍 밀도)**: $|E| / (|V|(|V|-1))$로 계산. 최대 가능한 방향성 엣지 수 대비 실제 엣지 비율. 그래프의 밀집도를 나타내는 지표

---

### Figure 7 & 8 (p.28): 성공/실패 정성적 사례

**Figure 7 해석**: 두 성공 사례(Web-style 먹이사슬, Network-style 네트워크)에서 TopoAgent가 Node F1 = Edge F1 = 1.0을 달성합니다. 공통 특징: 노드 수 소, 고유한 레이블, 명확한 연결, 비구조적 잡음 최소.

**Figure 8 해석**: 두 실패 사례(복잡한 먹이사슬 Web-style, 밀집 네트워크)에서 Edge F1이 31.3과 45.0으로 하락합니다. 실패 요인: 교차하는 긴 화살표, 모호한 방향성, 읽기 어려운 텍스트, 시각적 잡음 요소. 이는 향후 개선이 필요한 구체적 한계를 제시합니다.

## 8. 결론 및 후속 연구

### 8-A. 연구자가 제시한 시사점 및 후속 연구 계획

**시사점** (Section 7, p.8–9):
- 구조-인식 인식-추론 설계가 강력한 VLM 기준선과 시각 추론 프레임워크를 모두 능가
- 특히 에지 추출에서 명확한 이점 확인
- 다이어그램-그래프 위상 추출이라는 새로운 멀티모달 구조 이해 과제 정의

**저자 제안 후속 연구** (Section 8, p.9):
1. 합성/생성 다이어그램을 활용한 벤치마크 확장 (인간 검증 동반)
2. 더 컴팩트한 추론 파이프라인 개발
3. 다이어그램 특화 지각 모듈 강화
4. 경량 파인튜닝을 통한 반복 멀티스테이지 추론 의존성 감소
5. 더 효율적인 모델 라우팅 (로컬 추론 → 소형 모델, 글로벌 계획 → 대형 모델)

### 8-B. 모델의 일반화 성능 향상 가능성

#### 현재 일반화 실험 결과 (Table 4, p.21)

| 백본 | 설정 | Network-style Edge F1 |
|------|------|----------------------|
| GPT-4o | Single-pass | 53.5 |
| GPT-4o | **TopoAgent** | **58.1 (+4.6)** |
| Qwen2.5-VL-72B | Single-pass | 47.5 |
| Qwen2.5-VL-72B | **TopoAgent** | **55.6 (+8.1)** |
| Qwen2.5-VL-7B | Single-pass | 29.6 |

**핵심 관찰**: 소형 모델(7B)에서 향상 폭이 가장 크며, 이는 구조적 추론 설계가 약한 VLM에게 더 큰 보조 역할을 함을 시사합니다.

#### 일반화 성능 향상을 위한 잠재적 방향

1. **도메인 적응적 훈련**: 다이어그램 유형별 특화 훈련 데이터 구성. 예: 회로도, UML, 생물학적 경로도 등 도메인별 소량 파인튜닝(few-shot fine-tuning)

2. **구조 인식 표현 학습**: 그래프 구조 정보를 VLM 임베딩 공간에 통합하는 아키텍처 수정. 예: Graph Neural Network(GNN)와 VLM의 하이브리드

   > 💡 **용어 설명**
   > - **GNN(Graph Neural Network)**: 그래프 구조 데이터에서 노드와 엣지의 관계를 학습하는 신경망. 위상 추출 결과를 후처리하거나 추론 보조에 활용 가능

3. **합성 데이터 증강**: 다양한 위상 패턴의 합성 다이어그램을 생성하여 훈련 데이터 다양성 확보. NetworkX, Graphviz 등 라이브러리를 활용한 프로그래매틱 생성

4. **메타러닝(Meta-learning) 접근**: 새로운 다이어그램 유형에 빠르게 적응하는 MAML 류의 방법 적용

5. **강화학습(RL) 기반 추론 최적화**: 위상 일관성 보상 함수를 설계하여 에이전트가 더 효과적인 추론 전략을 학습하도록 유도

### 8-C. 2020년 이후 관련 최신 연구 비교 분석

> ⚠️ **중요**: 아래 비교는 본 논문의 참고문헌 목록과 일반 AI 연구 지식에 기반합니다. 직접 논문을 확인하지 않은 내용은 별도 표시합니다.

#### 관련 최신 연구 비교표

| 연구 | 연도 | 핵심 접근법 | 본 논문과의 관계 |
|------|------|-------------|-----------------|
| **ChartQA** (Masry et al.) | 2022 | 차트 QA 벤치마크 | 구조적 시각 이해 벤치마크 선행 연구; QA에 한정 |
| **AI2D-RST** (Hiippala et al.) | 2021 | 과학 다이어그램 담화 구조 분석 | 다이어그램 이해 분야 선행; 그래프 추출 미포함 |

| **Pixel-Reasoner** (Wang et al.) | 2025 | 픽셀 공간 강화학습 기반 추론 | 비교 기준선; 위상 특화 없음 |

| **DeepSeek-R1** (Guo et al.) | 2025 | RL 기반 추론 강화 LLM | 위상 추론 개선에 적용 가능한 방법론 |
| **LLaVA-CoT** (Xu et al.) | 2025 | 단계적 시각 추론 | TopoAgent와 유사한 체인-오브-쏘트 접근; 위상 특화 없음 |

#### 본 논문의 영향 및 고려사항

**앞으로의 연구에 미치는 영향**:

1. **새로운 과제 정의**: 다이어그램-그래프 위상 추출이라는 과제를 공식적으로 정의함으로써 후속 연구의 방향성을 제시합니다.

2. **벤치마크 기여**: TopoBench-180이 공개 배포됨으로써 표준 평가 기반이 마련됩니다 (HuggingFace 공개).

3. **파이프라인 설계 원칙**: 지각→속성추론→노드목록→관계추론→일관성강제의 단계적 설계 원칙이 유사 구조 이해 과제에 적용 가능합니다.

4. **에이전트-도구 통합**: VLM을 에이전트로 활용하여 OCR, 영역 분해 등 외부 도구와 결합하는 패러다임을 강화합니다.

**앞으로 연구 시 고려할 점**:

1. **벤치마크 확장 필요성**: 180개는 현대 AI 연구 기준으로 매우 소규모. 최소 수천 개 이상의 다이어그램으로 확장이 필요합니다.

2. **비용 효율성**: 현재 약 14회 API 호출/샘플 구조를 2~4회로 줄이는 경량 변형 연구가 실용화에 필수적입니다.

3. **다국어·다도메인 확장**: 영어 텍스트 레이블에 치우친 현재 벤치마크를 다국어 및 다양한 기술 도메인으로 확장해야 합니다.

4. **엔드-투-엔드 학습**: 현재 프롬프팅 기반 설계를 학습 가능한 모듈로 전환하는 파인튜닝 연구가 성능 상한선을 높일 수 있습니다.

5. **평가 지표 정교화**: 현재 이진 엣지 매칭(exact match)은 부분 정확도를 반영하지 못합니다. 그래프 편집 거리(Graph Edit Distance)나 부분 매칭 점수 도입을 고려해야 합니다.

   > 💡 **용어 설명**
   > - **Graph Edit Distance(그래프 편집 거리)**: 두 그래프를 동일하게 만들기 위해 필요한 최소한의 노드/엣지 삽입·삭제·치환 횟수. 부분적으로 옳은 예측을 평가하는 데 유용

6. **시각적 환각 정량화**: 위상 추출 맥락에서 환각의 유형과 빈도를 체계적으로 측정하고 완화하는 연구가 필요합니다.

7. **동적/변화하는 다이어그램**: 정적 다이어그램뿐만 아니라 애니메이션이나 시간에 따라 변화하는 다이어그램 처리로 확장 가능성을 고려해야 합니다.
