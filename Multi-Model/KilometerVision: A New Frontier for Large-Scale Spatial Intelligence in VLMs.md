# KilometerVision: A New Frontier for Large-Scale Spatial Intelligence in VLMs

**이 논문의 핵심 기여는 새로운 공간 추론 모델이 아니라, 기존 시각-언어 모델이 도시 규모의 공간을 실제로 이해하는지 평가하는 벤치마크와 진단 방법입니다.** 분석 기준은 첨부된 **arXiv:2609.39588v1, 2026년 9월 30일 버전**이며, 공식 프로젝트는 ECCV 2026 채택을 명시합니다. 아래 페이지 번호는 **첨부 PDF의 실제 페이지 순서**를 따릅니다. 따라서 PDF pp.21–29는 부록에 인쇄된 pp.1–9에 해당합니다. [arXiv](https://arxiv.org/abs/2609.39588)

## 1. Executive summary — 9문장

KilometerVision은 시각-언어 모델이 실제 도시 보행 영상을 보고 장소를 재인식하는 수준을 넘어, 이동 경로와 전체 공간 배치를 이해하는지 평가하기 위한 벤치마크입니다.  
저자들은 235개 보행 영상, 약 288시간의 원자료에서 최대 10분·약 1km 이동 구간에 관한 5지선다 질문을 구성하고, 이를 랜드마크·경로·지도라는 세 수준으로 조직합니다.  
정답은 사람이 영상 전체를 수작업으로 추적하는 대신, 시각적 위치 추정 서비스와 지도 경로 API를 결합해 생성합니다. **[저자 보고: pp.2, 4–6, Fig.1]** 2609.39588v1 2609.39588v1 2609.39588v1

평가한 다섯 모델 중 GPT-5가 가장 높은 성능을 보였으며, 입력을 32프레임에서 500프레임으로 늘렸을 때 전체 정확도가 본문 보고 기준 약 45%에서 57%로 상승했습니다.  
반면 Gemini 2.5 Flash는 32프레임에서 600프레임으로 늘려도 약 38% 수준으로 거의 개선되지 않았습니다.  
저자들은 장소 재인식에 비해 거리·방향·지도 대응이 취약하고, 도로명이나 지도 글자를 활용하는 경향이 강하다는 결과를 근거로 평가 모델들의 도시 규모 공간 이해가 제한적이라고 주장합니다. **[저자 보고: pp.12–15, Figs.8–9, Tables 1–2]** 2609.39588v1 2609.39588v1 2609.39588v1

다만 이러한 행동 관찰만으로 모델 내부에 기하학적 공간 표현이 전혀 없다고 확정할 수는 없습니다.  
또한 인간과 모델의 입력 조건 차이, 통계적 불확실성의 미보고, 문항 수와 일부 해석 문장의 내부 불일치를 고려해야 합니다.  
이 연구는 일반화 성능 향상을 직접 입증하지는 않지만, 향후 연구가 단순 정답률 상승을 넘어 새로운 도시·시점·경로에서도 유지되는 공간 표현을 검증해야 한다는 중요한 평가 방향을 제공합니다. **[해석: pp.11–14, PDF pp.25–26의 실험·분석 범위에 근거]** 2609.39588v1 2609.39588v1 2609.39588v1

> **용어**  
> **시각-언어 모델, VLM**: 이미지·영상과 언어를 함께 입력받아 질문에 답하는 모델  
> **벤치마크**: 여러 모델을 동일한 문제와 채점 규칙으로 비교하는 평가 자료  
> **일반화**: 학습하거나 익숙해진 사례와 다른 환경에서도 능력을 유지하는 것

## 2. 연구 목적과 필요성

### 2.1 무엇을 해결하려는가?

**[저자 보고]** 기존 연구는 물체 사이의 관계, 실내 공간, 시뮬레이션 환경 등을 중심으로 공간 능력을 평가해 왔습니다.  
KilometerVision은 평가 범위를 실제 도시 보행 영상으로 확장하여, 모델이 여러 장면을 시간에 걸쳐 연결하고 유효한 지리적 공간 표현을 구성하는지 묻습니다. **[pp.2–4, §1–2]** 2609.39588v1 2609.39588v1

이를 구분하는 질문은 다음과 같습니다.

| 공간 이해 수준 | 확인하려는 능력 | 단순 인식만으로 부족한 이유 |
|---|---|---|
| **랜드마크** | 특정 장소를 전에 보았는가? | 장소를 알아보더라도 현재 위치와의 거리를 알지는 못할 수 있습니다. |
| **경로** | 어떤 방향으로 얼마나 회전했고, 어떤 순서로 이동했는가? | 도로명을 읽는 것과 실제 이동·회전을 누적 추적하는 것은 다릅니다. |
| **지도 수준 지식** | 서로 다른 위치의 전체 배치와 직선거리는 무엇인가? | 이동 중 직접 보지 못한 공간 관계까지 통합해야 합니다. |

세 수준은 논문의 평가 설계를 조직하는 중심 틀입니다. 다만 **이 분류 자체가 모델 내부도 반드시 같은 순서로 발달한다는 증거는 아닙니다.** **[저자 보고와 해석 구분: pp.2, 6, Fig.1]** 2609.39588v1 2609.39588v1

> **용어**  
> **랜드마크**: 위치를 기억하거나 구분하는 기준이 되는 건물·조형물·장소  
> **자기중심적 표현, egocentric representation**: “내 앞”, “내 오른쪽”처럼 관찰자를 기준으로 한 공간 표현  
> **환경중심적 표현, allocentric representation**: 관찰자의 방향과 무관하게 장소들 사이의 배치를 나타낸 표현  
> **지도 수준 지식, survey knowledge**: 여러 경로와 장소를 전체 배치로 통합한 지식

### 2.2 왜 필요한가?

**[해석]** “영상에서 무엇을 보았는가”에 잘 답하는 모델이 “어디로 이동했으며 현재 어디에 있는가”에도 잘 답한다고 가정해서는 안 됩니다. 이 논문에서 중요한 구분은 **장소 재인식, 이동 추적, 공간 관계 추론을 별도로 평가한다는 점**입니다. 실제 결과에서도 시각적 재인식과 거리·시간 선택 성능 사이에 차이가 나타납니다. **[p.14, Fig.9]** 2609.39588v1

또한 여기서 “1km 규모”는 **대략적인 이동 경로 길이**를 가리킵니다. 모델이 매번 1시간 영상을 입력받는다는 뜻도, 시작점과 끝점 사이 직선거리가 항상 1km라는 뜻도 아닙니다. 원자료는 장시간 영상이지만 평가 구간은 최대 10분입니다. **[pp.4, 6]** 2609.39588v1 2609.39588v1

## 4. 제안 방법과 모델 구조: 실제로 새로 만든 것은 무엇인가?

### 4.1 모델 학습 구조가 아니라, 정답 생성·평가 구조다

**[저자 보고]** 전체 과정을 다음처럼 구분할 수 있습니다.

```text
정답 생성
장시간 보행 영상
→ 사람이 시작·끝 위치 표시
→ VPS 순방향·역방향 위치 추정
→ 신뢰도 가중 결합 및 재추정
→ 이상치 제거
→ 지도 경로와 정렬
→ 5지선다 질문·정답 생성

모델 평가
균일하게 샘플링한 영상 프레임
+ 질문
+ 다섯 선택지
+ 과제에 따라 랜드마크 이미지 또는 지도 선택지
→ 기존 VLM
→ 선택지 응답 채점
```

첫 번째 과정에 Google의 위치·지도 정보가 사용되지만, 그것이 주 실험에서 각 VLM에 자동으로 제공되는 것은 아닙니다. 좌표·카메라 자세·정답 지도 등의 추가 제공은 별도 실험입니다. 또한 평가 모델의 실제 도구 사용은 활성화되지 않았습니다. **[pp.4–5, 10, 12–14; PDF p.29, Fig.16]** 2609.39588v1 2609.39588v1 2609.39588v1 2609.39588v1

**이 논문은 새로운 인코더, 지도 메모리 모듈, 학습 손실 또는 학습된 KilometerVision 모델을 제안하지 않습니다.** 평가 대상은 PLM-8B, Qwen2.5-VL-72B, Gemini 2.5 Flash, GPT-5, Claude Opus입니다. 모델별 내부 층 구성이나 공통 학습 절차도 이 논문의 실험 방법으로 제시되지 않습니다. **[pp.11–12, §5]** 2609.39588v1 2609.39588v1

> **용어**  
> **카메라 자세, pose**: 카메라의 위치와 바라보는 방향  
> **인코더**: 이미지 같은 입력을 모델이 계산하기 쉬운 숫자 표현으로 바꾸는 구성 요소  
> **추론**: 학습이 끝난 모델에 입력을 주고 답을 생성하는 과정

### 4.2 VPS 기반 영상 위치 추정

**[저자 보고]** VPS는 영상 프레임을 Street View 이미지 표현과 대응시켜 위치와 자세를 추정합니다. 가까운 초기 위치 추정이 필요하기 때문에 사람이 시작점과 끝점을 제공합니다. 초기 탐색은 4 FPS, 이후 전체 영상 처리는 1 FPS로 수행합니다. 위치 갱신 신뢰도 임계값은 0.9이며, 일정 시간 갱신이 없을 때의 보완 규칙도 사용합니다. **[pp.4–5; PDF pp.21–22, Algorithm 1]** 2609.39588v1 2609.39588v1 2609.39588v1

순방향과 역방향의 위치를 결합하는 설명은 다음과 같이 수식화할 수 있습니다.

**[설명용 재표현 — 논문에 독립된 번호로 제시된 수식은 아님]**

```math
\bar{\boldsymbol{\ell}}_t
=
\frac{
c_t^{f}\boldsymbol{\ell}_t^{f}
+
c_t^{b}\boldsymbol{\ell}_t^{b}
}{
c_t^{f}+c_t^{b}
}
```

여기서 $t$는 프레임 시점, $\boldsymbol{\ell}_t^{f}$와 $\boldsymbol{\ell}_t^{b}$는 각각 순방향·역방향 처리에서 얻은 위도·경도 좌표, $c_t^{f}$와 $c_t^{b}$는 해당 신뢰도, $\bar{\boldsymbol{\ell}}_t$는 결합된 초기 위치입니다. 분모가 양수인 경우의 표현이며, 이 위치를 초기값으로 **마지막 VPS 추정을 다시 수행**합니다. 카메라 회전까지 위 식으로 단순 평균한다는 뜻은 아닙니다. **[PDF pp.22–23, Algorithm 2]** 2609.39588v1

> **용어**  
> **VPS, Visual Positioning System**: 영상의 시각적 특징을 이용해 촬영 위치를 추정하는 서비스  
> **신뢰도 가중 평균**: 더 신뢰할 만하다고 평가된 추정값에 더 큰 비중을 주는 평균  
> **FPS**: 1초당 처리하거나 보여 주는 프레임 수

이후 낮은 신뢰도, 비현실적인 인접 위치 변화, 희박한 유효 구간을 제거합니다. 저자들이 선택한 필터 설정은 검증 자료에서 거짓 양성이 관찰되지 않는 대신, 약 40%의 데이터를 유지하는 보수적 설정입니다. **[PDF pp.23–25, Algorithm 3, Fig.11]** 2609.39588v1

**[해석]** 정확한 정답을 우선하는 합리적 선택이지만, 유지된 데이터가 전체 도시 환경을 대표한다는 보장은 없습니다. Street View 대응이 어렵거나 시각적 특징이 부족한 환경이 더 많이 제거될 가능성을 별도로 조사해야 합니다.

### 4.3 논문에 실제로 제시된 수식: DTW 거리

첨부 논문의 번호가 붙은 수식은 부록의 다음 **Eq.(1)**입니다.

```math
\text{dist}(A,B)
=
\sum_{k=1}^{K}
\left\|A[i_k]-B[j_k]\right\|
```

$A$와 $B$는 비교할 두 위치 궤적, $i_k$와 $j_k$는 두 궤적에서 대응시킨 점의 인덱스, $K$는 대응 쌍의 수, $\|\cdot\|$는 대응 위치 사이의 거리입니다. DTW는 이동 순서를 유지하면서 이 거리의 합을 작게 만드는 대응을 찾습니다. **[PDF p.24, Eq.(1)]** 2609.39588v1

**[저자 보고]** 사람 경로와 VPS 경로는 샘플링 방식이 다릅니다. 필터링으로 VPS 경로에 빈 구간이 생기면 하나의 VPS 점이 여러 사람 경로 점과 대응되어 거리가 불필요하게 커질 수 있으므로, 저자들은 그중 가장 가까운 대응만 유지하는 변형을 사용합니다. **[PDF pp.24–25]** 2609.39588v1

> **용어**  
> **궤적, trajectory**: 시간 순서대로 나열한 이동 위치  
> **DTW, Dynamic Time Warping**: 속도나 샘플 수가 다른 두 순서를 늘이거나 줄여 대응시키는 정렬 방법  
> **이상치**: 주변 관측이나 물리적 이동 조건과 크게 어긋나는 추정값

**[해석]** 이 수식은 **모델을 학습시키는 손실이 아니라 정답 경로를 검증·선택하는 측정 방법**입니다. 또한 위치 경로가 잘 정렬된다는 사실만으로 카메라 회전 정확도까지 검증되는 것은 아닙니다.

과제 정의와 정답 구성은 본문 §§4.1–4.3에 해당합니다. 2609.39588v1 2609.39588v1 2609.39588v1 2609.39588v1

거리 과제를 설명하기 위해 위치를 미터 단위의 공통 좌표 $\mathbf p_t$로 나타내면 다음과 같습니다.

**[설명용 재표현]**

```math
d_{\text{start,end}}
=
\|\mathbf p_T-\mathbf p_0\|_2,
\qquad
d_{\text{reference,end}}
=
\|\mathbf p_T-\mathbf p_{\tau}\|_2
```

$\mathbf p_0$와 $\mathbf p_T$는 시작·마지막 카메라 위치, $\mathbf p_\tau$는 기준 랜드마크 이미지를 촬영한 카메라 위치입니다. 따라서 두 번째 거리는 **현재 카메라에서 랜드마크 물체 표면까지의 깊이**가 아니라, **두 촬영 위치 사이의 직선거리**입니다. 논문은 시작–끝 거리 계산에 L2 거리를 사용한다고 명시하지만, 위도·경도를 미터 좌표로 변환하는 세부 구현은 충분히 설명하지 않습니다. **[pp.6–7, 11]** 2609.39588v1 2609.39588v1

나침반 과제가 요구하는 누적 회전 추적은 개념적으로 다음과 같습니다.

**[설명용 식 — 논문이 구현한 모델 알고리즘은 아님]**

```math
\hat{\theta}_T
=
\left(
\theta_0+\sum_{t=1}^{T}\widehat{\Delta\theta_t}
\right)\bmod 2\pi
```

$\theta_0$는 초기 방향, $\widehat{\Delta\theta_t}$는 연속 관측 사이에서 추정한 회전 변화, $\hat{\theta}_T$는 마지막 방향 추정입니다. 실제 평가는 연속 각도가 아니라 방향 범주로 수행됩니다. **카메라가 바라보는 방향과 사람이 이동하는 방향은 항상 같지 않으므로**, 이 회전 식만으로 이동 위치까지 복원할 수 있는 것은 아닙니다. **[p.8; PDF p.27, Fig.14]** 2609.39588v1 2609.39588v1

> **용어**  
> **유클리드 거리·L2 거리**: 두 점을 직선으로 연결했을 때의 거리  
> **경로 적분, path integration**: 이동량과 회전량을 누적해 현재 위치·방향을 갱신하는 과정  
> **모듈로 $2\pi$**: 한 바퀴를 넘는 각도를 동일한 방향 범위로 되돌리는 연산

정답 생성에서 추가로 중요한 조건은 다음과 같습니다. 랜드마크 이미지는 같은 영상에서 VPS 신뢰도 0.98 초과 프레임을 선택하고, 루프 후보는 4m 반경 내 재방문을 탐색한 후 사람이 확인합니다. 시작–끝 거리 문항의 오답은 정답에서 100m 이내에 들어오지 않도록 생성합니다. 마지막 조건이 **랜드마크 거리 문항에도 동일하게 적용되었다고 원문은 명시하지 않습니다.** **[pp.7–8, 11]** 2609.39588v1 2609.39588v1 2609.39588v1

> **거짓 양성**: 부정확한 위치를 정확하다고 잘못 받아들인 경우  
> **참 양성률**: 실제로 올바른 위치 중 필터가 유지한 비율  
> **선택 편향**: 자료를 고르는 방식 때문에 최종 평가 자료가 전체 환경을 대표하지 못하는 문제

### 6.6 Fig.14 — 정답을 맞혔다고 중간 공간 추론도 맞은 것은 아니다

**[저자 보고]** Claude는 나침반 질문의 최종 정답을 맞혔지만, 중간 방향과 총 회전량 설명은 잘못되었습니다. 캡션은 실제 회전이 약 135도인데 응답은 약 90도로 설명했다고 지적합니다. **[PDF p.27, Fig.14]** 2609.39588v1

### 7.3 작은 과제별 차이에 필요한 불확실성 평가

**[설명용 계산 — 논문이 보고한 신뢰구간이 아님]** 문항이 독립이고 정확도가 약 50%라고 가정하면, 정확도의 대략적인 95% 오차 범위는 다음처럼 계산됩니다.

$$
\epsilon_{95}
\approx
1.96\sqrt{\frac{\hat p(1-\hat p)}{n}}
$$

$\hat p$는 관측 정확도, $n$은 독립 문항 수, $\epsilon_{95}$는 정규근사에 따른 오차 범위의 반폭입니다. 이 가정에서 $n=150$이면 약 **±8.0%포인트**, $n=49$이면 약 **±14.0%포인트**입니다.

실제 논문에는 문항·영상·평가자 사이의 의존성이 있으므로 이 값을 실제 신뢰구간으로 사용할 수 없습니다. 후속 평가에서는 같은 문항의 두 모델 응답을 대응시키고, 영상이나 도시 단위로 자료를 재추출하여 불확실성을 계산하는 편이 적절합니다.

> **용어**  
> **신뢰구간**: 표본 변동을 고려하여 성능의 불확실성을 나타내는 구간  
> **정규근사**: 표본 통계량의 분포를 종 모양 분포로 근사하는 방법  
> **군집 단위 재추출**: 개별 문항이 아니라 같은 영상·도시에 속한 자료 묶음을 함께 뽑아 불확실성을 계산하는 방법

### 7.4 루프 “존재 여부”에는 별도의 강한 기준선이 필요하다

**[저자 보고]** 루프 문항은 112개이고, 그중 루프가 없는 문항은 11개입니다. **[Figs.2, 4]** 2609.39588v1 2609.39588v1

$$

이는 **Fig.9의 이진 시각 재인식 점수**를 해석할 때 필요한 기준입니다. 그러나 방문 시점까지 맞혀야 하는 **원래 5지선다 루프 과제**의 기준선이 90.2%라는 뜻은 아닙니다.

**영상 없는 조건과 영상 있는 조건**은 문제 자체가 달라집니다. **좌표·정답 지도·정답 경로 설명을 받은 조건**은 순수 영상 조건보다 많은 정보를 사용합니다. **32·500·600프레임 조건**은 관측량과 계산 비용이 다릅니다. 따라서 이러한 차이는 각각 정보 제공 효과·입력 확대 효과로 해석해야 하며, 동일 조건의 모델 우열로 합쳐서는 안 됩니다. **[pp.12–14, Fig.8, Tables 1–2]** 2609.39588v1 2609.39588v1

### 8.2 방법 비교에서 중요한 두 가지 수식

#### 위치 정보를 “추가 입력”이 아니라 “학습 표현”에 통합하기

Video-3D LLM은 영상 특징과 좌표 특징을 다음처럼 결합합니다.

```math
\mathbf e_k^{\text{vis}}
=
\mathbf e_k^{\text{img}}
+
\mathbf e_k^{\text{coord}}
```

$k$는 프레임 인덱스, $\mathbf e_k^{\text{img}}$는 이미지 특징, $\mathbf e_k^{\text{coord}}$는 대응하는 3D 좌표의 위치 표현, $\mathbf e_k^{\text{vis}}$는 결합된 위치 인식 영상 표현입니다. **[Video-3D LLM, p.4, Eq.(5)]** [arXiv](https://arxiv.org/pdf/2412.00493)

**[해석]** KilometerVision의 좌표 제공 실험은 주로 **학습 없이 추가 정보를 사용하게 하는 조건**입니다. 따라서 두 연구가 묻는 질문은 다릅니다. 후속 연구는 “좌표를 주면 바로 사용하는가”와 “좌표를 사용하도록 훈련하면 새로운 도시에서도 도움이 되는가”를 분리해야 합니다.

> **용어**  
> **위치 표현·위치 인코딩**: 공간 좌표를 다른 시각 특징과 결합할 수 있는 숫자 벡터로 바꾼 것  
> **제로샷**: 해당 과제를 위한 추가 학습 없이 문제를 푸는 조건

#### 단계적 학습과 검증 가능한 보상

SpatialLadder의 보상은 다음과 같습니다.

```math
\mathcal R(o,y)
=
r_{\text{format}}(o)
+
r_{\text{accuracy}}(o,y)
```

$o$는 모델 응답, $y$는 정답, $r_{\text{format}}$은 응답 형식 보상, $r_{\text{accuracy}}$는 정답 일치 또는 수치 오차에 따른 보상입니다. **[SpatialLadder, §3.2, Eq.(1)]** [arXiv](https://arxiv.org/html/2510.08531v1)

**[해석]** 이 방향은 공간 지각을 먼저 학습한 후 추론을 강화한다는 점에서 유망합니다. 다만 **형식 준수와 최종 정답에 대한 보상만으로 중간 공간 추론의 정확성이 보장되지는 않습니다.** KilometerVision의 Fig.14처럼 정답과 설명의 타당성이 달라질 수 있기 때문입니다.

> **용어**  
> **지도학습, SFT**: 입력과 올바른 응답의 쌍을 이용해 모델을 추가 학습하는 방식  
> **보상 기반 학습**: 모델이 생성한 응답을 점수화하고 높은 점수를 얻는 행동을 강화하는 방식

### 8.3 최신 결과가 보여 주는 일반화의 크기와 한계

SpaceCast-Bench의 Table 4에서 Qwen3-VL-4B는 단계적 지도학습 후 자체 벤치마크가 **34.0%→65.7%**, 여섯 외부 평가의 평균은 **33.5%→38.1%**로 개선됩니다. 하지만 MindCube는 소폭 하락하며, 외부 평가는 각 벤치마크 전체가 아닌 선정된 부분집합을 포함합니다. 예를 들어 VSI는 150문항 부분집합입니다. **[p.9, Table 4; Appendix Table 10]** [arXiv](https://arxiv.org/pdf/2610.12402)

**[해석]** 이 결과에서 중요한 것은 “학습으로 개선될 수 있다”와 동시에 **훈련 과제에서의 큰 상승이 같은 크기의 외부 일반화 상승으로 이어지지는 않는다**는 점입니다. KilometerVision을 훈련 자료로 확장하더라도, 자체 점수와 새로운 도시·새로운 공간 과제의 성능을 따로 보고해야 합니다.

## 9. 문서가 답하지 않는 질문

### 9.1 새로운 도시에서도 같은 성능이 유지되는가?

여러 나라의 도시 영상을 모았다는 설명은 있지만, **도시 전체를 학습·개발 과정에서 제외한 평가**, 국가별 성능, 익숙한 관광지와 낯선 장소의 차이는 보고되지 않습니다. 따라서 지리적 다양성이 곧 지리적 일반화의 실증은 아닙니다. **[p.4, §3.1; pp.11–14의 실험 범위]** 2609.39588v1 2609.39588v1

### 9.2 실패의 주원인은 관측 부족인가, 공간 추론 부족인가?

프레임 수 실험은 있지만, 회전 구간을 조밀하게 보는 방식, 동일한 장면 관측 범위를 보장하는 방식, 연속 움직임 추정기를 결합하는 방식은 체계적으로 비교하지 않습니다. 따라서 32프레임 설정에서의 실패를 모두 추론 능력 부족으로 돌릴 수 없습니다. **[p.12, Fig.8]** 2609.39588v1

### 9.3 모델이 기하 정보를 전혀 쓰지 않는가?

영상 순서를 바꾸거나, 도로명만 교체하거나, 시각적 외형은 유지하면서 경로 기하를 바꾸는 실험이 필요합니다. 현재의 성능 차이와 선택된 응답 사례만으로 각 단서의 인과적 기여를 완전히 분리할 수 없습니다. **[pp.13–15; PDF p.26]** 2609.39588v1 2609.39588v1

### 9.4 정답 위치와 방향의 오차는 얼마나 되는가?

사람 경로와 VPS 경로의 검증 절차는 설명하지만, 전체 평가 문항의 위치 오차 분포, 카메라 방향 오차, 지도 정합 오차를 충분한 수치로 제공하지 않습니다. 또한 루프 후보에서 인접 프레임과 실제 재방문을 분리하는 세부 시간 조건도 명확히 재현하기 어렵습니다. **[pp.5, 8; PDF pp.23–25]** 2609.39588v1 2609.39588v1 2609.39588v1

### 9.5 실시간 이동과 안전한 의사결정에도 연결되는가?

이 연구는 주어진 영상을 본 뒤 선택지를 고르는 평가입니다. 모델이 직접 이동하며 관측을 선택하거나, 잘못된 지도를 수정하거나, 새로운 지름길을 실제로 찾아가는 능력은 평가하지 않습니다. **[pp.6, 10–11, 과제 정의]** 2609.39588v1 2609.39588v1

## 10. 결론과 후속 연구: 일반화 성능 향상을 중심으로

### 10.1 저자가 제시한 시사점과 후속 방향

**[저자 보고]** 저자들은 평가 모델들이 시각적 재인식과 의미 대조에 강하지만, 경로 적분과 전체 지도 지식은 충분히 성숙하지 않았다고 결론짓습니다. 이 벤치마크가 신뢰할 수 있는 AI 보조 시스템과 물리 환경에서 활동하는 AI의 공간 능력 개발에 도움이 되기를 기대합니다. **[p.15, §6]** 2609.39588v1

후속 방향으로는 추가 좌표·자세 정보를 활용하기 위한 **미세조정의 필요 가능성**, 자동 주석 파이프라인을 통한 **문항 확대 가능성**이 언급됩니다. 다만 새 모델, 학습 일정, 예정된 실험을 포함한 구체적인 후속 연구 계획은 제시하지 않습니다. **[pp.6, 13]** 2609.39588v1 2609.39588v1

### 10.2 추가 제안 ① — 장소 인식과 기하 추정을 경쟁시키지 말고 결합해야 한다

**[제안]** 유망한 구조는 장소 재인식, 연속 프레임의 이동 추정, 지속적인 지도 기억을 결합하는 방식입니다.

```text
장소 재인식 ─────────┐
                    ├→ 위치·경로를 유지하는 지도 기억 → 공간 질문 응답
연속 관측의 기하 추정 ┘
```

장소를 시각적으로 맞추는 것 자체는 잘못된 전략이 아닙니다. 논문도 SLAM이 시각적 인식과 기하 추정을 함께 사용한다고 설명합니다. 문제는 **유사한 외형을 가진 다른 장소를 기하학적으로 구분·검증할 수 있는가**입니다. **[p.8, §4.2; p.14, 루프 분석]** 2609.39588v1 2609.39588v1

이 구조의 효과를 검증할 때는 정답 좌표를 추론 시 제공하는 조건과, 학습에만 활용하고 평가 시 영상만 사용하는 조건을 분리해야 합니다.

### 10.3 추가 제안 ② — 정답뿐 아니라 공간 관계의 일관성을 학습·평가해야 한다

**[제안 수식 — KilometerVision이 사용한 손실이 아님]** 같은 좌표계에서 위치 $i$에서 $j$로의 상대 변위를 $\hat{\mathbf d}_{ij}$라고 하면, 세 위치 사이에는 다음 일관성이 요구됩니다.

```math
\mathcal L_{\text{cons}}
=
\sum_{(i,j,k)\in\mathcal T}
\left\|
\hat{\mathbf d}_{ij}
+
\hat{\mathbf d}_{jk}
-
\hat{\mathbf d}_{ik}
\right\|_2^2
```

$\mathcal T$는 평가할 위치 삼중항 집합, $\hat{\mathbf d}\_{ij}$는 예측한 상대 이동 벡터, $\mathcal L_{\text{cons}}$는 서로 다른 경로로 계산한 이동이 얼마나 모순되는지 측정하는 값입니다.

이 손실은 다음과 같은 다중 목적 학습의 한 항으로 사용할 수 있습니다.

```math
\mathcal L
=
\mathcal L_{\text{QA}}
+
\lambda_p\mathcal L_{\text{pose}}
+
\lambda_c\mathcal L_{\text{cons}}
```

$\mathcal L_{\text{QA}}$는 질문 응답 오차, $\mathcal L_{\text{pose}}$는 위치·방향 추정 오차, $\lambda_p$와 $\lambda_c$는 각 항의 비중입니다.

**주의할 점은 일관성만 맞추면 충분하지 않다는 것입니다.** 모든 이동을 0으로 예측해도 첫 식은 작아질 수 있으므로, 실제 이동량·방향을 감독하는 항과 결합해야 합니다. 또한 VPS 오류를 학습 정답으로 그대로 복제하지 않도록 별도의 검증 자료가 필요합니다.

> **용어**  
> **상대 변위**: 한 위치에서 다른 위치까지의 방향과 거리 변화  
> **일관성 손실**: 여러 방식으로 계산한 결과가 서로 모순될 때 부과하는 학습 벌점  
> **다중 목적 학습**: 최종 답뿐 아니라 위치·방향 같은 중간 능력도 함께 학습하는 방식

### 10.4 추가 제안 ③ — 일반화를 여러 축으로 나누어 측정해야 한다

| 일반화 축 | 권장 평가 설계 | 개선으로 인정할 근거 |
|---|---|---|
| **새로운 도시·국가** | 도시 전체를 개발·학습 자료에서 제외합니다. | 특정 도로명이나 관광지 기억 없이 성능이 유지됩니다. |
| **새로운 외형 조건** | 같은 경로를 다른 계절·조명·카메라·시점에서 촬영합니다. | 시각적 모습이 달라도 동일한 경로·장소를 연결합니다. |
| **새로운 경로 구조** | 학습과 다른 회전 조합·루프·우회 구조를 평가합니다. | 익숙한 경로 패턴을 외우지 않고 이동 관계를 계산합니다. |
| **언어 단서 변화** | 도로명을 제거하거나 가상의 이름으로 일관되게 교체합니다. | 불필요한 이름 변화에 기하 답변이 흔들리지 않습니다. |
| **더 긴 시간·거리** | 길이를 늘리되 회전 수와 관측 예산도 함께 통제합니다. | 길어질수록 누적되는 위치·방향 오류를 억제합니다. |
| **새로운 과제** | 학습하지 않은 지름길·역방향 경로·새 관찰점 질문을 냅니다. | 만들어 둔 공간 표현을 새로운 목적에 재사용합니다. |

**[제안]** 평가 점수는 전체 평균 하나보다, 도시별·거리별·회전 수별·문자 의존도별로 나누어 제시하는 편이 좋습니다. 동일한 영상·도시 단위의 대응 비교, 신뢰구간, 모델 버전, 입력 프레임과 시각 정보 처리 예산을 함께 공개해야 개선의 원인을 판단할 수 있습니다.

### 10.5 이 논문이 앞으로의 연구에 미칠 수 있는 영향

**[해석]** KilometerVision의 가장 중요한 잠재적 영향은 “공간 질문에 정답을 맞혔는가”에서 **“어떤 정보를 사용해 맞혔으며, 그 능력이 새로운 공간에서도 유지되는가”로 평가 기준을 옮기는 것**입니다. 특히 동일한 이동 경험을 랜드마크·경로·지도 수준에서 나누고, 글자 제거와 추가 정보 제공을 통해 성공 전략을 검사한 점이 유용합니다. **[Figs.1, 6, 9; Tables 1–2]** 2609.39588v1 2609.39588v1 2609.39588v1

그러나 후속 연구가 이 벤치마크의 객관식 선택지 패턴이나 유명 장소에 과적합하면, 높은 점수가 오히려 새로운 착시를 만들 수 있습니다. 최근의 벤치마크 편향 진단 연구와 외부 도메인 평가 연구를 함께 고려하면, **새로운 도시에서의 기하 일관성, 단서 교란에 대한 안정성, 새로운 과제로의 전이**를 개선의 핵심 증거로 삼는 것이 타당합니다. [arXiv](https://arxiv.org/pdf/2511.04655v2)

> **용어**  
> **과적합**: 특정 평가 자료의 특징에는 잘 맞지만 새로운 자료에는 성능이 떨어지는 현상  
> **전이**: 한 환경·과제에서 학습한 능력이 다른 환경·과제에도 도움이 되는 것

**최종 판단:** 이 논문은 **도시 규모 공간 이해의 취약성을 드러내는 의미 있는 진단 연구**입니다. 반면, “모든 VLM은 기하학적 공간 표현이 없다”는 강한 명제나 “특정 방법으로 일반화가 향상된다”는 명제를 입증한 연구는 아닙니다. 일반화 연구의 다음 단계는 입력 확대만이 아니라, **학습된 기하 표현·지도 기억·편법을 통제한 외부 평가를 함께 검증하는 것**입니다.
