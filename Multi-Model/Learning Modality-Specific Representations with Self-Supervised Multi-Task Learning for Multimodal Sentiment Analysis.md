# Learning Modality-Specific Representations with Self-Supervised Multi-Task Learning for Multimodal Sentiment Analysis

**핵심 판단:** 이 논문의 가장 중요한 기여는 **추가적인 사람의 단일모달 라벨 없이, 모달리티마다 다른 보조 감독 신호를 만들어 표현 학습을 개선하는 방법**입니다.  
다만 성능 향상은 데이터셋과 지표에 따라 다르며, **데이터셋 간 전이·결손 입력·잡음에 대한 일반화 개선은 원논문의 실험만으로 확인할 수 없습니다.** [원문, pp.3–7, Tables 1–4]

---

## 1. Executive summary — 10문장

1. 이 연구는 텍스트·음성·영상에 하나의 종합 감성 정답만 적용할 때 각 입력에 고유한 감성 정보가 충분히 학습되지 않는 문제를 다룹니다. [원문, p.1]
2. 제안 모델 **Self-MM**은 사람이 부여한 멀티모달 정답을 이용하면서, 단일모달 정답은 자동으로 생성하여 추가 주석 비용을 줄이도록 설계되었습니다. [원문, pp.1–3]
3. 모델은 하나의 멀티모달 감성 회귀 작업과 텍스트·음성·영상의 세 보조 회귀 작업을 공동 학습합니다. [원문, pp.2–3, Figure 1]
4. 단일모달 라벨 생성 모듈 **ULGM**은 각 표현이 긍정·부정 중심에서 얼마나 떨어져 있는지를 이용해 종합 감성 정답에 모달리티별 보정값을 더합니다. [원문, pp.4–5, Figure 2, 식 (1)–(8)]
5. 학습 중 생성 라벨이 급격히 변하는 문제를 완화하기 위해 과거 라벨과 새 라벨을 누적하고, 단일모달 라벨과 종합 라벨의 차이가 큰 표본에 더 큰 보조 손실 가중치를 부여합니다. [원문, p.5, 식 (9)–(10)]
6. MOSI에서 Self-MM은 MAE 0.713을 기록하여 저자가 재현한 MISA와 MAG-BERT보다 모든 보고 지표에서 좋은 결과를 보였습니다. [원문, p.4, Table 1]
7. MOSEI에서는 MAE 0.530과 상관계수 0.765를 기록했지만, 재현 MAG-BERT보다 이진 정확도는 낮아 모든 지표에서 우세한 것은 아닙니다. [원문, p.4, Table 1]
8. SIMS에서는 자동 라벨을 사용하는 Self-MM의 정확도가 80.74로 사람의 단일모달 라벨을 사용하는 Human-MM의 81.32에 근접했지만, Human-MM이 모든 보고 지표에서 더 좋았습니다. [원문, p.6, Table 3]
9. 다섯 번 실행한 평균은 보고되지만 변동성·유의성 검정과 데이터셋 간 전이·잡음·모달리티 결손 실험은 제시되지 않아, 통계적 우위와 환경 변화에 대한 일반화를 확정할 수 없습니다. [원문, pp.6–7]
10. 저자들은 전처리된 음성·영상 특징의 제약을 한계로 인정하며, 후속 연구로 종단간 멀티모달 학습과 단일모달·멀티모달 학습의 관계 탐구를 제시합니다. [원문, p.7, §6]

> **용어 설명**
>
> - **모달리티(modality):** 정보를 전달하는 형식으로, 이 논문에서는 텍스트·음성·영상을 뜻합니다.
> - **감성(sentiment):** 대상에 대한 긍정·부정의 평가와 그 강도입니다.
> - **회귀(regression):** 범주를 선택하는 대신 감성 강도와 같은 연속적인 숫자를 예측하는 문제입니다.
> - **감독 신호(supervision):** 모델이 무엇을 맞혀야 하는지 알려주는 학습 목표입니다.
> - **일반화(generalization):** 학습에 사용하지 않은 데이터에서도 예측이 잘 작동하는 성질입니다.

## 2. 연구 배경·목표·필요성

### 2.1 해결하려는 문제

**[저자 보고]** 멀티모달 감성 분석에서는 여러 입력을 함께 보고 만든 **하나의 종합 라벨**을 주로 사용합니다. 그러나 종합 판단과 텍스트만, 음성만, 영상만 보았을 때의 판단은 서로 다를 수 있습니다. 따라서 하나의 라벨만으로 표현을 학습하면 모달리티별 차이를 충분히 포착하기 어렵다는 것이 연구의 출발점입니다. [원문, p.1, §1]

저자들은 기존 접근을 다음과 같이 구분합니다.

| 접근 | 표현 학습을 유도하는 방식 | 저자가 지적한 문제 |
|---|---|---|
| 순방향 유도 | 모달리티 간 상호작용·융합 구조를 설계 | 공통 라벨만으로 모달리티 고유 정보를 충분히 학습하기 어려움 |
| 역방향 유도 | 추가 손실이나 단일모달 감독을 사용 | 사람의 추가 주석 비용 또는 손실 제약·가중치 설계 부담 |

[원문, pp.1–2, §§1–2]

> **용어 설명**
>
> - **표현(representation):** 원래의 문장·소리·영상을 모델이 처리하기 쉬운 숫자 벡터로 바꾼 결과입니다.
> - **융합(fusion):** 여러 모달리티의 표현을 결합해 하나의 판단에 사용하는 과정입니다.
> - **손실 함수(loss function):** 예측이 학습 목표에서 얼마나 벗어났는지 수치화하는 함수입니다.

### 2.2 연구 목적과 필요성

**[저자 보고]** 연구 목적은 다음 세 가지입니다.

1. 멀티모달 주 작업을 통해 모달리티 사이의 공통 정보를 학습합니다.
2. 서로 다른 단일모달 보조 라벨을 통해 모달리티 고유 정보를 학습합니다.
3. 추가적인 사람의 단일모달 주석 없이 이 과정을 수행합니다. [원문, pp.1–3]

이 문제의 배경에는 모달리티별 사람 라벨을 제공하는 **CH-SIMS**가 있습니다. CH-SIMS 연구는 종합 라벨과 개별 모달리티의 감성 상태가 항상 일치하지 않는다는 문제를 다루었고, Self-MM은 그러한 개별 감독을 자동으로 얻으려는 접근입니다. [원문, p.1; CH-SIMS, 초록 및 §7] [ACL Anthology](https://aclanthology.org/2020.acl-main.343/?utm_source=chatgpt.com)

**[해석]** Self-MM의 기여는 학습 목표의 설계에 있습니다. 단, 여기서 **자기지도 학습은 전체 학습에 사람 라벨이 필요 없다는 뜻이 아닙니다.** 사람이 부여한 멀티모달 정답이 필요하며, 자동화되는 부분은 단일모달 보조 라벨입니다. 또한 생성 라벨은 종합 라벨로부터 계산되므로, “독립적인 단일모달 감독”이라는 표현을 통계적 독립성으로 이해해서는 안 됩니다. [원문, pp.3–5, 식 (8)]

> - **제거 실험(ablation study):** 모델의 구성 요소를 빼거나 바꿔 해당 요소의 기여를 확인하는 실험입니다.
> - **Epoch:** 학습 데이터를 한 차례 사용하는 학습 단위입니다.

이 연구는 기존 공개 데이터셋을 이용한 **모델 비교 실험**, **보조 작업 조합의 제거 실험**, **생성 라벨의 변화 시각화**, **사례 분석**으로 구성됩니다. [원문, §§4–5]

| 데이터셋 | 학습 | 검증 | 시험 | 표에 기재된 합계 | 주요 데이터 소스 |
|---|---:|---:|---:|---:|---|
| MOSI | 1,284 | 229 | 686 | 2,199 | YouTube 영화 리뷰 93개에서 추출한 짧은 독백 클립 |
| MOSEI | 16,326 | 1,871 | 4,659 | 22,856 | 다양한 화자·주제를 포함하는 온라인 영상 발화 |
| SIMS | 1,368 | 456 | 457 | 2,281 | 중국어 영화·TV 연속극·예능 프로그램의 영상 클립 |

[원문, p.5, Table 2, §4.1]

MOSI의 감성 점수 범위는 $[-3,3]$, SIMS는 $[-1,1]$입니다. **MOSEI는 같은 페이지의 설명에 23,453개 발화라고 쓰였지만 Table 2의 합계는 22,856개이며, 차이 597개의 이유는 설명되지 않습니다.** [원문, p.5]

학습에는 Adam 최적화기를 사용하며, 초기 학습률은 BERT에 $5\times10^{-5}$, 나머지 파라미터에 $10^{-3}$을 적용합니다. Self-MM·MISA·MAG-BERT는 다섯 번 실행한 평균 성능을 보고합니다. [원문, p.6, §4.3]

> **용어 설명**
>
> - **검증 데이터:** 학습 설정이나 모델을 선택할 때 사용하는 데이터입니다.
> - **시험 데이터:** 선택이 끝난 모델의 성능을 평가하는 데이터입니다.
> - **Adam:** 학습 중 계산한 기울기에 따라 모델 파라미터를 갱신하는 최적화 방법입니다.
> - **학습률:** 한 번의 갱신에서 파라미터를 얼마나 크게 바꿀지 정하는 값입니다.

### 4.2 전체 구조: 주 작업 하나와 보조 작업 세 개

| 경로 | 입력 표현을 얻는 방법 | 학습 목표 | 추론 시 역할 |
|---|---|---|---|
| 텍스트 | 12층 BERT의 마지막 층 첫 단어 벡터 | 텍스트 보조 감성 예측 | 멀티모달 경로에 표현 제공 |
| 음성 | 사전 추출 특징을 단방향 LSTM으로 처리 | 음성 보조 감성 예측 | 멀티모달 경로에 표현 제공 |
| 영상 | 사전 추출 특징을 단방향 LSTM으로 처리 | 영상 보조 감성 예측 | 멀티모달 경로에 표현 제공 |
| 멀티모달 | 세 표현을 이어 붙인 후 선형 투영 | 사람의 종합 감성 정답 예측 | 최종 감성 예측값 출력 |

[원문, p.3, Figure 1, §3.2]

각 모달리티의 인코더는 멀티모달 주 작업과 해당 단일모달 보조 작업이 공유합니다. **텍스트·음성·영상이 하나의 동일한 인코더를 공유하는 구조는 아닙니다.** 보조 예측 경로와 ULGM은 학습에 사용하며, 최종 추론 출력은 멀티모달 예측값 $\hat y_m$입니다. [원문, pp.2–3]

> **용어 설명**
>
> - **인코더(encoder):** 입력을 특징 벡터로 바꾸는 신경망입니다.
> - **BERT:** 문맥을 반영한 텍스트 표현을 얻는 사전학습 언어 모델입니다.
> - **LSTM:** 순차 데이터를 처리하면서 이전 정보를 유지하도록 설계된 순환 신경망입니다.
> - **Hard sharing:** 여러 작업이 일부 신경망 파라미터를 직접 공유하는 방식입니다.
> - **추론(inference):** 학습된 모델로 새로운 입력을 예측하는 단계입니다.

### 4.3 입력 표현과 예측 수식

#### ① 모달리티별 표현 추출

원문의 p.3에 제시된 구조 수식은 다음과 같습니다.

$$
\begin{aligned}
F_t &= \text{BERT}(I_t;\theta_t^{\text{bert}})
\in \mathbb{R}^{d_t},\\
F_a &= \text{sLSTM}(I_a;\theta_a^{\text{lstm}})
\in \mathbb{R}^{d_a},\\
F_v &= \text{sLSTM}(I_v;\theta_v^{\text{lstm}})
\in \mathbb{R}^{d_v}.
\end{aligned}
$$

- $t,a,v$: 각각 텍스트, 음성, 영상.
- $I_t,I_a,I_v$: 각 모달리티의 입력.
- $F_t,F_a,F_v$: 각 입력을 요약한 표현 벡터.
- $\theta$: 해당 인코더의 학습 파라미터.
- $d_t,d_a,d_v$: 표현의 차원.
- $\text{sLSTM}$: 단방향 LSTM이며, 마지막 은닉 상태를 전체 시퀀스의 표현으로 사용합니다.

BERT는 미세조정합니다. 음성·영상의 초기 특징은 툴킷으로 추출하지만, **첨부 본문에는 해당 툴킷의 구체적인 이름과 정확한 특징 차원 설정이 충분히 명시되어 있지 않습니다.** [원문, p.2, §2.2; p.3, §3.2]

> **용어 설명**
>
> - **미세조정(fine-tuning):** 이미 학습된 모델을 현재 과제의 데이터로 추가 학습하는 과정입니다.
> - **은닉 상태(hidden state):** 순차 모델이 지금까지 처리한 정보를 담는 내부 벡터입니다.
> - **차원(dimension):** 벡터를 구성하는 숫자의 개수입니다.

#### ② 멀티모달 주 작업

$$
F_m^*=
\text{ReLU}\!\left(
(W_{l1}^{m})^\top[F_t;F_a;F_v]+b_{l1}^{m}
\right),
$$

$$
\hat y_m=(W_{l2}^{m})^\top F_m^*+b_{l2}^{m}.
$$

- $[F_t;F_a;F_v]$: 세 표현을 이어 붙인 벡터.
- $F_m^*$: 결합 후 투영된 멀티모달 표현.
- $W_{l1}^{m}$, $W_{l2}^{m}$: 학습 가능한 가중치 행렬.
- $b_{l1}^{m}$, $b_{l2}^{m}$: 편향.
- ${}^\top$: 전치.
- $\hat y_m$: 최종 감성 강도 예측값.
- $\text{ReLU}(z)=\max(0,z)$: 음수를 0으로 만드는 활성화 함수.

원문에서 $W_{l1}^{m}$의 크기는 $(d_t+d_a+d_v)\times d_m$, $W_{l2}^{m}$의 크기는 $d_m\times1$입니다. [원문, p.3, §3.2]

#### ③ 단일모달 보조 작업

```math
F_s^*=
\text{ReLU}\!\left((W_{l1}^{s})^\top F_s+b_{l1}^{s}\right),
```

$$
\hat y_s=(W_{l2}^{s})^\top F_s^*+b_{l2}^{s},
\qquad s\in\{t,a,v\}.
$$

```math
y_s=\text{ULGM}(y_m,F_m^*,F_s^*).
```

- $s$: 단일모달 작업의 종류.
- $F_s^*$: 보조 작업을 위해 투영한 표현.
- $\hat y_s$: 보조 작업의 예측값.
- $y_s$: 자동 생성한 보조 작업의 목표값.
- $y_m$: 사람이 부여한 멀티모달 정답.
- $\text{ULGM}$: 단일모달 라벨 생성 모듈.

ULGM 자체는 **학습할 파라미터가 없는 계산 모듈**입니다. 그러나 입력인 $F_m^\*,F_s^*$는 학습 중 변하므로 생성 라벨도 변합니다. [원문, pp.3–4]

> **용어 설명**
>
> - **투영(projection):** 벡터를 새로운 차원이나 특징 공간으로 변환하는 연산입니다.
> - **의사라벨(pseudo-label):** 사람이 직접 부여하지 않고 모델이나 계산 규칙으로 생성한 학습 목표입니다.

### 4.4 ULGM: 클래스 중심과 상대 거리

아래에서는 원문의 중복 인덱스를 구분하기 위해 **모달리티는 $q$, 표본은 $j$, epoch은 $k$**로 정리했습니다. 수식의 계산 내용은 유지했습니다.

#### ① 긍정·부정 중심 — 원문 식 (1), (2)

$$
C_q^p=
\frac{
\sum_{j=1}^{N}
\mathbf{1}[y_{q,j}>0]F_{qj}^{g}
}{
\sum_{j=1}^{N}
\mathbf{1}[y_{q,j}>0]
}.
$$

$$
C_q^n=
\frac{
\sum_{j=1}^{N}
\mathbf{1}[y_{q,j}<0]F_{qj}^{g}
}{
\sum_{j=1}^{N}
\mathbf{1}[y_{q,j}<0]
}.
$$

- $q\in\{m,t,a,v\}$: 멀티모달 또는 단일모달 경로.
- $N$: 학습 표본 수.
- $F_{qj}^{g}$: 표본 $j$에 대해 저장해 둔 경로 $q$의 전역 표현.
- $y_{q,j}$: 해당 경로에서 사용하는 라벨.
- $\mathbf{1}[\cdot]$: 조건이 참이면 1, 거짓이면 0.
- $C_q^p,C_q^n$: 각각 긍정·부정 표본 표현의 평균.

즉, 각 경로마다 긍정 표본의 평균 위치와 부정 표본의 평균 위치를 구합니다. **라벨이 정확히 0인 표본은 두 중심 계산에서 모두 제외됩니다.** [원문, p.4]

> **용어 설명**
>
> **클래스 중심 또는 centroid:** 같은 범주에 속한 벡터들의 평균 위치입니다. 이 논문에서는 감성 방향을 판단하는 기준점으로 사용합니다.

#### ② 중심까지의 거리 — 원문 식 (3), (4)

```math
D_q^p=\frac{\|F_q^*-C_q^p\|_2^2}{\sqrt{d_q}},
\qquad
D_q^n=\frac{\|F_q^*-C_q^n\|_2^2}{\sqrt{d_q}}.
```

- $F_q^*$: 현재 표본의 투영 표현.
- $d_q$: 해당 표현의 차원.
- $\|\cdot\|_2^2$: 제곱 유클리드 거리.
- $D_q^p,D_q^n$: 긍정·부정 중심까지의 거리를 차원에 따라 조정한 값.

**정확성 주의:** 원문 문장은 이를 “L2 normalization”이라고 부르지만, 실제 식은 **제곱 거리에 $\sqrt{d_q}$를 나누는 연산**입니다. 벡터를 길이 1로 만드는 일반적인 정규화 연산과 구별해야 합니다. [원문, p.5]

#### ③ 상대 거리 — 원문 식 (5)

$$
\alpha_q=
\frac{D_q^n-D_q^p}{D_q^p+\varepsilon}.
$$

- $\alpha_q$: 두 중심에 대한 상대 거리값.
- $\varepsilon$: 분모가 0이 되는 것을 방지하는 작은 수.

수식에서 직접 확인되는 의미는 다음과 같습니다.

- 긍정 중심에 더 가까우면 $\alpha_q>0$입니다.
- 부정 중심에 더 가까우면 $\alpha_q<0$입니다.
- 두 중심까지의 거리가 같으면 $\alpha_q=0$입니다.

이 값은 확률이 아닙니다. 또한 분모가 긍정 중심까지의 거리이므로 긍정·부정에 대해 대칭적인 점수도 아닙니다. [원문, p.5, 식 (5)에 대한 해석]

### 4.5 상대 거리로 라벨을 생성하는 방법

#### ① 비율과 차이에 대한 두 관계 — 원문 식 (6), (7)

저자는 다음 두 관계를 도입합니다.

$$
\frac{y_s}{y_m}
\propto
\frac{\hat y_s}{\hat y_m}
\propto
\frac{\alpha_s}{\alpha_m}
\quad\Rightarrow\quad
y_s=\frac{\alpha_s y_m}{\alpha_m}.
$$

$$
y_s-y_m
\propto
\hat y_s-\hat y_m
\propto
\alpha_s-\alpha_m
\quad\Rightarrow\quad
y_s=y_m+\alpha_s-\alpha_m.
$$

- $y_s,y_m$: 단일모달·멀티모달 목표값.
- $\hat y_s,\hat y_m$: 각 작업의 예측값.
- $\alpha_s,\alpha_m$: 각 경로의 상대 거리.
- $\propto$: 비례 관계.

**[저자 보고]** 식 (6)만 사용하면 $y_m=0$일 때 $y_s$도 항상 0이 되므로, 식 (7)을 함께 사용합니다. [원문, p.5]

**[해석]** 이 관계는 설계 직관입니다. 논문은 비례상수를 추정하거나 이 관계가 반드시 성립함을 증명하지 않습니다. 따라서 통계적 법칙이나 일반화 보장으로 받아들여서는 안 됩니다.

> **용어 설명**
>
> **휴리스틱(heuristic):** 엄밀한 최적성 증명보다 문제에 대한 직관과 경험을 바탕으로 설계한 규칙입니다.

#### ② 두 후보를 같은 비중으로 결합 — 원문 식 (8)

$$
\begin{aligned}
y_s
&=\frac{y_m\alpha_s}{2\alpha_m}
+\frac{y_m+\alpha_s-\alpha_m}{2}\\
&=y_m+
\frac{\alpha_s-\alpha_m}{2}
\frac{y_m+\alpha_m}{\alpha_m}\\
&=y_m+\delta_{sm}.
\end{aligned}
$$

여기서 보정값은 다음과 같습니다.

```math
\delta_{sm}
=
\frac{\alpha_s-\alpha_m}{2}
\frac{y_m+\alpha_m}{\alpha_m}.
```

- $\delta_{sm}$: 종합 라벨에 더하는 모달리티별 이동량.
- $\alpha_s-\alpha_m$: 단일모달과 멀티모달 경로의 상대 거리 차이.
- $1/2$: 식 (6)과 식 (7)의 후보를 같은 비중으로 평균하는 계수.

**직관:** 각 모달리티가 종합 표현과 다른 감성 방향을 보이면, 해당 모달리티의 목표값을 종합 정답에서 이동시킵니다. [원문, pp.4–5, Figure 2]

다만 다음 사항은 분명히 구분해야 합니다.

- **수치 안정성 미기재:** 식 (8)은 $\alpha_m$으로 나눕니다. 식 (5)의 $\varepsilon$이 있어도 $\alpha_m=0$이 될 수 있으며, 이 경우의 처리나 생성 라벨 범위 제한은 본문에 없습니다.
- **방향성의 조건:** 이동량의 부호는 $\alpha_s-\alpha_m$뿐 아니라 $(y_m+\alpha_m)/\alpha_m$에도 달려 있으므로, 그림의 예시를 모든 표본에 대한 보장으로 확대할 수 없습니다.
- **원문 기호 불일치:** 식 (8) 아래 설명에는 $\delta_{sm}$에 $\alpha_t$가 등장합니다. 위 식과 일반적인 $s\in\{t,a,v\}$에 맞추어 여기서는 $\alpha_s$로 통일했습니다. [원문, p.5]

### 4.6 생성 라벨의 누적 갱신 — 원문 식 (9)

원문의 괄호 유무에 따른 혼동을 줄이기 위해, 새 후보는 $\tilde y_s^{(k)}$, 누적 라벨은 $\bar y_s^{(k)}$로 표시하겠습니다.

```math
\bar y_s^{(k)}
=
\begin{cases}
y_m, & k=1,\\[4pt]
\displaystyle
\frac{k-1}{k+1}\bar y_s^{(k-1)}
+
\frac{2}{k+1}\tilde y_s^{(k)},
& k>1.
\end{cases}
```

- $k$: 현재 epoch.
- $\tilde y_s^{(k)}$: 현재 epoch에 식 (8)로 생성한 새 라벨.
- $\bar y_s^{(k-1)}$: 이전까지 누적한 라벨.
- $\bar y_s^{(k)}$: 갱신 후 사용할 라벨.
- 첫 epoch에서는 모든 단일모달 라벨을 $y_m$으로 초기화합니다.

저자가 제시한 바에 따르면, 총 $K$ epoch 후에는 epoch $k$에서 생성된 후보의 최종 기여 가중치가 다음과 같습니다.

$$
w_{k,K}=\frac{2k}{K(K+1)}.
$$

따라서 뒤에 생성된 라벨이 최종 누적값에서 더 큰 비중을 갖습니다. 다만 현재 새 라벨의 반영 계수 $2/(k+1)$ 자체는 학습이 진행될수록 작아집니다. [원문, p.5]

**[해석]** 이는 고정 계수를 사용하는 일반적인 지수이동평균과 다릅니다. 논문은 실험에서 라벨 분포가 안정되는 모습을 보고하지만, 임의의 라벨 생성 과정에 대한 수렴 정리를 제시하지는 않습니다.

> **용어 설명**
>
> **모멘텀 기반 갱신:** 과거 값과 현재 값을 섞어 급격한 변화를 완화하는 갱신 방식입니다. 여기서는 모델 파라미터가 아니라 생성 라벨에 적용합니다.

### 4.7 최종 손실과 자동 가중치 — 원문 식 (10)

표본 인덱스를 $j$로 정리하면 다음과 같습니다.

```math
\mathcal L
=
\frac{1}{N}
\sum_{j=1}^{N}
\left[
\left|\hat y_{m,j}-y_{m,j}\right|
+
\sum_{s\in\{t,a,v\}}
W_{s,j}
\left|\hat y_{s,j}-\bar y_{s,j}^{(k)}\right|
\right].
```

```math
W_{s,j}
=
\text{tanh}
\left(
\left|\bar y_{s,j}^{(k)}-y_{m,j}\right|
\right).
```

- $\mathcal L$: 전체 학습 손실.
- $N$: 학습 표본 수.
- $\hat y_{m,j},y_{m,j}$: 표본 $j$의 종합 예측값과 사람 정답.
- $\hat y_{s,j},\bar y_{s,j}^{(k)}$: 보조 작업의 예측값과 누적 생성 라벨.
- $W_{s,j}$: 표본별·보조 작업별 가중치.
- 절댓값 항: L1 손실.
- $\text{tanh}$: 입력이 커질수록 증가하다가 1에 가까워지는 함수.

**[저자 보고]** 종합 라벨과 다른 감성을 나타내는 표본에 보조 작업이 더 집중하도록 합니다. [원문, p.5, §3.4]

**[수식에서 확인되는 성질]**

- $0\le W_{s,j} < 1$입니다.
- 두 라벨이 같으면 가중치는 0입니다.
- 가중치는 작업 전체에 하나씩 적용하는 상수가 아니라 표본마다 다릅니다.
- 가중치의 합이 1이 되도록 정규화하지 않습니다.
- **라벨 차이를 측정하지만 생성 라벨의 정확성이나 신뢰도를 직접 측정하지는 않습니다.**

따라서 큰 차이가 유용한 감성 차이에서 발생했는지, 잘못 생성된 라벨에서 발생했는지를 이 가중치만으로 구분할 수 없습니다. [원문, 식 (10)에 대한 해석]

> **용어 설명**
>
> **L1 손실:** 예측값과 목표값의 절대 차이입니다. 예측 오차의 크기에 비례해 벌점을 줍니다.

### 4.8 실제 학습 순서

Algorithm 1을 정리하면 다음과 같습니다.

1. 모델과 표현 저장소를 초기화하고, 단일모달 라벨을 모두 종합 라벨로 설정합니다.
2. 각 미니배치에서 네 경로의 표현과 손실을 계산하여 모델 파라미터를 갱신합니다.
3. 첫 epoch 이후에는 클래스 중심·상대 거리로 새 단일모달 라벨을 생성하고 누적 갱신합니다.
4. 해당 표본의 저장 표현을 갱신하며 학습을 반복합니다.
5. 추론에서는 멀티모달 출력 $\hat y_m$을 사용합니다. [원문, p.4, Algorithm 1; p.3]

식대로라면 첫 epoch에는 단일모달 라벨과 종합 라벨이 같으므로 보조 손실 가중치가 0입니다. 또한 Algorithm 1의 13번째 줄은 갱신 대상을 $y_t,y_a,y_t$로 적고 있으며, 마지막 $y_t$는 문맥상 $y_v$의 오기로 보입니다.

> **용어 설명**
>
> **미니배치(minibatch):** 전체 학습 데이터 중 한 번의 파라미터 갱신에 사용하는 작은 묶음입니다.

## 5. 주요 결과와 정확한 해석

### 5.1 평가 지표를 먼저 구분해야 하는 이유

논문은 MAE, Pearson 상관계수, 이진 정확도, 가중 F1을 보고합니다. MOSI·MOSEI의 이진 평가에는 두 정의가 있습니다. [원문, p.6, §4.3]

| 표기 | 평가 기준 |
|---|---|
| 슬래시 왼쪽 | 부정 / 비부정: 정답 0을 포함 |
| 슬래시 오른쪽 | 부정 / 긍정: 정답 0을 제외 |

**슬래시 양쪽은 평가 표본과 범주 정의가 다르므로 서로 직접 비교하면 안 됩니다.**

> **용어 설명**
>
> - **MAE:** 예측값과 정답 사이의 평균 절대 오차로, 낮을수록 좋습니다.
> - **Pearson 상관계수(Corr):** 예측과 정답이 함께 증가·감소하는 정도로, 높을수록 좋습니다.
> - **Acc-2:** 두 감성 범주를 맞힌 비율입니다.
> - **가중 F1:** 범주별 정밀도·재현율을 결합한 F1을 범주별 표본 수에 따라 평균한 값입니다.

**[저자 보고]** Self-MM은 재현한 두 주요 비교 모델보다 대부분의 평가에서 좋은 결과를 보인다고 설명합니다. [원문, p.7, §5.1]

**[해석 및 원표에서 계산한 차이]**

- **MOSI:** MAG-BERT* 대비 MAE는 0.018 감소하고, 0 제외 정확도는 **1.68%p 증가**합니다.
- **MOSEI:** MAG-BERT* 대비 MAE는 0.009 감소하지만, 정확도는 0 포함 기준 **0.98%p**, 0 제외 기준 **0.06%p 낮습니다**.
- MOSEI의 F1 역시 0 포함에서는 1.21점 낮고, 0 제외에서는 0.22점 높습니다.

즉, **감성 강도의 회귀 성능 개선이 이진 분류 성능의 일관된 개선으로 이어지지는 않습니다.**

또한 Table 1 상단에 인용된 MAG-BERT 원보고값은 MOSI MAE **0.712**, 0 제외 정확도 **86.1**입니다. 따라서 Self-MM이 표에 포함된 **모든 기존 최고 수치를 갱신했다는 해석은 부정확합니다.** [원문, p.4, Table 1]

**비교 조건의 한계:** 저자는 별표 모델을 같은 조건에서 재현했다고 설명하지만, Table 1의 입력 설정은 Self-MM이 **비정렬**, MISA·MAG-BERT가 **정렬**입니다. 입력 정렬 조건까지 완전히 동일한 통제 비교는 아닙니다.

> **용어 설명**
>
> - **정렬된 입력(aligned):** 텍스트·음성·영상의 시간 단위를 서로 대응시킨 입력입니다.
> - **비정렬 입력(unaligned):** 모달리티마다 다른 길이나 시간 단위를 유지하는 입력입니다.
> - **%p:** 두 백분율의 산술적인 차이입니다.

### 5.3 SIMS: 사람의 단일모달 라벨을 얼마나 대체하는가?

| 모델 | MAE ↓ | Corr ↑ | Acc-2 ↑ | F1 ↑ |
|---|---:|---:|---:|---:|
| TFN | 0.428 | 0.605 | 79.86 | 80.15 |
| LMF | 0.431 | 0.600 | 79.37 | 78.65 |
| **Human-MM** | **0.408** | **0.647** | **81.32** | **81.73** |
| Self-MM | 0.419 | 0.616 | 80.74 | 80.78 |

[원문, p.6, Table 3]

Human-MM은 자동 생성 라벨을 사람이 부여한 단일모달 라벨로 교체한 비교 모델입니다. [원문, p.7, §5.1]

**[저자 보고]** Self-MM이 TFN·LMF보다 좋은 결과를 얻고, Human-MM과 비교할 만한 성능을 보인다고 설명합니다.

**[해석]** Self-MM은 Human-MM보다 MAE가 0.011 높고, 정확도는 0.58%p 낮습니다. **모든 보고 지표에서는 Human-MM이 더 좋습니다.** 이는 추가 주석 없이 근접한 최종 예측 성능을 얻었다는 근거이지만, 통계적 동등성을 입증한 결과는 아닙니다.

특히 **Table 3은 최종 멀티모달 예측을 비교한 표**입니다. 생성 라벨과 사람의 단일모달 라벨 사이의 직접적인 MAE·상관·부호 일치율은 보고하지 않습니다.

### 5.4 보조 작업은 많이 넣을수록 좋은가?

**그렇다고 결론 내릴 수 없습니다.** Table 4에서 다음이 관찰됩니다.

- 주 작업만 사용하면 0 제외 정확도가 83.67이고, 세 보조 작업을 모두 추가하면 85.98입니다.
- 영상 보조 작업만 추가하면 같은 정확도가 83.52로 낮아집니다.
- 멀티모달·텍스트·영상 작업 조합은 0 포함 정확도 84.26으로, 전체 작업 조합의 84.00보다 높습니다. [원문, p.7, Table 4]

**[저자 보고]** 텍스트·음성 보조 작업이 영상 보조 작업보다 더 도움이 되는 경향과, 일부 작업 조합이 전체 조합과 비슷하거나 더 좋은 결과를 보인다고 설명합니다. [원문, p.7, §5.2]

**원문 불일치:** Table 4의 오차 열 제목은 **MSE**이지만, 본문은 평가 지표로 **MAE**를 정의합니다. 마지막 행의 0.713이 Table 1 MOSI의 MAE와 일치하더라도 이를 임의로 수정해서는 안 됩니다. 표와 해당 설명에는 데이터셋명도 명시되어 있지 않으며, 전체 모델 행이 MOSI 결과와 일치한다는 점까지만 확인됩니다.

> **용어 설명**

> **용어 설명**
>
> **종단간 학습(end-to-end learning):** 입력 처리부터 최종 예측까지 연결된 모델을 목적에 맞게 함께 학습하는 방식입니다.

### 8.2 Self-MM의 후속 영향은 어디까지 확인되는가?

**직접 확인되는 영향 ①: 비교 기준으로 사용**

MMIM은 Self-MM을 주요 비교 모델로 포함하고 원보고값과 재현값을 별도 행으로 제시합니다. MOSI의 0 제외 정확도는 원보고 행에서 **85.98**, 재현 행에서 **84.77**입니다. 이는 Self-MM이 후속 연구의 비교 기준이 되었음을 보여주며, 동시에 같은 모델명이라도 실험 설정과 재현 과정에 따라 수치가 달라질 수 있음을 보여줍니다. [MMIM, PDF p.7, Table 2] [aclanthology.org](https://aclanthology.org/2021.emnlp-main.723.pdf?utm_source=chatgpt.com)

**직접 확인되는 영향 ②: ULGM의 추가 연구 가치**

LNLN 저자들은 Self-MM과 TETFN에서 사용하는 ULGM을 불완전 데이터의 모달리티 관계 학습에 유용할 수 있는 아이디어로 직접 언급합니다. 이는 후속 저자의 평가이며, 원 Self-MM이 결손 강건성을 입증했다는 의미로 바꾸어 해석해서는 안 됩니다. [LNLN, PDF p.10, §4.8; p.21, Appendix A.8] [proceedings.nips.cc](https://proceedings.nips.cc/paper_files/paper/2024/file/65a39213d7d0e1eb5d192aa77e77eeb7-Paper-Conference.pdf?utm_source=chatgpt.com)

### 8.3 일반화를 직접 평가한 최신 사례: TLRA

TLRA는 한 데이터셋에서 학습하고 다른 데이터셋에서 시험한 결과를 보고합니다.

| 학습 → 시험 | TLRA 정확도 | TLRA F1 |
|---|---:|---:|
| MOSEI → MOSI | 82.16 | 82.08 |
| MOSI → MOSEI | 79.91 | 80.11 |

[TLRA, PDF p.7, §4.4, Table 4] [IJCAI](https://www.ijcai.org/proceedings/2026/108?utm_source=chatgpt.com)

**[해석]** 이 실험은 Self-MM에 추가할 일반화 검증의 구체적인 사례입니다. 다만 TLRA는 정렬된 입력과 부정/비부정 이진 기준을 사용하며, 해당 교차 데이터셋 표에는 Self-MM이 없습니다. 따라서 위 수치를 Self-MM 원논문의 데이터셋 내부 성능과 비교해 모델 순위를 정할 수는 없습니다. [TLRA, PDF p.6, §4.1; p.7, Table 4] [ijcai.org](https://ijcai.org/proceedings/2026/0108.pdf?utm_source=chatgpt.com)

### 8.4 후속 연구에서 고려할 변화

**[분석자의 종합]** 선정한 연구를 통해 세 가지 비교 축을 얻을 수 있습니다.

1. **모달리티 고유 정보의 보존:** MISA·Self-MM의 핵심 문제의식입니다.
2. **정보의 유용성과 신뢰성 선별:** ALMT·LNLN이 강조하는 방향입니다.
3. **환경 변화에 대한 직접 검증:** MISR의 불변성 학습 목표와 TLRA의 교차 데이터셋 실험을 구분하여 평가해야 합니다.

후속 실험에서는 구현·평가 코드 버전도 확인해야 합니다. 실제로 LNLN 공식 저장소는 **그 논문의 비교 실험에서 보고한 SIMS F1 일부의 과대 계산과 MOSEI의 TETFN 결과 오류**를 정정·안내하고 있습니다. 이는 ALMT 원논문의 모든 수치를 정정한다는 의미가 아니라, LNLN 평가에 포함된 해당 결과에 대한 안내입니다. [공식 저장소, *Corrigendum*] [GitHub](https://github.com/Haoyu-ha/LNLN?utm_source=chatgpt.com)

## 9. 결론·시사점·빠른 후속 검증 제안

### 9.1 저자가 제시한 결론과 후속 계획

**[저자 보고]** Self-MM은 추가적인 사람의 단일모달 라벨 없이 보조 감독을 생성하여 모달리티 고유 표현을 학습하는 관점을 제안합니다. 저자는 생성 라벨의 안정성과 유용성을 실험으로 뒷받침했다고 평가하며, 다음 연구를 계획합니다.

- 전처리 특징의 제약을 줄일 종단간 멀티모달 네트워크 구축.
- 단일모달 학습과 멀티모달 학습의 관계 탐구. [원문, p.7, §6]

### 9.2 학술적·실용적 시사점

**[해석] 학술적 의미:** 멀티모달 표현 학습에서 **어떻게 융합할 것인가와 함께, 각 모달리티에 어떤 목표를 줄 것인가를 연구해야 한다는 문제를 구체적인 수식과 실험으로 제시**했습니다. 특히 공동 작업의 종합 정답을 모든 보조 작업에 그대로 적용할 필요가 없다는 점이 중요합니다. [원문, pp.3–5]

**[해석] 실용적 의미:** 이미 종합 감성 라벨이 있는 데이터에서 추가 단일모달 주석 없이 보조 학습을 구성할 수 있습니다. 그러나 실제 비용 절감량, 배포 환경의 성능, 결손 입력 대응은 별도 검증이 필요합니다. [원문, p.6, Table 3; p.7, §6]

**일반화 관점에서의 핵심 검증 질문은 다음과 같습니다.**

> 자동 생성한 모달리티별 감독이 데이터셋에 특화된 단서를 강화하는가, 아니면 환경이 바뀌어도 유용한 감성 정보를 학습하게 하는가?

원논문은 이 질문의 두 가능성을 구별할 실험을 제공하지 않습니다. 따라서 후속 연구에서는 전체 평균 성능뿐 아니라 **교차 데이터셋 성능, 결손 조건별 성능, 라벨 신뢰도**를 함께 평가해야 합니다.

### 9.3 가장 유망한 접근과 빠른 검증 순서

아래는 **원논문의 보고 결과가 아니라 추가 실험 제안**입니다. 성능 향상 수치를 예상하지 않고, 작은 실험으로 핵심 가정을 확인하는 데 초점을 둡니다.

| 우선순위 | 검증할 아이디어 | 간단한 실험 | 확인할 핵심 질문 |
|---|---|---|---|
| **1** | ULGM의 라벨 생성 | SIMS에서 생성 라벨과 사람 단일모달 라벨의 MAE·상관·부호 일치율 측정 | 생성 라벨이 종합 라벨을 복사한 것보다 실제 단일모달 감성을 잘 반영하는가? |
| **2** | 서로 다른 보조 감독 | 같은 작은 융합 모델에서 주 작업만 / 종합 라벨을 복사한 보조 작업 / ULGM 보조 작업 비교 | 이득이 보조 작업 추가 때문인가, 서로 다른 라벨 때문인가? |
| **3** | 누적 갱신과 차이 가중치 | 누적 갱신 유무와 상수 가중치/원문 가중치를 교차 비교 | 안정화와 가중치가 각각 성능·변동성에 기여하는가? |
| **4** | 일반화 가능성 | 부분 정보 삭제, 전체 모달리티 결손, MOSI↔MOSEI 전이를 별도로 평가 | 어떤 환경 변화에서도 효과가 유지되고, 어디에서 실패하는가? |

**첫 단계는 SIMS의 저장 특징과 작은 투영·융합 모델로 시작할 수 있습니다.** 이렇게 얻은 결과는 원논문 전체 재현과 구별하고, 핵심 가정이 지지될 때 더 큰 인코더나 종단간 모델로 확장하는 것이 적절합니다.

검증 설계에서 특히 중요한 사항은 세 가지입니다.

1. **같은 종합 라벨을 사용하는 보조 작업의 가중치는 상수로 두어야 합니다.**  
   원문의 $W_s=\text{tanh}(|y_s-y_m|)$를 그대로 적용하면 $y_s=y_m$일 때 가중치가 0이 되어 보조 작업이 사라집니다.

2. **라벨의 집계와 개별 표본의 변화를 함께 측정해야 합니다.**  
   긍정·부정 개수뿐 아니라 동일 표본의 epoch별 라벨 변화량과 사람 라벨 일치도를 확인해야 합니다.

3. **시험 데이터의 정답을 라벨 생성이나 클래스 중심 갱신에 사용하지 않아야 합니다.**  
   원문의 $N$은 학습 표본 수입니다. 교차 데이터셋 평가에서도 대상 시험 데이터의 정답을 사용하면 일반화 검증의 의미가 사라집니다.

반복 실험에서는 평균과 변동성을 함께 보고하고, 가능한 경우 영상·화자 단위를 고려한 신뢰구간을 제시하는 것이 좋습니다.

**우선 검증할 기술은 ULGM 자체입니다.** 모달리티별 라벨을 자동으로 만든다는 핵심 아이디어가 직접적인 라벨 품질 평가를 통과한 뒤, 누적 갱신·가중치·불변성 또는 결손 대응 기법의 결합을 검토하는 순서가 가장 명확한 연구 경로입니다.
