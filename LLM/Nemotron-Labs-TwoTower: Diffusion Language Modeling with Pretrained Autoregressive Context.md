# Nemotron-Labs-TwoTower: Diffusion Language Modeling with Pretrained Autoregressive Context

> **⚠️ 중요 고지**: 본 분석은 제공된 PDF(arXiv:2606.26493v2, 2026년 6월 29일)만을 근거로 작성되었습니다. 논문에 명시되지 않은 내용은 추정임을 명시하며, 확인 불가능한 수치는 별도 표시합니다.

## 1. Executive Summary (10문장 이내)

Nemotron-Labs-TwoTower는 자기회귀(AR) 언어 모델의 순차적 디코딩 병목 문제를 해결하기 위해 제안된 두 탑(Two-Tower) 구조의 이산 확산 언어 모델이다.  
핵심 아이디어는 컨텍스트 표현과 반복적 노이즈 제거라는 두 역할을 단일 네트워크에 강제하는 기존 방식의 한계를 극복하는 것이다.  
동결된 AR 컨텍스트 타워와 학습 가능한 확산 디노이저 타워로 역할을 분리하여, 사전학습된 표현을 재활용하면서 병렬 블록 생성을 가능하게 한다.  
베이스 모델로는 Nemotron-3-Nano-30B-A3B(Mamba-2, Attention, MoE 혼합 52층 구조)를 사용하며, 약 2.1T 토큰으로 디노이저만 학습한다.  
레이어-정렬 크로스-어텐션(layer-aligned cross-attention)과 컨텍스트 시드 Mamba 상태를 통해 두 타워를 연결한다.  
마스크 확산 ELBO 목적함수로 학습하며, 신뢰도 기반 언마스킹(confidence unmasking) 샘플러로 추론한다.  
AR 베이스라인 품질의 98.7%를 유지하면서 벽시계 처리량을 2.42배 향상시켰다.  
어블레이션 실험을 통해 양방향 어텐션, adaLN 시간 조건화, 인과적 Mamba, 블록 크기 S=16이 최적 설계임을 확인하였다.  
컨텍스트 타워를 동결하고 디노이저만 독립적으로 학습하는 완전 분리 전략이 공동 학습(joint loss) 방식보다 우수함을 실험적으로 검증하였다.  
모델 가중치, 학습 코드, 레시피를 공개하였으며 향후 포스트 트레이닝 버전 추가를 계획하고 있다.

### 1-1. 연구의 목적과 필요성

**문제 배경**: AR 언어 모델은 토큰을 하나씩 순차 생성하는 구조적 특성으로 인해 처리량(throughput) 병목이 발생한다.

**기존 확산 언어 모델의 한계**: 기존 이산 확산 모델(예: MDLM, SEDD)은 단일 네트워크가 (1) 클린 토큰의 컨텍스트 표현, (2) 노이즈 토큰의 반복 디노이즈라는 서로 상충하는 두 역할을 동시에 수행해야 하므로, 동일한 가중치가 서로 다른 방향으로 당겨져 두 역할 모두에서 한계를 보인다.

**필요성 요약**:

| 필요성 | 설명 |
|--------|------|
| 처리량 향상 | AR의 순차 생성 병목 극복 |
| 역할 분리 | 컨텍스트 표현 ↔ 디노이징의 최적화 충돌 해소 |
| 대규모 검증 | 기존 최대 1.7B 실험을 30B 하이브리드 MoE로 확장 |
| 사전학습 활용 | 전체 재학습 없이 기존 AR 모델 재사용 |

## 2-1. 상세 설명

### 해결하고자 하는 문제

기존 단일 디코더 확산 언어 모델의 **역할 충돌 문제(role entanglement)**:
- 클린 토큰 표현(AR 역할): 인과적(causal), 결정론적
- 노이즈 토큰 디노이징(확산 역할): 양방향(bidirectional), 확률론적

같은 가중치로 두 역할을 동시에 최적화하면 목적함수가 서로 충돌한다.

### 제안하는 방법 (수식 포함)

**블록-자기회귀 분포 모델링** (Eq. 2, p.4):

$$\log p_\theta(\mathbf{x}) = \sum_{b=1}^{B} \log p_\theta(\mathbf{x}_b \mid \mathbf{x}_{<b})$$

각 블록 $\mathbf{x}_b = (x_b^1, \ldots, x_b^S)$는 마스크 확산 과정으로 모델링된다.

**전방 과정(Forward Process)** (Eq. 3, p.4):

$$q(\mathbf{z}_t^{b,\ell} \mid x_b^\ell) = \text{Cat}\!\left(\mathbf{z}_t^{b,\ell};\; \alpha_t \delta_{x_b^\ell} + (1-\alpha_t)\mathbf{m}\right)$$

- $\alpha_t = 1 - t$: 선형 스케줄 (클린 토큰이 마스킹되지 않을 확률)
- $\mathbf{m}$: [MASK] 토큰의 point mass
- $t$ 증가 → 완전 마스킹, $t$ 감소 → 경미한 오염

**학습 목적함수 (마스크 확산 ELBO)** (Eq. 4, p.4):

$$\mathcal{L}_{\text{MD}} = \mathbb{E}_{t,\mathbf{z}_t}\!\left[\frac{1}{|\mathcal{M}_t|}\sum_{(b,\ell)\in\mathcal{M}_t} -\log p_\theta\!\left(x_b^\ell \mid \mathbf{z}_t^b, t, \mathbf{c}_{<b}\right)\right]$$

- $\mathcal{M}_t = \{(b, \ell) : z_t^{b,\ell} = \text{[MASK]}\}$: 마스킹된 위치 집합
- 이론적 가중치 $1/t$ 생략(학습 안정성)

**레이어-정렬 크로스-어텐션** (Eq. 1, p.3):

$$\text{Attn}\!\left(\mathbf{Q}_b^{(i)},\; [\mathbf{K}_{<b}^{\text{ctx},(i)};\; \mathbf{K}_b^{\text{den},(i)}],\; [\mathbf{V}_{<b}^{\text{ctx},(i)};\; \mathbf{V}_b^{\text{den},(i)}]\right)$$

디노이저 레이어 $i$가 컨텍스트 타워의 동일 인덱스 레이어 $i$의 KV에 어텐션.

**컨텍스트 조건** (p.4):

$$\mathbf{c}_{<b} = (\text{KV}_{<b},\; \text{States}_{b-1})$$

### 모델 구조

```
┌─────────────────────────────────────────────────────────┐
│          Nemotron-Labs-TwoTower 구조                     │
├─────────────────────┬───────────────────────────────────┤
│   AR Context Tower  │      Diffusion Denoiser Tower      │
│   (동결, Frozen)    │      (학습 가능, Trainable)        │
├─────────────────────┼───────────────────────────────────┤
│ • 인과적 자기어텐션 │ • 양방향 블록 자기어텐션          │
│ • Mamba-2 (23층)    │ • 레이어-정렬 크로스-어텐션       │
│ • MoE (23층)        │ • 컨텍스트-시드 Mamba 상태         │
│ • Self-Attn (6층)   │ • adaLN 시간 조건화 (+1.5M param) │
│ • KV 캐시 생성      │ • 동일 MoE 라우팅 메커니즘        │
│ • Mamba 상태 노출   │                                    │
└─────────────────────┴───────────────────────────────────┘
         ↕ 레이어-정렬 상태 전달 (KV + Mamba States)
```

**백본**: Nemotron-3-Nano-30B-A3B (52층: Mamba-2 23 + Self-Attn 6 + MoE 23)

**학습 설정**:
- 배치 정밀도: BF16
- 옵티마이저: AdamW
- LR 스케줄: WarmupStableDecay (최대 $1\times10^{-4}$, 최소 $1\times10^{-6}$)
- 블록 크기: $S=16$ (기본값)
- 학습 토큰: ~2.1T (백본 사전학습 25T의 약 8.4%)

### 성능 향상

| 지표 | AR 베이스라인 | TwoTower | 변화 |

### 한계

1. **메모리 오버헤드**: 두 타워의 가중치를 동시에 메모리에 유지해야 함 (30B × 2 구조)
2. **블록 크기 의존성**: 학습-추론 블록 크기 불일치 시 성능 급락 (Table 4)
3. **좌→우 편향 지속**: Mamba의 인과적 구조로 인한 좌→우 순서 편향이 내부 블록에서도 관측됨
4. **코드 태스크 품질 저하**: HumanEval 등 코드 생성에서 상대적으로 큰 품질 하락
5. **단일 하드웨어 환경**: 2×H100에서만 평가됨 (다양한 하드웨어 일반화 미검증)

## 7. 가장 중요한 그림 5개 해석

### Figure 1 (p.2): 전체 아키텍처 및 품질-처리량 곡선

**(a) 두 타워 아키텍처**

동결된 AR 컨텍스트 타워(좌)가 클린 토큰을 인과적으로 처리하여 KV 캐시와 Mamba 상태를 생성하고, 이를 훈련 가능한 확산 디노이저 타워(우)에 레이어별로 전달한다. [M] 토큰으로 초기화된 블록이 $T$회 반복 정제되는 과정이 시각화되어 있다. 레이어 정렬 구조($\times T$)가 핵심이며, 같은 인덱스의 레이어끼리 상태를 공유함으로써 표현 수준의 정합성을 확보한다.

**(b) 품질-처리량 Pareto 곡선**

신뢰도 임계값 $\gamma$와 디노이징 스텝 $T$를 변화시키며 그린 Pareto 곡선으로, General Knowledge, Math, Code, Generative, All Tasks 5개 카테고리를 보여준다. $\gamma=0.8$, $S=16$의 기본 동작점이 98.7% 품질/2.42× 처리량으로 표시된다. 처리량 3×를 넘어서면 품질 하락이 급격해지며, 특히 Code 태스크가 가장 먼저 하락하는 패턴을 보인다.

---

### Figure 2 (p.6): 카테고리별 성능 비교

Nemotron-3-Nano AR 베이스라인(진한 색)과 TwoTower(밝은 색)의 카테고리별 정확도와 처리량을 나란히 제시한다. 주목할 점은:
- **다국어(Multilingual) 77.4→80.4**: TwoTower가 AR을 **능가**하는 유일한 카테고리 (블렌드 구성의 효과로 추정되나 원인 불명 ⚠️)
- **코드 77.0→74.9**: 가장 큰 절대 하락폭
- **처리량**: 생성 태스크(Generative)에서 2.42× 달성 (다지선다형 태스크는 병렬화 이득이 다름)

이 그림은 단일 집계 수치 98.7%가 태스크 간 불균등한 성능 분포를 숨기고 있음을 보여준다.

---

### Figure 3 (p.9): 샘플링 동역학 - 블록 완료와 위치별 커밋

**(a) 블록 완료 × 디노이징 스텝 (GSM8K vs MMLU-Pro)**

GSM8K(수학)는 초기 스텝(1-3)에 블록의 높은 비율이 완료되는 반면, MMLU-Pro는 중후반 스텝에도 상당한 질량이 남아 있다. 이는 수학 문제가 어느 정도 결정론적 패턴을 가지는 반면, 복잡한 지식 추론은 더 많은 반복 정제가 필요함을 시사한다.

**(b) 위치 × 디노이징 스텝 히트맵 (GSM8K, 로그 스케일)**

상단-좌측 삼각형 패턴: 블록 내 앞쪽 위치(position 1-5)가 초기 스텝에 커밋되고, 뒤쪽 위치(position 12-16)가 후기 스텝까지 남는다. 이는 사전학습된 AR 백본의 **좌→우 귀납적 편향**이 확산 디노이저에도 전이됨을 보여주며, 완전한 병렬 생성이라기보다 부분적 순차성이 남아 있음을 의미한다.

---

### Figure 4 (p.10): 디노이징 스텝별 평균 커밋 토큰 수

6개 태스크(MMLU Pro, MBPP-Sanitized, HumanEval, MATH-500, GSM8K, MGSM)에 걸쳐 일관되게 **첫 번째 디노이징 스텝에서 가장 많은 토큰이 커밋**되고 이후 급격히 감소하는 패턴을 보인다. 평균값은 태스크별로 MGSM 4.87, MBPP-Sanitized 4.24, MMLU Pro 3.73 등으로 AR의 1 토큰/스텝과 비교할 때 초기에 다수 토큰을 병렬 커밋하는 전략이 처리량 향상의 핵심 메커니즘임을 실증한다.

**해석**: 만약 평균 4토큰/스텝이 첫 스텝에 커밋된다면, 나머지 스텝들이 소수 잔여 토큰만 처리해도 전체 블록을 완성할 수 있으므로, 총 디노이징 스텝 수($T=16$)가 있어도 유효 처리량은 AR 대비 수 배 향상된다.

---

### Figure 7 (p.15): 전체 생성 블록에 걸친 위치-스텝 커밋 분포

Figure 3b의 GSM8K 한정 분석을 6개 태스크 전체 생성 블록으로 확장한 히트맵(정규화, 로그 스케일). **모든 태스크에서 상단-좌측 삼각형 패턴이 재현**되며, 태스크에 따라 패턴의 강도(명확성)가 다르다:
- **MBPP-Sanitized, GSM8K**: 매우 뚜렷한 삼각형 (높은 좌→우 편향)
- **MMLU Pro, MATH-500**: 더 분산된 패턴 (더 복잡한 의존 관계)
- **MGSM**: 중간 정도

이 그림은 TwoTower가 진정한 무순서 병렬 생성이 아닌, **순서적 특성을 내재화한 준-순차적(quasi-sequential) 생성**을 수행함을 전체적으로 보여준다.

## 8. 결론, 시사점 및 후속 연구

### 8-1. 저자 제시 시사점 및 후속 연구 계획

**저자 제시 시사점** (p.10-11):

1. **실용적 확산 디코딩 적응 가능성**: 마스크 확산이 대규모 사전학습 AR 모델(하이브리드 MoE 포함)의 실용적 디코딩 적응 방법으로 기능할 수 있음
2. **컨텍스트 타워 동결의 중요성**: 동결된 AR 표현이 훈련 가능한 디노이저를 위한 강력한 기반 역할 수행
3. **설계 원칙 확립**: 양방향 어텐션 + 인과적 Mamba + adaLN + 적절한 블록 크기가 최적 조합
4. **가중치/코드 공개**: 재현성 및 커뮤니티 활용을 위한 공개

**저자 발표 후속 계획** (p.11):

> "In future updates, we plan to add **post-trained Nemotron-Labs-TwoTower models** to the same collection."

즉, 명령어 튜닝 및 RLHF 버전 추가가 예정되어 있으나, 구체적 타임라인이나 방법론은 미공개.

### 모델의 일반화 성능 향상 가능성 (8-1 중점)

**현재 일반화의 한계**:

1. **아키텍처 단일성**: Nemotron-3-Nano-30B-A3B 단일 모델만 검증됨. 저자들은 "TwoTower is a general approach that can be applied to any pretrained AR model"이라 주장하나(p.2), 이는 실증적으로 미검증임 ⚠️

2. **도메인 일반화**: 학습 데이터가 Nemotron-3-Nano 사전학습 혼합의 일부이며, 의료·법률·과학 등 특수 도메인에서의 성능 미검증

3. **블록 크기 일반화 실패**: Table 4에서 학습-추론 블록 크기 불일치 시 catastrophic 성능 하락이 관측됨 (HumanEval: 76.40→19.85). 이는 현재 모델이 블록 크기에 강하게 의존함을 의미

**일반화 향상 가능 방향 (필자 제안)**:

| 전략 | 설명 | 기대 효과 |
|------|------|-----------|
| 멀티-블록 크기 학습 | 학습 시 다양한 $S$ 값을 샘플링하여 랜덤화 | 추론 시 블록 크기 유연성 확보 |
| 레이어-적응형 크로스-어텐션 | 단순 인덱스 정렬 대신 학습된 레이어 매핑 | 다른 AR 모델 아키텍처로의 이식성 향상 |
| 도메인 특화 Phase-3 학습 | 타겟 도메인 데이터로 추가 미세조정 | 도메인 일반화 |
| 경량 Context Tower 적응 | LoRA로 컨텍스트 타워 부분 적응 | 새로운 도메인에서의 표현 업데이트 |
| 다양한 백본 검증 | LLaMA-3, Mistral 등에 적용 실험 | 아키텍처 독립성 검증 |

#### TwoTower의 차별성 (논문 내 근거 기반)

1. **스케일**: 1.7B(Arriola 2025b) → 30B로의 확장, 하이브리드 Mamba-MoE에서 검증
2. **완전 분리**: 가중치 공유(tied weights) 없는 완전한 역할 분리 (Table 2에서 공유 시 -27%의 급락 입증)
3. **레이어-정렬 크로스-어텐션**: 최종 히든 스테이트 방송이 아닌 레이어별 KV 캐시 활용
4. **컨텍스트-시드 Mamba 상태**: SSM 레이어의 블록 경계 상태 전달 (새로운 기법)
5. **사전학습 활용 효율성**: 25T 대비 ~2.1T(약 8%)만으로 98.7% 품질 회복

#### 앞으로의 연구에 미치는 영향

**긍정적 영향**:

1. **AR 모델 재활용 패러다임 확립**: 기존 수십 조 토큰으로 학습된 AR 모델을 확산 모델로 적은 비용으로 변환하는 실용적 레시피 제공
2. **하이브리드 아키텍처에서의 확산 적용 검증**: Mamba + Attention + MoE 혼합 구조에서도 마스크 확산이 작동함을 보임
3. **역할 분리 원칙의 실증**: 컨텍스트 표현과 디노이징의 분리가 스케일에서도 유효함을 실험적으로 확인

**향후 연구 시 고려할 점**:

| 고려 사항 | 설명 |
|-----------|------|
| **메모리 효율화** | 60B 파라미터(2×30B)를 실제 배포 시 어떻게 관리할지. Knowledge Distillation이나 컨텍스트 타워의 양자화 가능성 탐색 |
| **좌→우 편향 제어** | 현재 확산 모델임에도 순서 편향이 강하게 나타남. 진정한 병렬 생성을 위한 Mamba 이상의 개선 필요 |
| **학습-추론 블록 크기 불일치 문제** | 블록 크기 의존성이 너무 강해 런타임 유연성이 제한됨. 멀티-스케일 학습 탐색 필요 |
| **포스트 트레이닝 적합성** | RLHF, DPO 등 정렬 기법이 확산 디노이저에 어떻게 적용될지 미지수. 저자들도 이를 계획 중 |
| **이론적 보장** | 중요도 가중치 $1/t$ 생략이 실용적으로 안정적임은 보였으나, 이론적 ELBO 하한 보장이 없음 |
| **타 AR 모델 이식성** | "범용 접근법"이라는 주장을 LLaMA, Mistral 등 순수 트랜스포머에서 실증 검증 필요 |
