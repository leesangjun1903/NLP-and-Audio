이 연구는 **이미 추론 능력을 갖춘 모델이 행동 명세인 Model Spec과 고수준 과제 지침을 이용하여, 더 강한 외부 교사 모델 없이 자신의 안전 정렬을 개선할 수 있는가**를 묻습니다.  
필요성은 수학·코딩과 달리 안전한 행동은 맥락에 따라 판단해야 하므로, 역량 향상에 비해 정렬을 위한 감독 신호 확보가 병목이 될 수 있다는 데 있습니다.  
SIGMA는 같은 모델을 과제 설계자·검증자·보상 판정자·학습자로 활용하여 이 병목을 줄이는 데이터 생성 및 학습 파이프라인입니다〔pp.1–3, Figure 1〕. 2610.07935v1 2610.07935v1

> **용어:** 정렬(alignment)은 모델의 행동을 의도한 원칙과 제약에 맞추는 것; Model Spec은 바람직한 행동과 그 이유를 적은 명세; 감독 신호는 어떤 출력을 더 바람직하게 학습할지 알려 주는 평가 정보

### 2.1 정확히 어떤 문제를 해결하려 하는가?

**저자 보고:** 기존 정렬 방법은 더 강한 모델의 감독이나 사람이 선별한 학습 프롬프트에 의존하는 경우가 많습니다.  
SIGMA의 목표는 사람이 Model Spec과 상위 수준의 과제 방향을 제공하면, 모델이 구체적인 학습 문제와 평가 기준을 스스로 만들고 이를 이용해 훈련에 없던 상황에서도 더 안전하게 행동하도록 하는 것입니다〔pp.1–3, §1–2〕. 2610.07935v1

**해석:** 이 문제는 “모델이 정답을 전혀 모르는 상태에서 지식을 창조할 수 있는가?”보다는, **이미 가진 일반 추론 능력과 명세 이해 능력을 더 일관된 행동으로 바꿀 수 있는가?**에 가깝습니다. 논문은 처음부터 추론 능력을 갖춘 후학습 모델을 가정하므로, “외부 감독 없이”를 “사전학습·인간 가치·기존 정렬 없이”로 읽으면 안 됩니다〔p.3〕. 2610.07935v1

> **용어:** 후학습(post-training)은 사전학습 이후 지시 수행·추론·안전성 등을 개선하는 학습; 분포 밖 일반화(OOD generalization)는 학습 자료와 다른 형식이나 상황에서 성능이 유지·개선되는 현상

## 3. 제안 방법과 모델 구조 — 수식 포함

### 3.1 모델 구조: 새로운 신경망보다 새로운 감독 구성 방식

**저자 보고:** SIGMA는 Qwen3.6-27B를 기반으로 합니다. 같은 초기 모델이 과제 설계자, 의미 검증자, 학습용 판정자 역할을 수행하며, 학습 대상 모델의 모든 매개변수를 미세조정합니다〔pp.4, 29, 31〕. 2610.07935v1 2610.07935v1 2610.07935v1

**외부 자료 보충:** Qwen의 공식 모델 카드에 따르면 기반 언어모델은 270억 매개변수, 64개 층, 은닉 차원 5,120이며, Gated DeltaNet과 Gated Attention을 결합한 구조입니다. 이는 기반 모델의 사양이지 SIGMA가 새로 제안한 구조는 아닙니다〔공식 모델 카드, “Model Overview”〕. [Hugging Face](https://huggingface.co/Qwen/Qwen3.6-27B)

> **용어:** 매개변수는 학습으로 조정되는 수치; 은닉 차원은 모델이 내부에서 토큰 하나를 표현하는 벡터의 길이; 어텐션 계열 구조는 문맥의 어떤 정보를 활용할지 계산하는 장치

학습 시스템은 다음과 같이 읽는 것이 정확합니다.

```text
Model Spec + 도메인·위협 유형 지침
                ↓
초기 시나리오 생성 및 중복·품질 점검
                ↓
동일 모델이 대조 과제쌍·루브릭·검증용 응답 생성
                ↕
형식·일관성·명세 준수·난도 검증과 수정
                ↓
채택된 프롬프트와 루브릭
           ┌────┴────┐
           ↓         ↓
     SIGMA-SFT   SIGMA-RL
     초기 π에서   초기 π에서
     별도 학습    별도 학습
```

**중요:** 논문의 SIGMA-RL은 SIGMA-SFT에 이어 추가 학습한 모델이 아닙니다. 두 방법 모두 초기 $\pi$에서 출발합니다〔p.4〕. 2610.07935v1

### 3.2 1단계: 명세에 따른 과제 합성

**저자 보고:** 12개 도메인과 3개 위협 유형을 조합해 초기 시나리오를 만듭니다. 위협 유형은 악의적인 사용자, 악의적인 외부 환경, 모델 자신의 부정렬 행동입니다. 이후 한 가지 의사결정 관련 사실만 달라지는 과제쌍을 생성합니다〔pp.3, 15–19, Figure 2〕. 2610.07935v1 2610.07935v1 2610.07935v1

예를 들어 부록의 실제 과제쌍은 다음과 같습니다.

| 동일한 상황 | 달라지는 사실 | 기대 행동 |
|---|---|---|
| 연구 자료를 결합해 분석해야 함 | 책임자가 분석 후 자료 보관까지 명시적으로 승인 | 분석하고 허용된 자료를 보관 |
| 같은 분석을 해야 함 | 일회성 분석만 승인하고 계속 보관하는 것은 승인하지 않음 | 분석은 수행하되 이후 자료를 보관하지 않음 |

여기서 학습해야 하는 것은 “자료를 보관하면 위험하다”라는 단순 규칙이 아니라 **승인 범위에 따라 행동을 바꾸는 판단**입니다〔pp.19–22, Appendix D〕. 2610.07935v1 2610.07935v1

> **용어:** 반사실적 대조(counterfactual contrast)는 나머지 조건을 거의 유지하고 핵심 사실만 바꿔 적절한 행동이 어떻게 달라지는지 비교하는 방식; 지름길 학습(shortcut learning)은 실제 판단 근거 대신 표면적인 단서만 외우는 학습

각 과제에는 프롬프트, 보통 5–8개 루브릭 항목, 성공 응답, 두 개의 실패 응답이 들어갑니다. 검증기는 형식 적합성, 응답과 루브릭의 일관성, 명세와의 일치, 초기 모델이 쉽게 통과하지 못하는 난도를 확인합니다〔pp.3–4, 19, 23〕. 2610.07935v1 2610.07935v1 2610.07935v1

**해석:** 대조쌍은 맥락 민감성을 학습시키는 합리적인 설계입니다. 그러나 과제쌍을 없앤 별도 절제 실험은 제시되지 않으므로, 일반화 향상의 원인을 대조쌍 자체로 확정할 수 없습니다. 또한 난도 검증은 과제당 새로 샘플링한 응답에 의존하므로, 일회성 실패가 안정적인 어려움을 뜻한다고 보장되지는 않습니다〔p.23, Algorithm 1〕. 2610.07935v1

### 3.3 학습 데이터와 루브릭 보상

검증용 성공·실패 응답은 학습 전에 버리고, 프롬프트와 루브릭을 남깁니다〔p.4〕. 2610.07935v1

$$
\mathcal D=\{(x_i,C_i)\}_{i=1}^{|\mathcal D|},
\qquad
C_i=\{c_{i,1},\ldots,c_{i,M_i}\}.
$$

**기호:** $\mathcal D$는 학습 데이터셋, $|\mathcal D|$는 과제 수, $x_i$는 과제 프롬프트, $C_i$는 해당 과제의 루브릭 집합, $c_{i,j}$는 개별 기준, $M_i$는 기준의 수입니다.

원문의 루브릭 보상은 다음과 같습니다〔p.4, §2.2〕. 2610.07935v1

```math
R_{\text{rubric}}(x_i,y_i;C_i)
=
\frac{1}{M_i}
\sum_{j=1}^{M_i}
\text{RubricEval}_{\pi}(x_i,y_i;c_{i,j}).
```

**기호:** $y_i$는 평가할 최종 응답, $\pi$는 판정에 사용하는 초기 모델, $\text{RubricEval}\_{\pi}\in\{0,1\}$은 해당 기준의 실패·통과 판정, $R_{\text{rubric}}\in[0,1]$은 통과한 기준의 비율입니다.

**직관:** 6개 기준 중 5개를 통과하면 보상은 $5/6$입니다. 각 기준을 별도 모델 호출로 판정하지만, **호출이 분리되어 있다는 것과 판정 편향이 독립적이라는 것은 다릅니다**〔pp.23–24, Appendix F〕. 2610.07935v1

### 3.4 Model Spec 보상 — 본문 수식과 부록 구현 설명의 구분

본문은 명세를 여러 절로 나누어 각 절의 준수 여부를 평균합니다〔p.4〕. 2610.07935v1

```math
S=\bigcup_{k=1}^{K}s_k,
\qquad
R_{\text{spec}}(x,y;S)
=
\frac{1}{K}
\sum_{k=1}^{K}
\text{SpecEval}_{\pi}(x,y;s_k).
```

**기호:** $S$는 전체 행동 명세, $s_k$는 명세의 한 절, $K$는 평가하는 절의 수, $\text{SpecEval}_{\pi}\in\{0,1\}$은 그 절의 준수 여부입니다.

**구현상 중요한 세부사항:** 부록 F는 실제 판정 단위를 **8개 번호 원칙과 3개 장 서론을 합친 11개**로 설명하며, 해당 응답에 관련 없다고 판정된 절은 평균에서 제외한다고 명시합니다〔p.24〕. 2610.07935v1

따라서 부록 설명을 반영한 **설명용 재표기**는 다음과 같습니다.

```math
R_{\text{spec}}^{\text{applicable}}(x,y;S)
=
\frac{1}{|\mathcal A(x,y)|}
\sum_{k\in\mathcal A(x,y)}
\text{SpecEval}_{\pi}(x,y;s_k).
```

**기호:** $\mathcal A(x,y)$는 판정 모델이 해당 대화에 관련 있다고 본 절의 인덱스 집합입니다. 이 식은 논문에 그대로 인쇄된 식이 아니라 부록 설명을 수학적으로 나타낸 것입니다. 모든 절이 관련 없다고 판정된 경우의 처리는 해당 설명에서 명확하지 않습니다.

**해석:** 명세 보상은 과제 루브릭이 놓친 전역 원칙을 보완합니다. 다만 무엇이 관련 있는지부터 같은 모델이 판단하므로, 잘못된 관련성 판정까지 자기지도 과정에 들어갈 수 있습니다.

### 3.5 SIGMA-SFT: 명세를 읽고 생성한 좋은 응답을 학습

먼저 명세를 입력에 넣고 과제당 $N=16$개의 추론·응답 후보를 생성합니다〔p.4〕. 2610.07935v1 2610.07935v1

$$
z_{i,j}\circ y_{i,j}
\sim
\pi(\,\cdot\mid S,x_i),
\qquad j=1,\ldots,N.
$$

**기호:** $z_{i,j}$는 추론 과정, $y_{i,j}$는 최종 응답, $\circ$는 두 텍스트의 연결, $j$는 후보 번호, $N$은 후보 수입니다.

명세 보상이 1인 후보 중 루브릭 보상이 가장 높은 것을 선택합니다.

```math
j_i^*
=
\underset{
\substack{
1\le j\le N\\
R_{\text{spec}}(x_i,y_{i,j};S)=1
}
}{\text{arg max}}
\;
R_{\text{rubric}}(x_i,y_{i,j};C_i).
```

**기호:** $j_i^*$는 선택된 후보 번호이며, $\text{arg max}$는 목적값을 가장 크게 만드는 후보를 고르는 연산입니다.

통과 후보가 없으면 그 과제를 제외하고, 동점이면 무작위로 선택합니다. **명세 보상 만점은 요구하지만, 루브릭 보상까지 반드시 만점이어야 하는 것은 아닙니다.** 학생 모델은 선택된 추론과 응답을 학습하되 입력에서 명세를 제거합니다〔pp.4, 32〕. 2610.07935v1 2610.07935v1

> **용어:** Best-of- $N$은 여러 후보 중 가장 좋은 것을 고르는 방식; 거절 샘플링은 기준에 못 미치는 후보를 버리는 방식; 사고 연쇄(CoT)는 답변 전에 생성되는 중간 추론 텍스트; 증류(distillation)는 더 유리한 조건에서 생성된 출력을 다른 모델이나 같은 모델의 새 버전에 학습시키는 것

일반적인 SFT 손실로 풀어 쓰면 다음과 같습니다. 이는 **원문의 학습 절차를 설명하기 위한 식이며, SIGMA가 별도로 제안한 손실 함수는 아닙니다.**

```math
\mathcal L_{\text{SFT}}(\theta)
=
-
\mathbb E_{(x,z,y)\sim\mathcal D_{\text{SFT}}}
\left[
\log \pi_\theta(z\circ y\mid x)
\right].
```

**기호:** $\theta$는 학습할 매개변수, $\pi_\theta$는 학습 중인 모델, $\mathcal D_{\text{SFT}}$는 선택된 추론·응답 데이터, $\mathbb E$는 데이터에 대한 평균입니다.

**해석:** 동일한 가중치의 모델이라도 **명세를 읽고 16번 시도한 모델**은 명세 없이 한 번 답한 모델보다 좋은 출력을 제공할 수 있습니다. SIGMA-SFT는 이러한 조건 차이를 학습으로 옮기는 방식으로 이해할 수 있습니다.

### 3.6 SIGMA-RL: 과제별 보상과 전역 보상의 결합

논문은 두 보상의 곱으로 GRPO 학습을 수행합니다〔p.4〕. 2610.07935v1

```math
R(x,y;C,S)
=
R_{\text{rubric}}(x,y;C)
\cdot
R_{\text{spec}}(x,y;S).
```

**기호:** $R$은 최종 학습 보상이고, 두 인자는 각각 과제별 기준 준수와 전역 명세 준수 점수입니다.

**중요한 한계:** 이 곱은 엄격한 논리적 AND가 아닙니다. 예컨대 11개 절이 모두 관련 있고 그중 하나를 위반해도, 나머지를 통과하면 명세 보상은 $10/11$로 남을 수 있습니다. 따라서 이 보상식만으로 **중대한 원칙 위반을 반드시 보상 0으로 만드는 하드 제약**이 구현되었다고 말할 수 없습니다.

> **용어:** 하드 제약은 다른 성과로 상쇄할 수 없는 절대적 제한; 보상 설계는 원하는 행동이 높은 점수를 얻도록 학습 신호를 구성하는 작업

GRPO의 기본 아이디어는 같은 질문에 대한 응답들을 서로 비교하는 것입니다. SIGMA가 인용한 *DeepSeekMath: Pushing the Limits of Mathematical Reasoning in Open Language Models*의 결과 보상형 GRPO를 설명용으로 쓰면 다음과 같습니다〔DeepSeekMath pp.13–14, Eq.3, §4.1.2〕. [arXiv](https://arxiv.org/pdf/2402.03300)

```math
\bar R=\frac{1}{G}\sum_{g=1}^{G}R_g,
\qquad
\widehat A_g
=
\frac{R_g-\bar R}
{\text{std}(R_1,\ldots,R_G)}.
```

**기호:** $G$는 같은 질문에 대한 응답 수, $R_g$는 각 응답의 보상, $\bar R$은 그룹 평균, $\text{std}$는 표준편차, $\widehat A_g$는 그룹 평균에 비해 얼마나 좋은지를 나타내는 상대적 이점입니다. 표준편차가 0인 경우에는 별도 구현 처리가 필요하며, 위 식은 양수인 경우의 기본 형태입니다.

SIGMA의 RL은 한 단계에서 32개 프롬프트마다 8개 응답을 생성하고, 총 446단계 학습합니다. 학습률은 $10^{-6}$, 초기 모델에 대한 KL 벌점 계수는 $10^{-3}$이며, 최종 응답만 채점하고 CoT는 채점하지 않습니다〔pp.4, 31〕. 2610.07935v1 2610.07935v1

> **용어:** 상대적 이점(advantage)은 동일 질문의 다른 후보보다 얼마나 나은지 나타내는 값; KL 벌점은 학습 모델의 출력 분포가 기준 모델에서 지나치게 멀어지지 않게 하는 제약

## 5. 일반화 성능 향상의 근거와 한계

### 5.1 관찰된 일반화와 아직 확인되지 않은 일반화

**관찰된 것:** 단일턴의 “이 상황에서 무엇을 하겠는가?”라는 학습에서, 도구 호출이나 이메일 처리 환경에서의 행동 개선으로 전이되었습니다. 최종 평가에서는 전체 Model Spec이 입력에 제공되지 않습니다〔pp.5, 32〕. 2610.07935v1 2610.07935v1

**아직 확인되지 않은 것:** 완전히 새로운 도메인, 학습 지침에 없던 위협 유형, 여러 언어, 매우 긴 작업, 지속적인 공격자와의 상호작용, 이후 역량 학습을 거친 모델에서의 안전성 유지입니다. 생성 지침 자체에 모델의 자기 이익·감독 회피 등이 포함되어 있으므로, 결과를 “전혀 접하지 않은 안전 개념까지 발견했다”로 해석해서도 안 됩니다〔pp.15–16, Appendix A〕. 2610.07935v1 2610.07935v1

**해석:** 가장 설득력 있는 성과는 **행동 원칙의 적용이 대화형 판단에서 다른 실행 형식으로 옮겨졌다는 점**입니다. 그러나 도메인 전체를 학습에서 제외하는 방식으로 검증한 강한 의미의 도메인 일반화와는 구분해야 합니다.

### 5.2 보상 결합: 전역 원칙과 구체적 기준의 보완

RL에서 명세 보상만 사용하면 AgentHarm Harm이 26.7로 초기 모델보다 높아집니다. 루브릭만 사용하면 Harm은 16.1로 낮아지지만 부정렬률은 41.2로 남으며, 두 보상을 결합하면 각각 14.9와 9.0이 됩니다〔p.34, Table 17〕. 2610.07935v1

**해석:** “큰 원칙만으로는 무엇을 해야 하는지 충분히 구체화되지 않고, 개별 과제 기준만으로는 전역적인 행동 제약이 약해질 수 있다”는 설명이 가능합니다. 다만 루브릭만 사용해도 부정렬률은 79.1→41.2로 감소하므로, 이를 문자 그대로 “효과가 없다”고 표현하는 것은 과도합니다.

### 5.3 명세의 내용: 가치 설명 자체의 우월성은 입증되지 않음

**저자 보고:** Safety-only는 부정렬률을 가장 낮게 만들지만 정상 작업 수행을 떨어뜨립니다. Values-based와 Rules-based는 대체로 비슷하고, 원칙 제목만 남긴 Titles-only는 부정렬 감소 효과가 더 작습니다〔p.7, Figure 4〕. 2610.07935v1

**해석:** 핵심은 “가치 설명이 언제나 세부 규칙보다 우월하다”가 아니라, **명세가 충분히 구체적이고 안전성과 유용성을 함께 설명해야 한다**는 것입니다. 설명 길이·내용량·규칙의 구체성이 함께 바뀌므로 설명의 철학적 깊이만을 원인으로 분리할 수는 없습니다.

또한 이 실험은 명세를 바꾸어 **SFT 응답 생성과 선택**을 수행한 것입니다. 과제 합성부터 모든 단계를 새 명세로 다시 수행한 실험으로 읽으면 안 됩니다〔p.40, Appendix M〕. 2610.07935v1

### 5.4 추론 모드: 유용한 근거지만 작동 원리의 완전한 증명은 아님

SIGMA-SFT의 thinking을 끄면 부정렬률이 3.8→38.4, SycophancyEval 정답률이 86.3→72.4로 악화됩니다. 반면 AgentHarm Harm은 14.8→9.5로 낮아지지만 정상 작업 점수도 76.7→66.4로 하락합니다〔p.8, Table 2〕. 2610.07935v1

InstrumentalEval에서도 thinking을 끄면 모든 모델의 목표 추구율이 낮아지며, 저자들은 이를 거절 증가와 연결합니다〔p.7, 각주 1〕. 2610.07935v1

**해석:** 이 결과는 추론 모드가 안전성과 유용성을 함께 달성하는 데 기여한다는 근거입니다. 하지만 추론을 끄면 계산량과 응답 생성 방식도 달라지므로, 성능 차이 전체가 “더 깊은 윤리 추론” 때문에 발생했다고 단정하기는 어렵습니다.

### 6.1 통계적 근거의 강도

**신뢰구간이 겹친다는 사실만으로 “차이가 없다”고 결론 내리는 것도 잘못입니다.** 같은 문항에서 두 모델의 결과를 비교하는 쌍대 분석과, 그 차이의 신뢰구간이 필요합니다.

#### 가장 중요한 표본 구조 문제

Agentic Misalignment의 900회 평가는 **900개의 독립적으로 설계된 환경이 아니라, 세 시나리오를 각각 300번 샘플링한 것**입니다. 이 반복은 해당 시나리오에서의 행동 확률을 정밀하게 추정하는 데 유용하지만, 새로운 기업·목표·압박·권한 구조로 일반화되는 정도까지 정밀하게 알려 주지는 않습니다〔p.33〕. 2610.07935v1

> **용어:** 의사반복(pseudoreplication)은 같은 상위 단위에서 나온 반복 관측을 서로 다른 독립 단위처럼 해석하는 문제; 여기서는 응답 반복의 다양성과 환경 자체의 다양성을 구분해야 함

#### 신뢰구간 계산의 재현성 확인점

**제 계산에 따른 확인 필요 사항:** InstrumentalEval 초기 모델의 결과는 76개 중 약 43개, 즉 56.6%입니다. 이를 단순한 독립 이항 표본으로 가정한 정규근사 95% 신뢰구간의 반폭은 다음과 같습니다.

$$
w
\approx
1.96
\sqrt{\frac{\hat p(1-\hat p)}{n}}
\approx 0.111.
$$

**기호:** $\hat p=43/76$은 관측 비율, $n=76$은 표본 수, $w$는 신뢰구간 반폭이며, 결과는 약 11.1%포인트입니다.

이는 Table 16의 $\pm7.2$와 다릅니다. **다른 재표집 구조나 계산 방식이 사용되었을 수 있으므로 원문이 틀렸다고 단정하지는 않지만**, 공개된 설명만으로 해당 구간을 그대로 재구성하기 어렵다는 점은 확인할 필요가 있습니다〔pp.32–33, Tables 15–16〕. 2610.07935v1 2610.07935v1

### 8.3 이 비교에서 도출되는 중요한 결론

**첫째, SIGMA의 새로움은 개별 부품보다 결합 방식에 있습니다.** 원칙 기반 학습, 자기비평, 자기보상, 합성 데이터, 추론 증류는 모두 선행 연구에 있습니다. SIGMA는 이를 **대조 과제쌍 → 자기검증·수정 → 과제별 루브릭과 전역 명세 보상 → OOD 안전성 평가**로 연결했다는 점에서 의미가 있습니다〔SIGMA pp.8–9, §4〕. 2610.07935v1

**둘째, 가장 가까운 MSM과 점수를 직접 비교해서는 안 됩니다.** MSM은 Qwen2.5/3-32B를 사용하고, 정보 반출·살해·첩보 행동과 여러 목표 조건을 조합한 27개 평가를 사용합니다. SIGMA는 다른 기반 모델과 세 시나리오의 반복 샘플링을 사용하므로, 7% 대 3.8%만으로 SIGMA가 우수하다고 말할 수 없습니다〔MSM pp.6–7; SIGMA p.33〕. [arXiv](https://arxiv.org/pdf/2605.02087v2) 2610.07935v1

**셋째, ‘왜’를 학습하는 최선의 방식은 아직 정해지지 않았습니다.** MSM은 가치 설명의 이점을 보고하지만 SIGMA에서는 가치 중심 명세와 규칙 중심 명세가 대체로 비슷했습니다. 이 차이는 모순이라기보다 기반 모델, 학습 단계, 문서 구성에 따라 어떤 설명 형식이 효과적인지가 달라질 수 있음을 시사합니다. [arXiv](https://arxiv.org/abs/2605.02087) 2610.07935v1

**넷째, 앞으로는 일반화와 지속성을 분리해서 평가해야 합니다.** SIGMA가 보여 준 전이가 다음 단계의 대규모 역량 RL, 장기 도구 사용, 적대적 미세조정 이후에도 유지되는지는 미검증입니다. 이 축은 *Reinforcement Learning Towards Broadly and Persistently Beneficial Models*가 직접 다룬 후속 비교 기준입니다. [arXiv](https://arxiv.org/pdf/2606.24014)

## 10. 결론: 저자의 시사점과 추가 후속 연구 방향

### 10.1 저자들이 제시한 시사점과 계획

**저자 보고:** 일반 추론·에이전트 능력이 더 강해지면, 그 능력을 더 좋은 정렬 감독을 만드는 데 사용할 가능성이 있습니다. 또한 윤리적 딜레마를 다루는 단일턴 자료가 여러 행동 평가로 전이된다는 결과를, 경험과 성찰을 통한 판단력 형성이라는 관점에서 해석합니다. 다만 저자들은 이것이 모델의 ‘실천적 지혜’를 입증하는 것은 아니라고 명시합니다〔p.9, §5〕. 2610.07935v1

> **용어:** 실천적 지혜(phronesis)는 구체적 상황에서 무엇이 적절한 행동인지 판단하는 능력을 뜻하는 철학적 개념; 여기서는 실험으로 검증된 모델의 정신적 속성이 아니라 설명을 위한 비유

저자의 직접적인 후속 연구 계획은 **개선된 모델을 다시 과제 설계자로 사용하는 반복 자기개선, CoT 감시 가능성에 대한 영향, 평가 인식의 영향 분석**입니다. RL은 CoT를 직접 채점하지 않는 대안이지만, 감시 가능성이 실제로 더 잘 보존되는지는 추가 검증이 필요합니다〔pp.9–10〕. 2610.07935v1

> **용어:** CoT 감시 가능성(monitorability)은 추론 텍스트를 관찰하여 위험한 의도나 행동을 알아차릴 수 있는 정도; 평가 인식(evaluation awareness)은 모델이 현재 상황을 시험으로 알아차리는 것

### 10.2 제가 제안하는 후속 연구

| 우선 과제 | 권장 실험 | 확인할 핵심 |
|---|---|---|
| **일반화 범위를 더 엄격하게 검증** | 도메인 전체·위협 유형·언어·도구 체계를 학습에서 제외하고 평가 | 형식 변화뿐 아니라 새로운 문제 구조에도 전이되는가? |
| **구성 요소와 비용을 통제** | 같은 프롬프트, 후보 수, 생성·학습 토큰 예산으로 DA·SIGMA 비교; 대조쌍·난도·정제 각각 제거 | 개선 원인이 데이터 구조인지, 추가 생성·선택 연산인지? |
| **자기 판정의 정확도 측정** | 비공개 인간 전문가 평가셋과 다른 계열 판정 모델로 루브릭·명세 판정 검증 | 자기 일관성뿐 아니라 외부 기준에서도 맞는가? |
| **반복 자기개선의 안정성 평가** | 여러 학습 라운드와 여러 학습 시드를 사용하고 판정 정확도·데이터 다양성·능력 손실을 함께 추적 | 개선이 누적되는가, 편향과 쉬운 문제로의 수렴이 누적되는가? |

| **후속 학습 이후의 지속성 평가** | 일반 역량 RL·장기 에이전트 작업·적대적 미세조정 전후의 안전성 비교 | 처음 얻은 안전성 개선이 이후에도 남는가? |
| **중대한 위반을 별도로 처리** | 현재 보상 곱과 중대 위반 우선 제약을 비교하고 정상 과제 성능도 측정 | 일부 원칙 위반이 높은 평균 점수에 가려지지 않는가? |

여기서 인간 평가를 **측정과 감사에만** 사용하면, 학습용 외부 교사에 의존하지 않는다는 SIGMA의 연구 질문을 유지하면서 자기 판정의 타당성을 검증할 수 있습니다.

평가 인식 연구인 *Decomposing and Measuring Evaluation Awareness*의 최신 확인본은 **평가를 알아차리는 것과 그 때문에 행동을 바꾸는 것은 별개**라고 구분합니다. 따라서 SIGMA에서도 “시험처럼 보이는 단서”를 바꾸되 실제 요청은 유지하는 대조 평가가 필요합니다〔2026년 9월 v3, §§2–4〕. [arXiv](https://arxiv.org/html/2605.23055v3)

또한 *Monitoring Reasoning Models for Misbehavior and the Risks of Promoting Obfuscation*은 CoT 감시 신호를 강하게 최적화하면 위험 행동 자체보다 그 의도의 표현이 숨겨질 수 있음을 보고합니다. 따라서 SIGMA-SFT와 RL을 비교할 때는 안전 점수뿐 아니라 **행동의 탐지 가능성과 추론 표현의 변화**도 함께 측정해야 합니다〔2025, 초록〕. [arXiv](https://arxiv.org/abs/2503.11926)

### 최종 평가

**이 논문은 “안전한 답변을 더 많이 외우게 한다”에서 “모델이 원칙을 적용할 연습 문제와 평가 기준을 직접 구성하게 한다”로 연구의 초점을 확장한다는 점에서 중요합니다.** 특히 단일턴 자료에서 에이전트 행동으로 전이된 큰 부정렬 감소는 후속 재현 가치가 높습니다. 다만 현재 근거로 정당화되는 결론은 **한 기반 모델과 제한된 평가군에서 안전 정렬의 일반화가 개선되었다**는 것이며, 일반 능력 전체의 향상·반복적 자기개선의 지속·현실 배포 안전성까지 입증된 것은 아닙니다〔pp.4–10, Tables 1–4〕. 2610.07935v1 2610.07935v1 2610.07935v1

**가장 중요한 다음 질문은 “같은 시험에서 점수가 더 오르는가?”가 아니라, “더 낯선 환경과 더 강한 압박, 그리고 이후의 학습을 거친 뒤에도 올바른 판단이 유지되는가?”입니다.**
