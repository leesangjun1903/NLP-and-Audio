## 2. 연구 목적·필요성 및 핵심 주장

### 2.1 무엇을 해결하려는가?

**[문서의 설명]** 문제는 크게 두 층위입니다.

첫째는 **목표의 불일치**입니다. 사전학습은 관측된 텍스트를 예측하지만, 사용자는 정확하고 관련성 높으며 적절한 방식으로 제시된 답변을 원합니다. 책의 예시에서 기본 모델은 문장을 계속 이어 쓰는 반면, 사후학습 모델은 질문에 직접 답합니다(pp. 8–11). 2504.12501v12 2504.12501v12

둘째는 **목표를 명세하기 어렵다는 문제**입니다. 수학 문제는 정답 검사가 가능하지만, “이 설명이 더 친절한가”, “이 답변이 상황에 적절한가”에는 하나의 정답이 없습니다. RLHF는 이러한 판단을 인간의 비교 데이터로부터 근사합니다(pp. 127–133). 2504.12501v12 2504.12501v12

> **용어 설명 — 사전학습·사후학습:** 사전학습은 대규모 데이터로 기본 언어 능력을 학습하는 과정이고, 사후학습은 그 모델을 지시 수행·대화·추론 등 원하는 용도에 맞게 추가로 훈련하는 과정입니다.  
> **목표 명세:** 모델이 무엇을 잘해야 하는지 측정 가능한 기준으로 정하는 일입니다.

**[분석자 해석]** 따라서 이 책이 다루는 문제를 “모델의 정답률을 높이는 법”으로만 축소하면 중요한 부분을 놓칩니다. 핵심은 **무엇을 좋은 답변으로 볼 것인지, 그 판단을 어떻게 측정할 것인지, 측정값을 최적화해도 원래 목표가 유지되는지**입니다.

## 3. 모델 구조와 핵심 방법 — 수식 포함

아래에서는 책에서 반복 사용되는 기호를 일관되게 정리했습니다. 정책 모델의 매개변수는 $\theta$, 보상 모델은 $\phi$, 가치 모델은 $\psi$로 구분합니다. **이 수식들은 책이 설명하는 대표 방법이지, 모두 이 책에서 처음 제안한 방법은 아닙니다.**

### 3.1 모델 구조: 하나의 새로운 신경망이 아니라 여러 역할의 결합

| 구성 요소 | 입력 → 출력 | 전형적인 구조와 역할 | RL 단계에서 학습 여부 |

| 보상 모델 $r_\phi$ | 질문과 완성된 답변 → 하나의 점수 | 언어모델의 마지막 유효 토큰 표현에 선형 출력층을 붙이는 방식이 대표적입니다. | 보통 해당 RL 실행 중 고정 |

### 3.2 지도 미세조정: 좋은 답변의 형식을 먼저 학습

**[문서의 설명을 수식화: pp. 36–37]**

```math
\mathcal{L}_{\text{SFT}}(\theta)
=
-\mathbb{E}_{(x,y)\sim D_{\text{SFT}}}
\left[
\sum_{t=1}^{T}
\log \pi_\theta(y_t\mid x,y_{ < t})
\right].
```

여기서 $D_{\text{SFT}}$는 질문–모범 답변 데이터, $x$는 질문, $y=(y_1,\ldots,y_T)$는 길이 $T$의 모범 답변, $y_{<t}$는 $t$번째 토큰 이전의 답변입니다. $\pi_\theta(y_t\mid x,y_{<t})$는 정답 토큰에 부여한 확률이고, $\mathbb{E}$는 데이터에 대한 평균입니다.

위 식은 **답변 토큰만 학습한다는 표기**입니다. 책은 사용자 질문 토큰을 손실에서 제외하는 마스킹과, 다중 대화에서 어느 답변까지 학습할지를 중요한 구현 선택으로 설명합니다. 2504.12501v12

> **용어 설명 — SFT, 지도 미세조정:** 주어진 모범 답변을 더 잘 재현하도록 모델을 훈련하는 것입니다.  
> **손실 함수:** 모델이 얼마나 잘못하고 있는지 나타내는 수치이며, 학습은 이를 줄이는 방향으로 진행됩니다.  
> **마스킹:** 특정 토큰이 학습 손실에 기여하지 않도록 제외하는 처리입니다.

**[분석자 해석]** SFT는 “나쁜 방법”이 아니라 모델을 원하는 인터페이스와 과제에 맞추는 기본 도구입니다. 다만 특정 답변 표현만 강하게 모방하도록 학습하면, 규칙이나 상황이 바뀌었을 때 그 표현을 벗어나기 어려울 수 있습니다. 이것이 뒤에서 논의할 일부 일반화 실험의 쟁점입니다.

### 3.3 보상 모델: 인간의 상대적 선호를 확률로 표현

**[문서의 수식: pp. 39–42, Eqs. 12–18]**

동일한 질문에 대해 사람이 더 선호한 답변을 $y^+$, 덜 선호한 답변을 $y^-$라 하면,

```math
P_\phi(y^+\succ y^-\mid x)
=
\sigma\!\left(r_\phi(x,y^+)-r_\phi(x,y^-)\right),
\qquad
\sigma(z)=\frac{1}{1+\exp(-z)}.
```

보상 모델의 학습 손실은 다음과 같습니다.

```math
\mathcal{L}_{\text{RM}}(\phi)
=
-\mathbb{E}_{(x,y^+,y^-)\sim D_{\text{pref}}}
\left[
\log \sigma\!\left(
r_\phi(x,y^+)-r_\phi(x,y^-)
\right)
\right].
```

$D_{\text{pref}}$는 선호 비교 데이터, $r_\phi$는 보상 점수, $\succ$는 “더 선호됨”, $\sigma$는 점수 차이를 0과 1 사이의 확률로 바꾸는 함수입니다. 이는 책의 **Bradley–Terry 선호 모델**입니다. 2504.12501v12 2504.12501v12

> **용어 설명 — Bradley–Terry 모델:** 각 후보에 잠재적 점수를 부여하고, 두 점수의 차이로 어느 후보가 선택될 확률을 설명하는 비교 모델입니다.  
> **시그모이드:** 임의의 실수를 확률처럼 해석할 수 있는 0–1 범위로 변환하는 함수입니다.

**중요한 수학적 주의점:** $r_\phi(x,y)$ 자체는 확률이 아닙니다. **두 점수의 차이를 시그모이드에 넣은 값**이 선호 확률입니다. 또한 같은 질문의 모든 답변 점수에 동일한 상수를 더해도 비교 확률은 변하지 않으므로, 보상 점수의 절대값을 사람의 만족도로 해석해서는 안 됩니다(p. 41). 2504.12501v12

책은 추가로 결과 보상 모델과 과정 보상 모델을 구분합니다. 전자는 최종 답의 정답 여부를, 후자는 추론 단계의 타당성을 학습하며, 대표 구현의 출력 위치와 학습 신호가 서로 다릅니다. 특히 **중간 단계가 그럴듯하다는 것과 최종 답이 맞다는 것은 별개의 평가 대상**입니다(pp. 44–51, Figs. 16–18, Table 2). 2504.12501v12 2504.12501v12 2504.12501v12

> **용어 설명 — 과정 보상 모델, PRM:** 풀이 전체에 한 번 점수를 주는 대신, 각 추론 단계가 올바른지 평가하는 모델입니다.

### 3.4 RLHF의 핵심 목적: 선호 점수를 높이되 지나치게 변하지 않기

**[문서의 수식 재표기: pp. 25–26, Eq. 11]**

```math
\max_\theta J(\theta)
=
\mathbb{E}_{x\sim D_x}
\left[
\mathbb{E}_{y\sim\pi_\theta(\cdot\mid x)}
r_\phi(x,y)
-
\beta
D_{\text{KL}}
\left(
\pi_\theta(\cdot\mid x)
\Vert
\pi_{\text{ref}}(\cdot\mid x)
\right)
\right].
```

분포 차이를 측정하는 항은 다음과 같습니다.

```math
D_{\text{KL}}(P\Vert Q)
=
\sum_y P(y)\log\frac{P(y)}{Q(y)}.
```

$D_x$는 학습 질문의 분포, $\pi_{\text{ref}}$는 고정된 기준 모델, $\beta>0$는 변화 억제의 강도입니다. $P,Q$는 비교하는 확률분포이며, 합은 가능한 출력에 대해 계산합니다. $\beta$가 크면 기준 모델에 더 가깝게 머물도록 압력을 주고, 작으면 보상을 추구할 자유가 커집니다. 2504.12501v12

> **용어 설명 — KL 발산:** 두 확률분포가 얼마나 다른지 측정하는 비대칭적인 양입니다. 일반적으로 $D_{\text{KL}}(P\Vert Q)\neq D_{\text{KL}}(Q\Vert P)$입니다.  
> **정규화·규제:** 목표 점수만 무작정 높이지 않도록 학습에 제약이나 추가 비용을 부여하는 것입니다.  
> **대리 목표:** 실제로 원하는 목표를 직접 측정하기 어려워 대신 최적화하는 지표입니다.

**[분석자 해석]** 이 식은 “인간의 진짜 만족을 최대화한다”는 식이 아닙니다. **학습된 선호 점수와 기준 모델 유지 사이의 절충**을 최적화합니다. 따라서 보상 모델이 잘못 평가하는 영역으로 정책이 이동하면, 식을 더 잘 최적화하면서 실제 품질은 떨어질 수 있습니다.

또한 책의 “상태 전이가 없다”는 설명은 답변 전체를 하나의 행동으로 취급하는 단일 질문–답변 추상화입니다. 토큰 단위로 보면 새 토큰이 접두부에 추가되는 상태 전이가 있으며, 도구 사용·다중 대화에서는 더 복잡한 순차 의사결정이 됩니다(pp. 24–25, 84). 2504.12501v12 2504.12501v12

### 3.5 PPO와 GRPO: 보상에 따라 생성 확률을 조정하는 방법

#### PPO

**[문서의 수식: pp. 65–68, Eq. 54, Figs. 22–23]**

```math
J_{\text{PPO}}(\theta)
=
\widehat{\mathbb{E}}_t
\left[
\min\left(
\rho_t(\theta)\widehat{A}_t,\,
\text{clip}\!\left(
\rho_t(\theta),1-\epsilon,1+\epsilon
\right)\widehat{A}_t
\right)
\right],
```

```math
\rho_t(\theta)
=
\frac{\pi_\theta(a_t\mid s_t)}
{\pi_{\text{old}}(a_t\mid s_t)}.
```

$s_t=(x,y_{ < t})$는 생성 중 상태, $a_t=y_t$는 선택한 토큰, $\pi_{\text{old}}$는 해당 답변을 생성한 시점의 정책, $\widehat{\mathbb{E}}_t$는 수집된 토큰에 대한 평균입니다. $\widehat{A}_t$는 해당 선택이 기대보다 얼마나 좋았는지 추정한 값이고, $\epsilon>0$는 클리핑 범위입니다. $\text{clip}$은 입력을 지정 범위 안으로 자릅니다. 2504.12501v12

가장 단순한 형태의 우위 추정은 $\widehat{A}\_t=\widehat{G}\_t-V_\psi(s_t)$입니다. 여기서 $\widehat{G}_t$는 이후 누적 보상의 추정치이며, 전형적인 RLHF 구현에서는 보상 모델 점수와 KL 패널티를 반영합니다. 가치 모델은 이 누적 보상을 예측하도록 별도로 학습됩니다(pp. 70–72). 2504.12501v12 2504.12501v12

> **용어 설명 — 우위, advantage:** “이 선택이 같은 상황에서의 평균적인 선택보다 얼마나 좋았는가”입니다.  
> **클리핑:** 지나치게 큰 값의 영향력을 제한하는 처리입니다.  
> **중요도 비율 $\rho_t$:** 과거 정책으로 수집한 데이터를 현재 정책의 학습에 사용할 때 확률 차이를 보정하는 값입니다.

**주의:** $\pi_{\text{old}}$와 $\pi_{\text{ref}}$는 다릅니다. 전자는 이번 학습 배치를 생성한 정책이고, 후자는 전체 변화의 기준입니다. 또한 PPO의 클리핑은 과도한 갱신 유인을 줄이는 장치이지, 모든 토큰 확률이나 전체 KL이 반드시 특정 범위 안에 머문다는 보장은 아닙니다.

#### GRPO

**[문서의 수식: pp. 72–74, Eqs. 58–59, Fig. 25]**

같은 질문에 대해 $G$개의 답변을 생성하고, 각각의 보상을 $r_1,\ldots,r_G$라 하면,

```math
\widehat{A}_i
=
\frac{r_i-\overline{r}}{s_r+\delta},
\qquad
\overline{r}
=
\frac{1}{G}\sum_{j=1}^{G}r_j.
```

$i$는 답변 번호, $\overline r$는 그룹 평균 보상, $s_r$는 그룹 보상의 표준편차입니다. $\delta>0$는 0으로 나누는 문제를 막는 작은 수로, 책의 이론식 Eq. 59에는 생략되어 있고 구현 예시에는 추가됩니다.

GRPO는 이 $\widehat A_i$를 해당 답변의 토큰들에 적용하고, PPO와 유사한 확률 비율·클리핑으로 갱신합니다. **가치 모델 없이 같은 질문에 대한 답변끼리 비교한다는 점**이 핵심이며, 대표 구현에서는 KL 항을 손실에 별도로 더합니다. 2504.12501v12 2504.12501v12

**[분석자 해석]** 별도 가치 모델이 필요 없다는 것은 메모리·구현 측면의 장점입니다. 그러나 그룹 내 답변이 모두 같은 보상을 받으면 보상 기반 상대 우위 신호는 0이 되고, 표준편차 정규화는 질문별 학습 가중치를 바꿉니다. 따라서 “GRPO가 더 단순하다”와 “항상 더 일반화한다”는 별개의 주장입니다.

### 3.6 DPO: 보상 모델을 따로 만들지 않고 선호를 직접 학습

**[문서의 수식: pp. 111–114, Eqs. 89·97·102·107]**

고정된 보상 함수에 대한 KL 규제 최적 정책은 다음 형태입니다.

```math
\pi^*(y\mid x)
=
\frac{
\pi_{\text{ref}}(y\mid x)\exp(r_\phi(x,y)/\beta)
}{
Z_\phi(x)
},
```

```math
Z_\phi(x)
=
\sum_y
\pi_{\text{ref}}(y\mid x)
\exp(r_\phi(x,y)/\beta).
```

$\pi^*$는 이 목적함수의 최적 정책이고, $Z_\phi(x)$는 확률의 합이 1이 되도록 만드는 정규화 상수입니다. 이를 선호 모델에 대입하면 별도 보상 모델 없이 다음 손실을 얻습니다.

```math
\mathcal{L}_{\text{DPO}}(\theta)
=
-\mathbb{E}_{(x,y^+,y^-)\sim D_{\text{pref}}}
\left[
\log\sigma
\left(
\beta\log
\frac{\pi_\theta(y^+\mid x)}
{\pi_{\text{ref}}(y^+\mid x)}
-
\beta\log
\frac{\pi_\theta(y^-\mid x)}
{\pi_{\text{ref}}(y^-\mid x)}
\right)
\right].
```

앞서 정의한 기호와 동일하며, 손실은 **선호 답변의 상대적 확률 변화가 비선호 답변보다 커지도록** 만듭니다. 이 식은 DPO 원논문의 Eq. 7과 대응합니다. 2504.12501v12 2504.12501v12 2504.12501v12 [arXiv](https://arxiv.org/pdf/2305.18290)

**[분석자 해석: 이론과 실제를 구분해야 하는 지점]**

책의 pp. 110·117은 DPO의 정확한 최적해 및 KL 설정을 강하게 표현하지만, 위 유도는 **목적함수의 최적해를 표현한 것**입니다. 실제 신경망에서는 유한한 데이터, 모델 표현력, 최적화 오차가 있으므로, $\beta$를 정했다고 실제 KL 값이 정확히 고정되거나 최적 정책에 도달하는 것은 아닙니다. 2504.12501v12 2504.12501v12

또한 상대적 차이만 커지면 손실이 줄기 때문에, **선호 답변과 비선호 답변의 절대 확률이 모두 감소하면서 비선호 답변이 더 크게 감소하는 현상**도 가능합니다. 책의 Fig. 30은 이를 설명하는 개념도입니다(pp. 115–116). 2504.12501v12

> **용어 설명 — 선호 변위, preference displacement:** 학습 목표상 선호 격차는 개선되지만, 확률이 데이터에 없는 다른 출력으로 이동할 수 있는 현상입니다.

### 3.7 RLVR·거부 샘플링·다중 교사 증류는 무엇이 다른가?

**RLVR**은 보상 모델 대신 정답 검증 함수를 사용할 수 있습니다(pp. 97–99).

```math
r_{\text{VR}}(x,y)
=
\begin{cases}
1, & \text{검증 함수가 답변을 통과시킨 경우},\\
0, & \text{그렇지 않은 경우}.
\end{cases}
```

$r_{\text{VR}}$은 검증 보상이며, 검증은 수학 정답 비교나 코드 테스트 실행 등이 될 수 있습니다. 다만 **검증 함수 통과가 그 함수가 검사하지 않은 모든 속성의 정확성을 의미하지는 않습니다.** 2504.12501v12

> **용어 설명 — RLVR:** 사람이 어느 답변을 선호하는지를 예측하는 대신, 정답 검사처럼 검증 가능한 결과를 보상으로 쓰는 강화학습입니다.

**거부 샘플링 기반 학습**은 여러 답변을 생성하고, 좋은 답변을 골라 SFT를 수행합니다. 반면 **Best-of-N**은 여러 답변 중 좋은 답변을 선택해 사용자에게 제공할 뿐 모델의 가중치를 바꾸지 않습니다(pp. 120–125, Fig. 31). 2504.12501v12 2504.12501v12

**다중 교사 온정책 증류, MOPD**는 여러 전문 모델의 능력을 하나의 학생 모델로 옮깁니다. 책의 대표 목적함수는 다음과 같습니다(p. 152, Eq. 138).

```math
\mathcal{L}_{\text{MOPD}}(\theta)
=
\mathbb{E}_{x\sim D_x,\;y\sim\pi_\theta(\cdot\mid x)}
\left[
\sum_{t=1}^{T}
\sum_{k=1}^{K}
w_k(x)
D_{\text{KL}}
\left(
\pi_\theta(\cdot\mid s_t)
\Vert
\pi_{T_k}(\cdot\mid s_t)
\right)
\right].
```

$K$는 교사 모델 수, $\pi_{T_k}$는 $k$번째 교사, $w_k(x)\geq0$는 질문별 교사 가중치이며 $\sum_k w_k(x)=1$입니다. $s_t=(x,y_{<t})$는 **학생이 실제로 생성한 접두부**입니다. 학생의 현재 출력 상황에서 교사가 제공하는 토큰 분포를 학습한다는 점이 중요합니다. 2504.12501v12

> **용어 설명 — 증류:** 강한 모델의 출력이나 확률 정보를 다른 모델의 학습 신호로 사용하는 것입니다.  
> **온정책, on-policy:** 지금 학습 중인 모델 자신이 생성한 데이터를 사용하는 것입니다.  
> **노출 편향:** 훈련에서는 모범 답변의 접두부를 보지만 실제 사용에서는 자신의 불완전한 출력을 보게 되는 차이입니다. 책은 온정책 증류를 이 차이를 줄이는 방법으로 설명합니다(pp. 150–152). 2504.12501v12

## 4. 일반화 성능 향상 가능성: 무엇이 실제로 입증되었는가?

### 4.1 일반화를 하나의 점수로 취급하면 안 된다

이 리뷰에서는 다음을 구분합니다.

| 일반화의 종류 | 검증해야 하는 질문 |
|---|---|
| 새로운 입력에 대한 일반화 | 같은 종류의 문제에서 처음 보는 사례도 잘 푸는가? |
| 규칙·분포 변화에 대한 일반화 | 훈련 때와 다른 규칙이나 표현에서도 적응하는가? |
| 기존 능력 유지 | 특정 과제를 추가 학습해도 다른 능력을 덜 잊는가? |
| 능력 범위의 확장 | 원래 거의 해결하지 못하던 문제군까지 해결하게 되는가? |
| 사용자·가치의 일반화 | 평가자 집단과 다른 사용자에게도 적절한 답변을 제공하는가? |

> **용어 설명 — OOD, 분포 밖 평가:** 훈련 데이터와 다른 조건에서 모델을 시험하는 것입니다.  
> **망각:** 새로운 과제를 학습하면서 기존 과제의 성능이 떨어지는 현상입니다.

**[분석자 해석]** 이 다섯 가지는 관련되어 있지만 동의어가 아닙니다. 새로운 규칙에 대한 정확도 상승이 출력 다양성 유지나 다른 문화권 사용자의 만족까지 증명하지는 않습니다.

### 4.2 인간 선호 기반 RLHF의 직접적인 일반화 증거

**[원연구 저자 보고]** Kirk 등은 RLHF와 SFT를 비교하여, 요약 및 지시 수행에서 RLHF의 분포 밖 성능이 더 높은 경우를 보고했습니다. 그러나 요약 과제에서는 분포 안과 밖의 성능 차이가 방법 간 비슷했고, 더 어려운 순차 지시 과제에서는 RLHF의 일반화 이점이 두드러졌습니다. 또한 요약에서 문법적·의미적 다양성이 감소했지만, 모든 다양성 지표가 같은 결론을 보인 것은 아닙니다(원논문 Figs. 2–6, §§6.1–6.2). [arXiv](https://arxiv.org/html/2310.06452)

**[분석자 해석]** 이 결과는 “RLHF가 좋은 답변을 더 안정적으로 내도록 할 수 있다”는 근거입니다. 동시에 **평균 품질 상승과 다양한 답변 가능성의 유지가 충돌할 수 있음**을 보여줍니다. 따라서 책 p. 10의 일반화에 관한 강한 표현에는 과제·평가지표 조건을 붙여 읽는 것이 적절합니다. 2504.12501v12

### 4.5 일반화 기제: 온정책 데이터와 KL 방향

**[문서의 이론 설명: pp. 182–185, Eqs. 148–152]**

고정된 질문 $x$에서 모범 답변의 분포를 $p_D$라 하면, SFT는 다음과 같이 쓸 수 있습니다.

```math
\mathcal{L}_{\text{SFT}}(\theta;x)
=
H\!\left(p_D(\cdot\mid x)\right)
+
D_{\text{KL}}
\left(
p_D(\cdot\mid x)
\Vert
\pi_\theta(\cdot\mid x)
\right).
```

$H(p_D)$는 데이터 분포의 엔트로피이며 $\theta$와 무관한 상수입니다. 따라서 SFT는 이 설정에서 **데이터 분포에서 모델 분포로 향하는 KL**을 최소화합니다.

반면 앞서 정의한 고정 보상·고정 기준 모델· $\beta > 0$ 조건의 RL 목적함수는,

```math
J(\theta)
=
\beta\,\mathbb{E}_{x\sim D_x}\log Z_\phi(x)
-
\beta\,\mathbb{E}_{x\sim D_x}
D_{\text{KL}}
\left(
\pi_\theta(\cdot\mid x)
\Vert
\pi^*(\cdot\mid x)
\right)
```

로 표현됩니다. 즉 모델이 스스로 생성하는 분포에서 보상 최적 분포로 향하는 KL을 줄이는 관점입니다. 2504.12501v12 2504.12501v12

> **용어 설명 — 엔트로피:** 확률분포가 얼마나 퍼져 있고 불확실한지를 나타내는 양입니다.  
> **정방향·역방향 KL:** KL의 두 인자 순서를 바꾸어 부르는 표현으로, 어느 분포에서 평균을 내는지가 달라집니다.

**[분석자 해석]** 이 차이는 RL이 이미 어느 정도 가능한 답변을 개선하는 방식으로 학습할 수 있다는 설명을 제공합니다. 그러나 세 가지 제한이 있습니다.

첫째, $p_D$와 $\pi^*$는 같은 목표 분포라고 보장되지 않습니다. 둘째, 위 등식은 명시한 목적함수에 관한 것이지 모든 RL 알고리즘의 일반화 정리는 아닙니다. 셋째, 역방향 KL의 집중 성향은 기존 능력 보존뿐 아니라 **답변 다양성 축소와도 양립**할 수 있습니다.

### 4.6 반드시 바로잡아 읽어야 할 수치: $R^2=0.96$

**[첨부본의 서술]** p. 186은 새 과제에서 측정한 모델 변화와 기존 과제의 망각 사이에 $R^2=0.96$의 관계가 관찰되었다고 요약합니다. 2504.12501v12

**[원연구와 대조]** 그러나 *RL’s Razor* 원문 p. 6은 다음을 구분합니다.

| 실험 대상 | 보고된 $R^2$ | 원문 위치 |
|---|---:|---|
| 소규모 신경망의 ParityMNIST–FashionMNIST 실험 | 0.96 | p. 6, §4 |
| 언어모델 실험 | 0.71 | p. 6, Fig. 11 |

원문은 또한 이상적으로 구성한 SFT 학습 분포가 RL보다 좋은 능력 유지 절충을 보일 수 있음을 보고합니다. [arXiv](https://arxiv.org/pdf/2509.04259)

> **용어 설명 — $R^2$, 결정계수:** 특정 회귀식이 관측값의 변동을 얼마나 설명하는지 나타내는 수치입니다. 원인 관계나 새로운 환경에서의 예측 정확도를 자동으로 보장하지 않습니다.

**[분석자 해석]** 따라서 “RLHF는 언어모델의 망각을 96% 설명한다” 또는 “SFT는 본질적으로 일반화하지 못한다”는 결론은 부적절합니다. 더 정확한 연구 질문은 **어떤 데이터 생성 방식과 학습 분포가 같은 목표 성능을 더 작은 변화로 달성하게 하는가**입니다.

### 6.2 Table 9의 표준편차를 어떻게 읽어야 하는가?

**[첨부본 재인용: p. 242, Table 9]** 책은 14개 모델에 대해 각 3회 추론 평가를 수행하고, 모델별 표준편차를 구한 뒤 평균한 값을 제시합니다. 예를 들어 GPQA는 1.48점, MATH는 0.25점, AIME 24의 Avg@32는 0.54점입니다. 2504.12501v12

이 수치는 **학습 시드 간 표준편차가 아니며, 95% 신뢰구간도 아닙니다.** 또한 반복 답변을 평균하는 평가와 단일 답변 평가가 섞여 있으므로, 숫자가 작다고 해당 벤치마크가 본질적으로 더 안정적이라고 단정할 수 없습니다.

> **용어 설명 — 표준편차:** 반복 관측값이 평균 주위에서 얼마나 흔들리는지 나타냅니다.  
> **신뢰구간:** 사용한 통계 절차와 가정에 따라 추정값의 불확실성을 구간으로 표현한 것입니다.

생성형 모델 평가에서는 특히 다음을 구분해야 합니다.

| 지표 | 의미 |
|---|---|
| **pass@1** | 한 번 생성한 답이 맞을 확률에 해당하는 성능 |
| **Avg@k** | 여러 생성의 정답 여부를 평균하여 단일 생성의 평균 성능을 더 안정적으로 추정 |
| **pass@k** | $k$개 생성 중 하나라도 맞는 문제가 얼마나 되는지 측정 |
| **Cons@k** | 여러 답변의 다수결 등 합의 방식으로 최종 답을 선택한 성능 |
| **Best-of-N** | 별도 채점 기준으로 후보 중 하나를 선택한 성능 |

따라서 **pass@1 상승, pass@k 상승, 다수결 성능 상승은 같은 종류의 개선이 아닙니다.** 학습 효과와 추론 시 추가 계산의 효과를 분리해야 합니다.

### 7.1 최신 연구를 읽을 때 특히 중요한 세 가지

**첫째, “능력 통합 점수”를 정확도로 읽으면 안 됩니다.** MOPD의 Table 2에서 0.9373은 정답률 93.73%가 아니라, SFT 학생에서 전문 교사까지의 개선 여지를 기준으로 정규화한 통합 점수입니다. Mix-RL의 0.8818과는 같은 표 안에서 비교할 수 있지만, 다른 논문의 평균 정확도와 직접 비교할 수 없습니다. [arXiv](https://arxiv.org/html/2606.30406v1)

**둘째, 학습 데이터의 질문 수와 실제 학습 기여는 다릅니다.** Open-MOPD는 짧은 지시 수행 답변과 긴 수학·코드 답변을 섞을 때, 질문 비율과 손실에 기여하는 토큰 비율이 크게 달라질 수 있음을 보여줍니다. 이는 책 pp. 81–83의 손실 집계 문제를 능력 통합의 실제 병목으로 연결합니다. [arXiv](https://arxiv.org/html/2608.19098v1) 2504.12501v12

**셋째, 최신 연구에는 더 나은 불확실성 보고도 나타납니다.** MOPD-Router는 짝지은 재표집 검정과 특정 4B 설정의 3개 학습 시드 반복을 보고합니다. 다만 평가 문항의 불확실성과 학습 실행의 불확실성은 별개이며, 한 설정의 시드 반복이 모든 모델 규모의 안정성을 보장하지는 않습니다(Appendix D, Tables 9–10). [arXiv](https://arxiv.org/html/2609.30837v1)

> **용어 설명 — 짝지은 재표집, paired bootstrap:** 같은 평가 문항에 대한 두 모델의 결과를 함께 다시 뽑아, 성능 차이의 불확실성을 추정하는 방법입니다.

**[분석자 종합]** 2020년 이후의 변화는 “RLHF가 SFT를 대체했다”가 아닙니다. **모범 답변의 모방, 선호 비교, 정답 검증, 현재 모델의 생성, 전문 교사의 피드백을 어떻게 조합해야 일반화와 능력 유지가 함께 좋아지는가**로 연구 질문이 정교해졌습니다.

## 9. 결론: 저자의 시사점과 추가 후속 연구 방향

### 9.1 저자가 제시한 시사점·향후 방향

**[문서의 설명]** 저자는 RLHF를 특정 시기의 한 알고리즘보다, 인간의 복잡한 목표를 모델 학습으로 연결하는 연구의 기반으로 봅니다. 향후에는 더 많은 계산을 사용하는 추론 학습, 합성 데이터와 인간 데이터의 조합, 도구 사용, 모델의 행동 특성 및 평가가 중요해질 것으로 전망합니다(pp. 17, 107, 208–209). 2504.12501v12 2504.12501v12 2504.12501v12

실제로 제시된 후속 활동은 구현 예제와 실험 제안, 데이터·학습률·샘플링 조건의 비교, 공개 모델의 중간 학습 상태를 이용한 연구입니다. **책 자체가 특정 일정·표본 수·성공 기준을 갖춘 하나의 후속 실험 계획을 약속하는 것은 아닙니다.** 예를 들어 거부 샘플링에서는 보상 기반 선택과 무작위 선택을 비교하도록 제안합니다(pp. 125–126). 2504.12501v12

### 9.2 분석자가 제안하는 후속 연구 — 일반화 중심

#### A. 알고리즘 효과와 데이터 생성 효과를 분리해야 한다

동일한 초기 모델과 질문 집합에서, **고정 외부 답변·초기 모델 답변·학습 중 현재 모델 답변**을 구분하고, 모방 손실과 보상 기반 손실을 비교하는 실험이 우선입니다. 계산량, 답변 길이, 데이터 품질, 명시적 KL 규제를 별도로 통제해야 합니다.

이 설계는 “RL이어서 좋아졌는가”와 “현재 모델에게 적합한 데이터를 사용해서 좋아졌는가”를 구분합니다. 책의 온정책 일반화 설명과 최근 망각 연구를 직접 검증하는 방향입니다(pp. 181–186). 2504.12501v12 2504.12501v12

#### B. 평가를 평균 점수에서 ‘개선과 손실의 관계’로 바꾸어야 한다

목표 과제의 이득과 함께 비목표 과제의 하락, 출력 다양성, 사실성, 불필요한 거절, 추론 비용을 동시에 기록하는 것이 좋습니다. 특히 **훈련에 쓰지 않은 규칙·언어·시점·사용자 집단**을 별도의 최종 평가로 유지해야 합니다.

**[분석자 제안]** 체크포인트 선택은 개발 평가에서만 수행하고, 최종 평가는 선택 과정에서 한 번도 보지 않은 조건에서 수행해야 합니다. 여러 학습 시드의 평균과 분산을 보고하고, 필요한 반복 수는 기대 효과 크기와 검정력에 맞추어 정하는 것이 적절합니다.

> **용어 설명 — 검정력:** 실제로 차이가 있을 때 통계 검정이 그 차이를 발견할 가능성입니다.

#### C. 보상 모델이 확신하지 못하는 영역을 학습의 핵심 대상으로 삼아야 한다

보상 모델 하나의 점수를 계속 높이기보다, 서로 다른 보상 모델이나 인간 평가자 사이의 불일치를 추적하고, **새로운 유형의 답변에서 평가가 흔들리는 사례를 추가 검토 대상으로 선택하는 방식**을 연구할 가치가 있습니다.

이는 단순한 모델 확대보다 “어떤 선호 정보를 더 수집해야 일반화가 좋아지는가”를 직접 다룹니다. 다만 모델 간 합의가 인간 판단의 정확성을 보장하지는 않으므로 독립적인 인간 검증이 필요합니다(pp. 144–145, 175). 2504.12501v12 2504.12501v12

#### D. 다중 교사 통합을 미관측 복합 과제로 시험해야 한다

MOPD 계열의 다음 중요한 검증은 수학·코드·지시 수행 점수의 단순 합이 아니라, **훈련에서 분리되어 있던 능력을 한 문제 안에서 결합해야 하는 상황**입니다. 예를 들어 새로운 도구를 사용하면서 여러 제약을 지키고, 중간 오류를 복구하며, 최종 결과를 검증해야 하는 과제를 만들 수 있습니다.

교사 선택 정확도뿐 아니라 응답 길이에 따른 학습 예산, 교사 간 중복 편향, 학생이 실제로 방문하는 상태, 교사 호출 비용을 함께 측정해야 합니다. 이 방향은 MOPD·Open-MOPD·MOPD-Router의 결과를 “능력 통합”에서 “새로운 조합에 대한 일반화”로 확장하는 연구입니다. [arXiv](https://arxiv.org/html/2606.30406v1)

### 9.3 최종 평가

**이 책의 가장 큰 학술적 가치는 새 최고 성능을 제시하는 데 있지 않고, 선호 데이터·보상 모델·정책 최적화·규제·평가를 연결해 후속 연구의 공통 기반을 제공하는 데 있습니다.**

일반화에 대한 가장 방어 가능한 결론은 다음과 같습니다.

> **RLHF와 관련 온정책 학습은 특정 조건에서 새로운 입력과 규칙에 대한 성능을 높이고 기존 능력의 손실을 줄일 수 있습니다. 그러나 그 효과는 보상 신호의 신뢰성, 초기 모델의 능력, 학습 데이터의 생성 방식, 최적화 강도, 평가 조건에 의존하며, “RL은 언제나 일반화하고 SFT는 언제나 암기한다”는 보편 명제로 요약할 수 없습니다.**

따라서 앞으로의 연구에서 중요한 목표는 **높은 보상을 받는 모델**을 넘어, **처음 보는 상황에서도 실제로 유용하고, 기존 능력을 덜 잃으며, 다양한 사용자에게 적절한 모델을 만드는 조건을 규명하는 것**입니다.
