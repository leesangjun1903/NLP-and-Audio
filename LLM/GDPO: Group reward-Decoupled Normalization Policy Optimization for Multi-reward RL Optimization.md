## 1. Executive Summary (10문장 이내)

GDPO(Group reward-Decoupled Normalization Policy Optimization)는 NVIDIA 연구팀이 2026년 1월 발표한 다중 보상(Multi-reward) 강화학습 최적화 방법론이다.  
기존에 널리 사용되던 GRPO(Group Relative Policy Optimization)를 다중 보상 환경에 그대로 적용하면, 서로 다른 보상 조합이 동일한 어드밴티지(advantage) 값으로 붕괴(collapse)되는 근본적 문제가 발생한다.  
이 붕괴는 학습 신호의 해상도(resolution)를 낮추고, 정책 업데이트를 부정확하게 만들며, 심각한 경우 학습 조기 실패를 유발한다.  
GDPO는 각 보상을 **개별적으로 그룹 정규화**한 후 합산하고, 이후 **배치 단위 어드밴티지 정규화**를 추가 적용하여 이 문제를 해결한다.  
이 방법은 보상 간 상대적 차이를 더 충실히 보존하여 다중 보상 최적화의 정확도를 높인다.  
저자들은 도구 호출(Tool Calling), 수학적 추론(Math Reasoning), 코딩 추론(Coding Reasoning) 세 가지 태스크에서 GDPO와 GRPO를 비교 실험했다.  
모든 설정에서 GDPO가 GRPO보다 일관되게 우수한 성능을 보였으며, AIME 벤치마크에서 최대 6.3% 정확도 향상을 달성했다.  
추가로, 보상 우선순위 반영을 위한 조건부 보상 함수(conditioned reward function) 설계 전략도 체계적으로 제시한다.  
본 논문은 GRPO의 다중 보상 적용 가능성에 대한 근본적 재검토를 촉구하며, GDPO를 더 안정적이고 선호 정렬된 대안으로 제시한다.

### 1-1. 연구의 목적과 필요성

**목적**: 다중 보상 강화학습(Multi-reward RL) 환경에서 GRPO의 구조적 한계를 극복하는 새로운 정책 최적화 알고리즘 개발

**필요성**:
- LLM이 발전함에 따라 효율성, 안전성, 응답 논리, 성별 편향 등 **다양하고 이질적인 인간 선호**를 단일 모델에서 동시에 만족시킬 필요성이 증가 (p.2)
- 기존 다중 보상 RL 연구들([1],[3],[5] 인용)은 보상 함수 설계에 집중하면서 GRPO를 **검증 없이 그대로 사용**해왔음
- GRPO를 다중 보상에 직접 적용하면 **보상 신호 붕괴(reward signal collapse)** 문제가 발생한다는 사실이 이 연구 이전까지 간과되어 왔음 (p.2, Fig. 2)

> 💡 **용어 설명 — 인간 선호 정렬(Alignment)**: LLM이 인간이 원하는 방식으로 행동하도록 훈련하는 과정. 단순 정확도 외에도 안전성, 간결성, 형식 준수 등 다양한 기준을 동시에 만족해야 한다.

## 2-1. 상세 설명

### 🔴 해결하고자 하는 문제: GRPO의 보상 신호 붕괴

GRPO의 기존 다중 보상 적용 방식은 다음과 같다:

**Step 1: 보상 합산**

$$r_{\text{sum}}^{(i,j)} = r_1^{(i,j)} + \cdots + r_n^{(i,j)} \tag{Eq. 1}$$

- $r_k^{(i,j)}$: $i$번째 질문의 $j$번째 롤아웃에서 $k$번째 목표의 보상값
- $n$: 목표(보상) 개수

**Step 2: 그룹 상대 어드밴티지 계산**

$$A_{\text{sum}}^{(i,j)} = \frac{r_{\text{sum}}^{(i,j)} - \text{mean}\{r_{\text{sum}}^{(i,1)}, \ldots, r_{\text{sum}}^{(i,G)}\}}{\text{std}\{r_{\text{sum}}^{(i,1)}, \ldots, r_{\text{sum}}^{(i,G)}\}} \tag{Eq. 2}$$

- $G$: 그룹 내 롤아웃 수
- $\text{mean}\{\cdot\}$: 그룹 평균
- $\text{std}\{\cdot\}$: 그룹 표준편차

> 💡 **용어 설명 — 어드밴티지(Advantage)**: 어떤 행동이 평균 대비 얼마나 좋은지를 나타내는 값. 양수이면 강화, 음수이면 억제 신호가 된다.

> 💡 **용어 설명 — 롤아웃(Rollout)**: 모델이 주어진 질문에 대해 생성한 응답. GRPO는 그룹(G개)의 롤아웃을 생성하여 상대적 품질을 평가한다.

**붕괴 문제 예시 (p.3, Fig. 2):**

2개의 이진 보상 $r_1, r_2 \in \{0,1\}$, 2개의 롤아웃 가정 시:

| 보상 조합 (롤아웃1, 롤아웃2) | GRPO 어드밴티지 | 실제 의미 |
|---|---|---|
| (0,1), (0,2), (1,2) | $(-0.7071, +0.7071)$ ← **동일** | 실제로는 다른 학습 신호여야 함 |
| (0,0), (1,1), (2,2) | $(0, 0)$ ← **동일** | 구별 불가 |

→ 총 6개 조합 → GRPO는 단 **2개** 어드밴티지 그룹으로 붕괴

**GRPO 최적화 목적 함수:**

$$\mathcal{J}_{\text{GRPO}}(\theta) = \mathbb{E}_{(q_i, o_j) \sim D,\ \{o_j\}_{j=1}^G \sim \pi_{\theta_{\text{old}}}(\cdot|q)} \left[ \frac{1}{G} \sum_{j=1}^{G} \frac{1}{|o_j|} \sum_{t=1}^{|o_j|} \min\left( s_{i,t}(\theta)\, A_{\text{sum}}^{(i,j)},\ \text{clip}(s_{i,t}(\theta), 1-\epsilon, 1+\epsilon)\, A_{\text{sum}}^{(i,j)} \right) \right] \tag{Eq. 3}$$

- $s_{i,t}(\theta) = \dfrac{\pi_\theta(o_j^t \mid q, o_j^{<t})}{\pi_{\theta_{\text{old}}}(o_j^t \mid q, o_j^{<t})}$: 현재 정책과 이전 정책의 토큰 확률 비율 (중요도 비율)
- $\epsilon$: 클리핑 임계값 (정책 업데이트 안정화)
- $|o_j|$: $j$번째 응답의 토큰 길이

> 💡 **용어 설명 — 클리핑(Clipping)**: 정책 업데이트 크기를 제한하는 기법. 너무 큰 업데이트를 방지하여 학습을 안정화한다.

---

### 🟢 제안하는 방법: GDPO

**Step 1: 각 보상을 개별적으로 그룹 정규화 (Decoupled Normalization)**

$$A_1^{(i,j)} = \frac{r_1^{(i,j)} - \text{mean}\{r_1^{(i,1)}, \ldots, r_1^{(i,G)}\}}{\text{std}\{r_1^{(i,1)}, \ldots, r_1^{(i,G)}\}}, \quad \ldots, \quad A_n^{(i,j)} = \frac{r_n^{(i,j)} - \text{mean}\{r_n^{(i,1)}, \ldots, r_n^{(i,G)}\}}{\text{std}\{r_n^{(i,1)}, \ldots, r_n^{(i,G)}\}} \tag{Eq. 4}$$

- $A_k^{(i,j)}$: $k$번째 보상에 대해 개별 정규화된 어드밴티지

**Step 2: 정규화된 어드밴티지 합산**

$$A_{\text{sum}}^{(i,j)} = A_1^{(i,j)} + \cdots + A_n^{(i,j)} \tag{Eq. 5}$$

**Step 3: 배치 단위 어드밴티지 정규화 (수치 안정성 확보)**

```math
\hat{A}_{\text{sum}}^{(i,j)} = \frac{A_{\text{sum}}^{(i,j)} - \text{mean}\!\left\{A_{\text{sum}}^{(i',j')} \mid i' \in D_{\text{Batch}},\, j' = 1,\ldots,G\right\}}{\text{std}\!\left\{A_{\text{sum}}^{(i',j')} \mid i' \in D_{\text{Batch}},\, j' = 1,\ldots,G\right\} + \epsilon}
```

- $D_{\text{Batch}}$: 현재 미니배치 내 질문 인덱스 집합
- $\epsilon$: 수치 안정성을 위한 소수 값

> 💡 **용어 설명 — 배치 정규화(Batch Normalization)**: 미니배치 전체에 걸쳐 값의 평균과 분산을 통일하는 정규화 기법. 보상 개수가 늘어도 어드밴티지 크기가 폭발하지 않도록 방지한다.

**우선순위 가중치 적용 (Eq. 7):**

$$A_{\text{sum}}^{(i,j)} = w_1 A_1^{(i,j)} + \cdots + w_n A_n^{(i,j)} \tag{Eq. 7}$$

- $w_k$: $k$번째 보상의 가중치 (우선순위 반영)

**조건부 보상 함수 (Eq. 8):**

$$r_k = \begin{cases} r_k, & \text{if } r_l \geq t \\ 0, & \text{otherwise} \end{cases} \tag{Eq. 8}$$

- $r_l$: 더 어렵거나 우선순위가 높은 보상
- $t$: 사전 정의된 임계값 (threshold)
- 해석: $r_l$이 충족될 때만 $r_k$를 부여 → 모델이 쉬운 보상부터 먼저 최적화하는 현상(reward hacking) 방지

> 💡 **용어 설명 — Reward Hacking**: 모델이 보상 함수의 허점을 이용해 실제 목적과 무관한 방식으로 높은 보상을 받는 현상.

### 🔵 모델 구조

별도의 새로운 신경망 아키텍처는 제안하지 않음. GDPO는 **기존 GRPO 프레임워크의 어드밴티지 계산 방식을 수정**하는 알고리즘 수준의 방법론이다.

- 적용 모델: Qwen2.5-Instruct (1.5B, 3B), DeepSeek-R1 (1.5B, 7B), Qwen3-4B-Instruct
- 학습 프레임워크: verl [19], HF-TRL, Nemo-RL

## 4. 저자 보고 결과 vs. 내 해석 분리

### 📌 저자가 직접 보고한 결과

**연구 주제**: 다중 보상 RL에서 GRPO의 어드밴티지 붕괴 문제 발견 및 GDPO 제안

**방법**: Eq. 4의 분리 정규화 + Eq. 6의 배치 정규화

**결과** (원문 직접 인용):
- "GDPO achieves almost 5% and 3% improvement on Live/non-Live tasks and gains roughly 2.7% improvement on the overall average accuracy" (p.8)
- "training DeepSeek-R1-1.5B and Qwen3-4B-Instruct with GDPO yields up to 6.3% and 2.3% higher accuracy on AIME compared to GRPO" (p.2)
- "GRPO w/o std... results in a correct format ratio of 0% on BFCL-v3" (p.8)
- "GRPO training starts to destabilize after 400 steps with the correctness rewards score gradually decreasing" (p.9)

### 📌 내 해석 (저자 주장과 구분)

1. **방법의 단순성은 양날의 검**: GDPO는 기존 GRPO 파이프라인에 최소 수정만 필요하다는 점이 실용적 강점이지만, 이는 동시에 더 근본적인 다중 목표 최적화 방법(예: Pareto 최적화, 메타-학습 기반 보상 균형)에 비해 이론적 깊이가 부족할 수 있음을 시사한다.

2. **성능 향상의 원천 불명확**: 저자들은 "더 많은 구별 가능한 어드밴티지 그룹"이 성능 향상의 원인이라고 주장하지만, 이것이 실제 인과관계인지 아니면 배치 정규화의 안정화 효과인지 분리 검증이 부족하다.

3. **쉬운 보상 우선 최적화 문제**: 저자들은 이를 관찰하고 조건부 보상으로 해결하려 하지만, 이 현상 자체는 GDPO의 한계라기보다 다중 목표 RL의 일반적 문제이며, GDPO가 완전히 해결하지는 못한다.

4. **5회 반복 실험**: 도구 호출 태스크에서 5회 반복 실험을 수행했으나, 수학/코딩 태스크에서 반복 횟수가 명시되지 않아 통계적 신뢰도 차이가 있다.

## 7. 가장 중요한 그림 5개 해석

### Figure 1(b) — GDPO vs. GRPO 보상 추이 (p.1)

**내용**: Qwen2.5-Instruct-1.5B 도구 호출 태스크에서 5회 실험의 중앙값(Median) + IQR 밴드

**해석**:
- **형식 보상(Format Reward)**: GDPO(녹색)는 약 40 스텝에서 급격히 수렴하여 1.0에 도달, GRPO(회색)는 수렴 속도가 느리고 분산이 큼
- **정확도 보상(Correctness Reward)**: GDPO는 더 높은 최종 보상 점수(≈+2)에 수렴, GRPO는 낮은 수준(≈+1)에 머뭄
- **시사점**: GDPO의 더 풍부한 어드밴티지 신호가 두 보상을 동시에 더 잘 최적화함을 보여줌
- ⚠️ IQR 밴드가 GDPO에서 더 넓은 구간이 존재 → 수렴 타이밍의 분산이 일부 존재

> 💡 **용어 설명 — IQR(사분위 범위)**: 데이터의 25번째~75번째 백분위 구간. 중앙값 주변 분포의 퍼짐을 나타낸다.

### Figure 2 — GRPO vs. GDPO 어드밴티지 계산 비교 (p.4)

**내용**: 2개 이진 보상, 2개 롤아웃 설정에서 모든 가능한 보상 조합의 어드밴티지 값

**해석**:
- **GRPO** (왼쪽): 9개 조합이 단 2개 그룹으로 붕괴
  - $(-0.7071, +0.7071)$: (0,1), (0,2), (1,2) 동일 처리
  - $(0, 0)$: (0,0), (1,1), (2,2) 동일 처리

  - $(-1.4142, +1.4142)$: (0,2) — 두 보상 모두 극단적 차이
  - $(-0.7071, +0.7071)$: (0,1), (1,2) — 한 보상만 차이
  - $(0, 0)$: (0,0), (1,1), (2,2) — 보상 차이 없음
- **시사점**: GDPO는 (0,2)가 (0,1)보다 더 강한 학습 신호를 주어야 한다는 직관을 수식으로 보존

**내용**: 롤아웃 수(왼쪽)와 보상 수(오른쪽) 증가에 따른 구별 가능한 어드밴티지 그룹 수 변화

**해석**:

- **시사점**: 다중 보상 및 대규모 롤아웃 환경에서 GDPO의 이점이 갈수록 커짐

### Figure 5 — DeepSeek-R1-1.5B 수학 추론 학습 곡선 (p.9)

**내용**: 500 학습 스텝에 걸친 정확도 보상, 길이 보상, 최대 응답 길이 변화

**해석**:
- **초기 단계 (0–100 step)**: GRPO와 GDPO 모두 길이 보상을 빠르게 최대화 (더 쉬운 목표 우선)
- **중기 단계 (100–300 step)**: 정확도 보상 회복 시작. GDPO가 더 빠르게 더 높은 수준으로 회복
- **후기 단계 (300–500 step)**: GRPO는 400 스텝 이후 정확도 보상 **하락** + 최대 응답 길이 **급증**(학습 붕괴 징조). GDPO는 정확도 지속 개선 + 응답 길이 지속 감소
- **핵심 발견**: GDPO가 두 경쟁 보상(정확도 vs. 길이) 사이에서 더 균형 잡힌 최적화를 수행
- ⚠️ **통계적 한계**: 이 곡선이 단일 실험인지 불명확 (반복 수 미명시)

### Figure 6 — 보상 가중치 변화에 따른 성능 분석 (p.10)

**내용**: DeepSeek-R1-7B에서 길이 보상 가중치 $w_{\text{length}} \in \{0.25, 0.5, 0.75, 1.0\}$ 변화 + 조건부 보상 유무에 따른 MATH/AIME 정확도 및 초과율

**해석**:
- **일반 보상($\mathcal{R}_{\text{length}}$, 왼쪽 4개 그래프)**: 가중치를 0.75→0.5로 조정해도 초과율 변화 미미 (GRPO AIME: 0.4%, GDPO AIME: 1.3%). 가중치 0.25까지 줄여야 유의미한 변화
- **조건부 보상($\tilde{\mathcal{R}}_{\text{length}}$, 오른쪽 4개 그래프)**: 가중치 조정이 더 예측 가능하게 반영됨. 0.25→1.0으로 증가 시 초과율이 단조적으로 감소
- **핵심 발견**: 목표 간 난이도 차이가 클 때는 가중치 조정만으로는 부족하며, 조건부 보상 설계가 필요함
- **GDPO 우위**: 조건부 보상 사용 시 GDPO가 GRPO 대비 더 일관되게 정확도 향상 달성 (AIME에서 +4.4%)

## 8. 결론 및 후속 연구

### 8-1. 연구자들이 제시한 시사점

저자들은 결론(p.14)에서 다음을 제시한다:

1. **핵심 발견**: GRPO를 다중 보상에 직접 적용하면 어드밴티지 붕괴 발생 → 부정확한 정책 업데이트 및 학습 실패
2. **GDPO 확립**: "더 안정적이고, 정확하며, 선호 정렬된 최적화 방법"으로서 GRPO의 강력한 대안
3. **실용적 지침**: 보상 우선순위 반영을 위한 가중치 조정 vs. 조건부 보상 함수의 체계적 가이드라인 제공
4. **미래 방향** (원문 명시): 논문 내 명시적인 후속 연구 계획은 제시되지 않음 *(원문에 구체적인 Future Work 섹션 없음)*

### 8-1. 모델 일반화 성능 향상 가능성

**저자 주장에 근거한 일반화 가능성:**

- 3가지 이질적 태스크(도구 호출, 수학, 코딩)에서 모두 효과적 → 태스크 독립적 방법론임을 시사
- 3개 서로 다른 기반 모델(Qwen2.5, DeepSeek-R1, Qwen3)에서 일관된 성능 향상
- 2개 보상 → 3개 보상으로 확장 시에도 효과 유지

**⚠️ 내 해석에 근거한 일반화 한계:**

1. **분포 외(Out-of-Distribution) 일반화**: 모든 실험이 도메인 특화 데이터셋(수학 대회, 코딩 대회)에서 수행. 일반적인 대화나 개방형 태스크에서의 일반화 미검증

2. **보상 간 상관관계 문제**: GDPO는 각 보상을 독립적으로 정규화하지만, 실제로 보상들이 강하게 상관되어 있을 때(예: 형식 준수가 정확도와 매우 연관된 경우) 분리 정규화의 이점이 감소할 수 있음

3. **연속형 보상의 일반화**: 실험의 많은 보상이 이진형({0,1}) 또는 제한된 범위. 연속형 보상(예: 인간 평가 점수)에서의 효과는 미검증

4. **스케일 일반화 가능성**: 이론적으로 Eq. 4–6은 모델 크기에 무관하게 적용 가능하나, 대형 모델(30B+)에서의 실증 검증 필요

**일반화 향상을 위한 추가 후속 연구 방향 (내 제안):**

1. **적응적 보상 가중치 학습**: 정적 가중치 $w_k$ 대신 훈련 진행에 따라 동적으로 가중치를 조정하는 메타-학습 프레임워크 연구

2. **보상 간 상관관계 고려**: 독립 정규화를 가정하는 Eq. 4를 개선하여, 보상 간 공분산을 고려한 Mahalanobis 거리 기반 어드밴티지 계산

3. **연속형 보상 환경 검증**: RLHF 스타일의 학습된 보상 모델(reward model)을 사용하는 환경에서 GDPO 효과 검증

4. **비정상(Non-stationary) 보상 환경**: 보상 함수 자체가 학습 중 변화하는 동적 환경에서의 강건성 연구

> ⚠️ 아래 분석은 논문의 Related Work(p.13-14) 및 참고문헌에 명시된 연구들에만 근거합니다.

#### 논문이 직접 인용한 관련 연구들

| 연구 | 핵심 방법 | GDPO와의 관계 |
|------|----------|--------------|
| GRPO (Shao et al., 2024) [32] | 그룹 상대 어드밴티지 추정 | GDPO의 출발점, 다중보상 한계 존재 |

| DLER (Liu et al., 2025) [36] | 배치 보상 정규화 + 길이 페널티 | GDPO의 수학/코딩 실험 설정 기반 |
| L1 (Aggarwal & Welleck, 2025) [44] | 길이 제어 정책 최적화(LCPO) | 다중보상 RL의 길이 제어 관련 연구 |
| Safe RLHF (Dai et al., 2023) [37] | 도움/무해 분리 선호 최적화 | 다중 보상 설계의 선구적 연구 |
| RLPHF (Jang et al., 2023) [38] | 개인화된 다중 선호 정책 병합 | 다중 보상의 다른 접근법 |
| DeepSeek-R1 (Guo et al., 2025) [8] | 추론 능력 강화를 위한 RL | 실험 기반 모델 |
| DeepSeek V3.2 (DeepSeek-AI, 2025) [40] | 규칙 기반 보상 + 길이 페널티 + 언어 일관성 | 다중 보상 통합의 실제 적용 사례 |
| ToolRL (Qian et al., 2025) [12] | 도구 학습을 위한 보상 기반 RL | GDPO 도구 호출 실험의 기반 |
| GSPO (Zheng et al., 2025) [33] | 시퀀스 수준 클리핑 | GRPO의 안정성 개선 변형 |
| GFPO (Shrivastava et al., 2025) [35] | 그룹 필터링을 통한 길이 효율화 | 길이 효율성 측면 보완 연구 |

#### 앞으로의 연구에 미치는 영향

1. **다중 보상 RL의 표준 방법론 재정립**: GDPO는 향후 다중 보상 RL 연구에서 단순 GRPO 합산 방식을 사용하는 것에 대한 재검토를 촉구. 새로운 연구들이 GDPO를 기본 베이스라인으로 채택할 가능성이 높음

2. **보상 설계와 최적화 알고리즘의 공동 연구**: 이 논문은 보상 함수 설계(조건부 보상, 가중치 조정)와 최적화 알고리즘(GDPO)을 함께 고려해야 함을 보임. 두 측면을 분리하지 않는 통합 연구 방향 제시

3. **정보 이론적 접근의 필요성**: GDPO의 핵심 개선이 "정보 손실 방지"에 있는 만큼, 향후 연구에서는 정보 이론(상호 정보량, 엔트로피)을 활용한 어드밴티지 추정 방법론 연구가 촉진될 것

#### 앞으로 연구 시 고려할 점

1. **std=0 엣지 케이스**: Eq. 4에서 특정 보상의 std가 0이면 수치 불안정. 실제 구현 시 엡실론 처리 또는 대체 정규화 전략 필요

2. **보상 스케일 이질성**: 서로 다른 범위의 보상(예: $\mathcal{R}\_{\text{format}} \in \{0,1\}$ vs. $\mathcal{R}_{\text{correct}} \in [-3,3]$ )을 개별 정규화하면 사실상 동등한 가중치가 부여됨. 의도적 우선순위 조정 시 Eq. 7의 가중치가 더 중요해짐

3. **KL 발산 항의 역할**: 본 논문은 KL 항을 "명확성을 위해 생략"했으나, 실제 학습에서 KL 페널티가 다중 보상 간 균형에 영향을 줄 수 있음. KL과 다중 보상의 상호작용 연구 필요

4. **오픈소스 재현성**: HF-TRL, verl, Nemo-RL 세 프레임워크에서 구현을 공개한 것은 긍정적이나, 정확한 수치 재현을 위한 하이퍼파라미터 민감도 분석 연구 필요

5. **장기 학습(Long-horizon Training)**: 실험 최대 500 스텝 설정은 비교적 단기. 수천 스텝 이상의 장기 학습에서 GDPO의 안정성과 수렴 특성 연구 필요
