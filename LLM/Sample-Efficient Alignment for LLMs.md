## 1. Executive summary

이 연구는 대규모 언어모델을 사람의 선호에 맞추는 과정에서 비싼 선호 평가를 얼마나 적게 요청할 수 있는지를 다룹니다.  
저자들은 이를 프롬프트에 대한 두 응답을 비교하며 학습하는 문제로 정식화하고, 실제 서비스 중 응답 품질을 유지해야 하는 상황과 별도 평가자를 통해 최종 모델을 개선하는 상황을 구분합니다. **[pp. 2–4]** 2411.01493v2 2411.01493v2

제안 방법인 SEA는 생성 모델과 보상 추정 모델을 함께 갱신하면서, 좋은 응답과 학습에 도움이 되는 응답을 전략적으로 골라 평가받습니다.  
또한 외부 평가자가 제공한 선호와 내부 보상 모델이 만든 합성 선호를 섞어 사용함으로써 외부 피드백을 재활용합니다. **[pp. 6–8, Algorithm 1; p. 16, Algorithm 2]** 2411.01493v2 2411.01493v2

저자들은 TL;DR 요약 과제에서 1B·2.8B·6.9B 모델과 세 가지 선호 학습 손실을 시험하고, 주요 비교에서 약 2~5배의 질의 표본 효율 개선을 보고합니다.  
그러나 실험의 선호 제공자는 실제 인간이 아니라 보상 모델 또는 GPT-4o-mini이며, 각 실험은 세 번의 독립 실행으로 평가되었습니다. **[p. 9, Figures 1·5; pp. 11, 19]** 2411.01493v2 2411.01493v2 2411.01493v2

따라서 이 논문은 동일 과제의 미사용 프롬프트에서 평가자의 선호를 더 적은 질의로 학습한다는 근거는 제공하지만, 새로운 도메인·언어·인간 집단에 대한 일반화 향상을 입증하지는 않습니다.  
연구적 가치는 새로운 선호 손실 자체보다 **온라인 데이터 수집, 불확실성 기반 응답 선택, 생성 정책 갱신을 결합한 설계**에 있으며, 광범위한 일반화와 실제 비용 절감은 후속 검증이 필요합니다. **[pp. 7–10, 19에 근거한 해석]** 2411.01493v2 2411.01493v2

## 2. 연구의 목적과 필요성

### 2.1 무엇을 해결하려는가?

**[저자 보고]** 핵심 문제는 단순히 “선호 데이터가 부족하다”가 아니라, **제한된 평가 예산을 어떤 응답 비교에 배분해야 모델이 가장 빨리 개선되는가**입니다. 저자들은 이를 위해 두 조건을 강조합니다. 첫째, 최신 모델이 만든 데이터를 즉시 학습하는 온라인 상호작용이 필요하고, 둘째, 무작위로 응답을 평가받는 대신 개선에 도움이 되는 응답을 고르는 능동적 탐색이 필요합니다. **[p. 2, Properties 1·2]** 2411.01493v2

> **용어 — 온라인 학습:** 모델을 한 번 학습하고 끝내지 않고, 새 피드백을 얻을 때마다 갱신하는 방식입니다. 여기서 “온라인”은 인터넷 연결 여부가 아닙니다.  
> **용어 — 능동적 탐색:** 아직 잘 모르는 응답을 전략적으로 시험하여, 다음 학습에 유용한 정보를 얻는 과정입니다.

기존 오프라인 방법은 고정 데이터에 의존하므로, 개선된 모델이 새롭게 생성하는 응답 영역을 충분히 평가하지 못할 수 있습니다. 반대로 온라인으로 전환하더라도 응답을 수동적으로 추출하기만 하면, 이미 잘 아는 비교에 평가 예산을 낭비할 수 있다는 것이 저자의 문제의식입니다. **[pp. 4–5]** 2411.01493v2 2411.01493v2

> **용어 — 오프라인 학습:** 이미 수집된 고정 데이터만으로 학습하는 방식입니다.  
> **용어 — 데이터 커버리지:** 학습 데이터가 가능한 질문·응답의 여러 영역을 얼마나 넓게 포함하는지를 뜻합니다.

## 4. 제안 방법과 모델 구조: 수식 중심 설명

### 4.1 정식화: 문맥적 쌍대 비교 밴딧

**[저자 보고]** 프롬프트를 문맥, 완성된 응답을 행동, 두 응답 중 하나를 고르는 선호 피드백을 관측값으로 취급합니다. 이때 한 행동은 개별 토큰이 아니라 **응답 전체**입니다. **[pp. 2–3, Figure 2]** 2411.01493v2 2411.01493v2

> **용어 — 문맥적 쌍대 비교 밴딧:** 주어진 상황에서 두 선택지를 제시하고, 어느 쪽이 더 좋은지만 관찰하며 학습하는 문제입니다. 절대 점수를 직접 받지 않는다는 점이 특징입니다.

논문은 선호 확률에 Bradley–Terry 가정을 사용합니다.

```math
\mathcal P(y\succ y'\mid x)
=
\frac{\exp(r^\star(x,y))}
{\exp(r^\star(x,y))+\exp(r^\star(x,y'))}
=
\sigma\!\left(r^\star(x,y)-r^\star(x,y')\right).
```

**기호 설명:** $x$는 프롬프트, $y,y'$는 두 응답, $\mathcal P$는 선호 확률을 제공하는 환경, $\succ$는 “더 선호됨”, $r^\star$는 숨겨진 참 보상 함수입니다. $\sigma(u)=1/(1+e^{-u})$는 시그모이드 함수입니다. **[p. 3, Eq. 3]** 2411.01493v2

> **용어 — Bradley–Terry 모델:** 두 응답의 잠재적 점수 차이가 클수록 높은 점수의 응답을 선택할 확률이 커진다고 가정하는 비교 모델입니다.  
> **주의:** 이 가정은 복잡한 인간 선호를 하나의 스칼라 점수로 표현할 수 있다고 보는 모델링 선택이지, 논문이 입증한 인간 심리 법칙은 아닙니다.

이 가정 아래 저자가 추구하는 정책 목표는 다음과 같습니다.

```math
\pi^\star\in\arg\max_\pi J(\pi),
\qquad
J(\pi)
=
\mathbb E_{x\sim p_X}
\mathbb E_{y\sim\pi(\cdot\mid x)}
\left[r^\star(x,y)\right].
```

**기호 설명:** $\pi$는 프롬프트별 응답 생성 분포인 정책, $\pi^\star$는 최적 정책, $p_X$는 프롬프트 분포, $J$는 평균 보상, $\mathbb E$는 기댓값입니다. **[p. 3, Eq. 4]** 2411.01493v2

논문은 이를 모든 다른 정책에 평균적으로 이기거나 비기는 정책이라는 *von Neumann winner* 개념과 연결합니다. 다만 실제 SEA는 위의 스칼라 보상 가정을 채택하므로, 일반적인 순환적 선호까지 다룬다고 해석하면 안 됩니다. **[p. 3, Eqs. 1–4]** 2411.01493v2

> **용어 — 순환적 선호:** A보다 B, B보다 C, C보다 A를 선호하는 상황입니다. 하나의 고정된 점수 순서로는 이런 관계를 그대로 표현할 수 없습니다.

> **용어 — 보상 모델:** 응답의 선호도를 점수로 예측하는 모델입니다.

### 4.3 첫 번째 구성요소: 불확실성을 추정하는 보상 모델

개별 보상 모델은 선호 응답의 점수가 비선호 응답보다 높아지도록 학습됩니다.

```math
\mathcal L_r(\phi\mid D)
=
-\mathbb E_{(x,y^+,y^-)\sim p_D}
\left[
\log\sigma\!\left(
r_\phi(x,y^+)-r_\phi(x,y^-)
\right)
\right].
```

**기호 설명:** $\phi$는 보상 모델의 학습 파라미터, $D$는 수집한 선호 데이터, $p_D$는 그 데이터에서 표본을 뽑는 분포, $y^+$와 $y^-$는 각각 선호·비선호 응답, $\mathcal L_r$는 손실입니다. **[p. 4, Eq. 5]** 2411.01493v2

앙상블 학습 손실은 원문에 다음처럼 인쇄되어 있습니다.

```math
\mathcal L_R(\Phi^t\mid D_t)
=
\sum_{k=1}^{K}
\left[
\mathcal L_r(\phi_k^t\mid D_t)
-
\lambda\left\|\phi_k^t-\phi_k^0\right\|
\right].
```

**기호 설명:** $K$는 보상 헤드 수, $\Phi^t=\{\phi_k^t\}_{k=1}^{K}$는 시점 $t$의 전체 헤드 파라미터, $\phi_k^0$는 각 헤드의 초기 파라미터, $\lambda$는 규제 계수입니다. **[p. 7, Eq. 8]** 2411.01493v2

**[수식 검토: 중요한 불일치]** 저자는 이 항을 “각 초기 가중치 쪽으로 정규화”한다고 설명하지만, 원문 식에는 **마이너스 부호**가 있습니다. $\lambda>0$에서 이 손실을 최소화하면 해당 항은 초기값과의 거리를 줄이는 대신 늘리는 방향으로 작용합니다. 따라서 **수식과 설명 사이에 불일치가 있으며, 오탈자인지 실제 구현 차이인지는 논문만으로 확정할 수 없습니다.** 임의로 플러스 부호로 고쳐서 원문 수식인 것처럼 제시해서는 안 됩니다.

논문의 ERM은 이러한 앙상블로 보상 함수의 불확실성을 근사하고, 헤드 하나를 무작위로 고르는 것을 보상 함수의 사후 표본 추출로 사용합니다. **[p. 7, §4.2.1]** 2411.01493v2

> **용어 — ERM:** 이 논문에서는 *Epistemic Reward Model*, 즉 지식 부족에 따른 불확실성을 표현하는 보상 모델입니다. 흔히 쓰이는 ‘경험적 위험 최소화’와 다른 약어입니다.  
> **용어 — 사후분포:** 관측한 데이터를 반영한 뒤 가능한 보상 함수들에 부여하는 확률분포입니다.  
> **주의:** 앙상블에서 헤드를 고르는 것은 정확한 베이지안 사후분포 추출이 아니라 실용적인 근사입니다.

### 4.4 두 번째 구성요소: 정책이 제안한 후보 안에서 탐색

**[저자 보고]** 가능한 모든 문장 중 최적 응답을 직접 찾는 것은 계산상 어렵기 때문에, 최신 생성 정책에서 후보를 추출한 뒤 그 안에서 선택합니다. **[pp. 6–7, §4.2.2]** 2411.01493v2 2411.01493v2

$$
S_t=\{y_t^i\}_{i=1}^{M},
\qquad
y_t^i\sim\pi_{\theta_{t-1}}(\cdot\mid x_t).
$$

$$
k\sim\text{Uniform}(\{1,\ldots,K\}),
\qquad
y_t=\arg\max_{b\in S_t}r_{\phi_k}(x_t,b).
$$

**기호 설명:** $S_t$는 후보 응답 집합, $M$은 후보 수, $y_t^i$는 $i$번째 후보, $k$는 무작위로 고른 보상 헤드 번호, $b$는 후보 응답을 나타내는 변수입니다. 실험에서는 $M=20$, $K=20$입니다. **[p. 16, Algorithm 2; p. 19]** 2411.01493v2 2411.01493v2

> **용어 — Thompson sampling:** 현재 그럴듯한 보상 모델 하나를 무작위로 선택한 뒤, 그 모델이 가장 좋다고 보는 행동을 고르는 탐색 방법입니다.

두 번째 응답은 목적에 따라 달라집니다.

**E&E에서는** 다른 보상 헤드를 다시 추출하고, 그 헤드가 가장 좋다고 평가하는 응답을 고릅니다. 첫 응답과 같으면 반복합니다. **[p. 6, Algorithm 1, Line 5]** 2411.01493v2

**BAI에서는** 첫 응답과 비교했을 때 헤드 간 선호 예측의 분산이 가장 큰 응답을 고릅니다.

```math
y'_t
=
\arg\max_{b\in S_t}
\text{Var}_{k}
\left[
\sigma\!\left(
r_{\phi_k}(x_t,y_t)-r_{\phi_k}(x_t,b)
\right)
\right].
```

**기호 설명:** $y'\_t$는 두 번째 비교 응답, $\text{Var}_{k}$는 보상 헤드들 사이의 분산입니다. 나머지 기호는 위와 같으며, 시그모이드 안의 값은 첫 응답과 후보 응답의 보상 차이입니다. **[p. 16, Algorithm 2, Line 7]** 2411.01493v2

**[해석]** 핵심은 “모델들이 선호 순위에 동의하지 않는 비교”를 찾아 평가받는다는 것입니다. 예를 들어 모든 헤드가 선호 확률을 0.5로 예측하면 헤드 간 분산은 0이지만, 절반은 0.9, 절반은 0.1로 예측하면 분산은 큽니다. 후자는 이 앙상블이 표현하는 지식 부족을 줄일 가능성이 더 큰 비교입니다. 다만 분산 최대화가 실제 정보 획득량이나 정책 개선량을 항상 최대화한다는 정리는 제시되지 않습니다.

### 4.5 세 번째 구성요소: 외부 선호와 합성 선호를 혼합

```math
p_{B_t^{\text{mix}}}
=
\gamma p_{B_t}
+
(1-\gamma)p_{B_t^{\text{ERM}}}.
```

```math
\mathcal L_\pi(\theta_t)
=
\mathbb E_{(x,y^+,y^-)\sim p_{B_t^{\text{mix}}}}
\left[
F_{\theta_t}(x,y^+,y^-,\pi_{\text{ref}})
\right].
```

**기호 설명:** $B_t$는 외부 오라클이 라벨링한 배치, $B_t^{\text{ERM}}$은 내부 보상 헤드가 라벨링한 배치, $\gamma$는 외부 선호의 혼합 비율, $F$는 DPO·IPO·SLiC 등의 선호 손실입니다. $\theta_t$는 생성 정책의 파라미터입니다. 두 번째 식은 원문 Eq. 9에 혼합 분포를 대입한 표현입니다. **[pp. 7–8, Eq. 9 및 §4.2.3]** 2411.01493v2

실험에서는 처음 1,000개 표본 동안 $\gamma=1$로 외부 피드백만 사용하고, 이후 $\gamma=0.7$로 바꿉니다. 중요한 안전장치는 **합성 선호를 보상 모델의 경험 저장소 $D_t$에는 넣지 않는 것**입니다. 보상 모델은 외부 피드백으로만 학습하고, 생성 정책만 혼합 데이터를 사용합니다. **[pp. 16, 19]** 2411.01493v2 2411.01493v2

> **용어 — 합성 선호·의사 라벨:** 실제 외부 평가를 새로 받지 않고, 현재 모델이 추정해 만든 선호 라벨입니다.  
> **용어 — Dyna:** 실제 경험으로 내부 모델을 학습하고, 그 내부 모델이 제공하는 가상 경험도 정책 학습에 활용하는 구조입니다. 저자들은 SEA를 이 관점으로 해석합니다. **[p. 17, Appendix B]** 2411.01493v2

**[해석]** 합성 선호가 보상 모델에 직접 되먹임되는 경로는 차단되어 있지만, 생성 정책이 잘못된 합성 선호에 적응할 위험까지 없어지는 것은 아닙니다. 또한 논문의 “ERM sync”는 생성 정책과 보상 모델의 **가중치를 복사한다는 뜻이 아니라**, 합성 선호 학습을 통해 생성 정책을 보상 모델에 맞춘다는 의미입니다.

### 4.6 정책 손실: DPO·IPO·SLiC

표현을 간단히 하기 위해 다음 로그 비율 차이를 정의하겠습니다.

```math
\Delta_\theta
=
\log\frac{\pi_\theta(y^+\mid x)}
{\pi_{\text{ref}}(y^+\mid x)}
-
\log\frac{\pi_\theta(y^-\mid x)}
{\pi_{\text{ref}}(y^-\mid x)}.
```

**기호 설명:** $\Delta_\theta$는 기준 정책에 비해 선호 응답을 얼마나 더 상대적으로 선호하도록 바뀌었는지를 나타냅니다. $\pi_\theta$는 학습 정책, $\pi_{\text{ref}}$는 기준 정책입니다.

주논문 부록의 세 손실은 다음과 같이 다시 쓸 수 있습니다.

$$
F_{\text{DPO}}=-\log\sigma(\beta\Delta_\theta),
$$

```math
F_{\text{IPO}}
=
\left(\Delta_\theta-\frac{1}{2\beta}\right)^2,
```

```math
F_{\text{SLiC}}
=
\max\left(0,\,1-\beta\Delta_\theta\right).
```

**기호 설명:** $F$는 한 선호 쌍의 손실이고, $\beta$는 기준 정책 대비 변화 정도를 조절하는 하이퍼파라미터입니다. 위 식들은 **SEA 논문이 사용한 정의**이며, 각각 원문 Eqs. 10–12에 대응합니다. **[p. 16]** 2411.01493v2

> **용어 — DPO:** 선호 응답과 비선호 응답의 상대 확률을 직접 조정하는 방법입니다.  
> **용어 — IPO:** 위 상대 로그 비율 차이를 정해진 목표값에 맞추는 제곱 손실을 사용합니다.  
> **용어 — SLiC:** 선호 응답이 일정한 차이 이상 우세하도록 만드는 마진 손실을 사용합니다.  
> **주의:** 여기의 SLiC 식을 SLiC-HF의 모든 구현 및 부가 손실과 동일하다고 일반화해서는 안 됩니다.

**[해석]** SEA의 핵심은 이 세 손실 중 하나를 새로 발명한 데 있지 않습니다. **어떤 데이터를 얻을지 결정하는 탐색 절차를, 어떤 손실로 정책을 학습할지와 분리한 것**이 구조적 장점입니다.

> **용어 — 표준오차:** 평균 추정의 불확실성을 나타내는 값입니다. 개별 실행의 흩어짐을 나타내는 표준편차나 95% 신뢰구간과 다릅니다.  
> **용어 — 외적 타당성:** 관찰된 결과가 실험 밖의 환경에도 적용되는 정도입니다.

**[통계적 해석]** 예를 들어 실행별 성능이 독립적인 정규 표본이라는 가정을 추가하더라도, 실행 수가 3이면 평균의 95% t-신뢰구간은 다음과 같습니다.

$$
\bar W\pm t_{0.975,2}\frac{s}{\sqrt 3}
\approx
\bar W\pm4.303\,\text{SE}.
$$

**기호 설명:** $\bar W$는 세 실행의 평균 승률, $s$는 실행 간 표본 표준편차, $\text{SE}=s/\sqrt3$, $t_{0.975,2}$는 자유도 2인 t분포의 분위수입니다. 이는 **논문이 보고한 신뢰구간이 아니라**, 세 실행의 표준오차를 해석하기 위한 계산입니다.

따라서 그림의 좁은 표준오차 띠만으로 모든 방법 차이가 높은 확신으로 구분된다고 판단하면 안 됩니다.

### 6.2 “표본 효율”에는 추가 정책 업데이트 효과도 포함될 수 있다

**[해석]** $\gamma=0.7$인 구간에서 외부 라벨과 합성 라벨 배치가 알고리즘처럼 선택된다면, 이상화된 집계에서 같은 외부 라벨 수에 대해 전체 정책 업데이트 기회는 외부 라벨만 사용할 때의 약 $1/0.7\approx1.43$배가 될 수 있습니다. 이는 실측 업데이트 수가 아니라 혼합 규칙에서 나오는 계산입니다. **[p. 16, Algorithm 2]** 2411.01493v2

이 자체는 문제가 아닙니다. 오히려 외부 피드백을 효율적으로 활용한다는 목표에 부합합니다. 다만 **응답 선택의 질, 합성 데이터 활용, 추가 계산의 효과를 분리하려면 업데이트 수와 생성 토큰 수를 맞춘 대조군이 더 필요합니다.**

### 6.3 보상 기반 regret과 선호 확률 기반 regret은 동일한 식이 아니다

논문은 p. 3에서 선호 확률 기반 regret을 정의한 뒤, BT 가정 아래 보상 기반 식으로 “다시 쓸 수 있다”고 설명합니다. 두 식을 구분하기 위해 위첨자를 붙이면 다음과 같습니다. 2411.01493v2 2411.01493v2

```math
R_t^{\text{pref}}
=
\mathcal P(y_t^\star\succ y_t\mid x_t)
+
\mathcal P(y_t^\star\succ y'_t\mid x_t)-1,
```

```math
R_t^{\text{reward}}
=
r^\star(x_t,y_t^\star)
-
\frac{r^\star(x_t,y_t)+r^\star(x_t,y'_t)}{2}.
```

**기호 설명:** $y_t^\star$는 최적 응답, $R_t^{\text{pref}}$는 선호 확률 기반 손실, $R_t^{\text{reward}}$는 잠재 보상 격차 기반 손실입니다. 위첨자는 설명을 위해 추가했습니다.

**[수학적 검토]** BT 가정만으로 두 식이 수치적으로 같아지지는 않습니다. 최적 응답 보상을 1, 두 비교 응답의 보상을 모두 0으로 두면 첫 식은 약 0.462, 둘째 식은 1입니다. 따라서 두 식은 **최적 행동을 향하도록 하는 관련된 척도**로 이해해야 하며, 정확한 대수적 등식으로 취급하면 안 됩니다.

> **용어 — regret:** 최선의 행동을 했을 때와 비교하여 발생한 손실 또는 기회비용입니다.

### 6.4 이론에서 실제 SEA까지의 보장은 별도로 필요하다

**[저자 보고]** 저자들은 밴딧 이론과 Thompson sampling의 통찰을 활용하지만, 실제 구현에서는 사후분포·전역 최적화·정책 학습을 모두 근사합니다. **[pp. 6–7]** 2411.01493v2 2411.01493v2

**[해석]** 첨부 버전에는 이러한 근사를 모두 포함한 SEA 전체의 새로운 유한 표본 복잡도 정리가 제시되어 있지 않습니다. 따라서 **“이론에서 착안한 알고리즘”과 “실제 Transformer 구현 전체가 이론적으로 보장된 알고리즘”은 구분해야 합니다.**

또한 p. 11의 “품질이 비슷한 두 응답은 더 작은 DAP 그래디언트를 만들 수 있다”는 설명은 일반적인 수학적 결론으로 읽기 어렵습니다. 앞서 정의한 DPO 손실은 다음을 만족합니다.

```math
\frac{\partial F_{\text{DPO}}}{\partial\Delta_\theta}
=
-\beta\sigma(-\beta\Delta_\theta).
```

즉 기울기는 실제 오라클 보상 차이만이 아니라 정책의 상대 로그 확률과 파라미터 기울기에 의존합니다. 이 부분은 **실험 경향에 대한 저자의 설명 가설**로 보는 편이 적절합니다. **[주논문 p. 11; DPO 원논문 p. 5]** 2411.01493v2 [arXiv](https://arxiv.org/pdf/2305.18290)

## 7. 핵심 쟁점: 모델의 일반화 성능이 좋아질 가능성

### 7.1 실제로 확인된 일반화의 범위

**[저자 보고]** 학습에 사용하지 않은 고정 프롬프트 집합을 평가하고, 여러 모델 크기와 손실에서 결과를 비교합니다. **[pp. 9, 19]** 2411.01493v2 2411.01493v2

**[해석]** 이는 다음 두 사실을 뒷받침합니다. 하나는 동일 요약 과제의 미사용 입력에 대한 성능 향상이고, 다른 하나는 알고리즘 효과가 여러 모델 크기·손실에서 관찰된다는 것입니다. 그러나 후자는 엄밀히 말해 **알고리즘의 적용 견고성**이지, 한 모델이 새 도메인에 일반화했다는 증거는 아닙니다.

**[미검증]** 첨부 버전은 요약에서 대화·수학·코딩으로의 전이, 영어에서 다른 언어로의 전이, 학습 평가자에서 독립 인간 평가자로의 전이, 시간에 따른 선호 변화에 대한 적응을 보고하지 않습니다.

### 7.2 일반화에 도움이 될 수 있는 작동 원리

**[해석: 검증할 가치가 있는 가설]**

첫째, 정책을 계속 갱신하면 고정 데이터에 없던 응답을 만들고 평가받을 수 있으므로, 변화하는 응답 분포에 대한 데이터 부족을 줄일 가능성이 있습니다. 둘째, 헤드 간 의견이 갈리는 비교에 외부 피드백을 배분하면, 같은 예산으로 더 많은 판단 경계를 학습할 수 있습니다. 셋째, Figure 6의 정책 단독 추론 개선은 학습한 선호가 생성 모델 안에 반영됨을 보여주므로, 단순한 추론 시 재순위화보다 넓은 활용 가능성이 있습니다. **[pp. 7, 10에 근거한 해석]** 2411.01493v2 2411.01493v2

다만 이 가능성은 보상 모델의 불확실성이 실제 오류와 관련되고, 새로 생성된 응답이 유용한 영역을 포함하며, 외부 평가자가 그 응답을 신뢰성 있게 판단한다는 조건에 의존합니다.

### 7.3 중요한 병목: 후보로 나오지 않는 좋은 응답은 선택할 수 없다

**[알고리즘에서 도출한 해석]** 한 프롬프트에서 좋은 응답 영역에 후보 하나가 들어갈 확률을 $q_t$라고 하고 후보 $M$개가 독립적으로 추출된다고 가정하면, 좋은 후보를 하나 이상 얻을 확률은 다음과 같습니다.

```math
\Pr(\text{좋은 후보를 하나 이상 얻음})
=
1-(1-q_t)^M.
```

**기호 설명:** $q_t$는 최신 정책이 좋은 응답 영역에 부여하는 총확률, $M$은 후보 수입니다. 이는 논문의 실험 결과가 아니라 후보 추출 구조에서 도출한 확률식입니다. **구조 근거: p. 16, Algorithm 2, Line 4.** 2411.01493v2

예를 들어 $q_t=0.01$, $M=20$이면 확률은 약 18.2%입니다. 즉 보상 모델이 완벽하더라도 대부분의 후보 집합에는 좋은 응답이 없을 수 있습니다.

따라서 SEA는 후보 선택을 개선하지만 **생성 정책의 실질적인 탐색 범위 문제를 완전히 제거하지는 않습니다.** 일반화 향상을 위해서는 좋은 후보의 발견 가능성 자체를 높이는 생성 다양성·다중 제안 정책·프롬프트 선택 전략도 중요해집니다.

### 7.4 일반화를 방해할 수 있는 경로

**[해석]** 같은 동결 표현을 공유한 헤드들이 새로운 도메인에서 함께 틀릴 수 있고, 잘못된 합성 선호가 생성 정책을 편향시킬 수 있으며, 단일 평가자가 좋아하는 표현 양식을 과도하게 학습할 수도 있습니다. 또한 프롬프트 자체는 분포에서 주어지고 SEA는 주로 응답 쌍을 선택하므로, 중요한 희귀 도메인이 입력 단계에서 거의 나타나지 않는 문제까지 해결하지는 않습니다. **[구조 근거: pp. 7, 16, 19]** 2411.01493v2 2411.01493v2 2411.01493v2

> **용어 — 보상 해킹:** 실제로 원하는 품질을 높이는 대신, 평가 모델이 높은 점수를 주는 허점을 이용하는 현상입니다. 여기서는 발생이 입증되었다는 뜻이 아니라, 독립 평가로 점검해야 할 위험을 뜻합니다.

**종합하면, SEA가 일반화를 개선할 만한 경로는 있지만, 주논문의 실증적 결론은 “일반화 개선이 입증되었다”보다 “일반화 개선을 시험할 유망한 학습 구조를 제시했다”에 가깝습니다.**

### 8.2 후속 연구와 연결되는 수학적 차이

#### COPO: “의견이 갈리는가?” 대신 “얼마나 적게 보았는가?”

COPO 원문 Eq. 16을 최소화 손실 형태로 다시 쓰면 다음 구조입니다.

```math
\mathcal L_{\text{COPO}}
=
\mathcal L_{\text{DPO}}
-
\alpha
\mathbb E_{x,y}
\left[
\frac{1}{\sqrt{\widehat N_t(x,y)+\lambda_c}}
\right].
```

**기호 설명:** $\widehat N_t(x,y)$는 과거 데이터에서 해당 프롬프트·응답을 관측한 정도의 근사값, $\alpha$는 탐색 강도, $\lambda_c$는 분모를 안정화하는 상수입니다. $\lambda_c$는 SEA의 규제 계수와 혼동하지 않도록 원문의 기호에 아래첨자를 붙였습니다. [arXiv](https://arxiv.org/html/2501.12735)

> **용어 — 의사 방문 횟수:** 문장이 정확히 몇 번 반복되었는지뿐 아니라, 유사한 입력·응답을 얼마나 학습했는지를 근사하는 값입니다.

**[해석]** SEA는 평가 모델들의 불일치를 활용하고, COPO는 데이터의 희소성을 활용합니다. 두 신호는 다르므로 결합 가능성이 있지만, 드문 응답이 항상 유용한 응답인 것은 아니라는 점도 고려해야 합니다.

**[저자 보고 수치]** COPO의 Llama-3-8B-Instruct, 3회 반복 조건에서 AlpacaEval 2.0의 길이 보정 승률은 Online DPO 33.17%, COPO 35.54%입니다. 차이는 2.37퍼센트포인트입니다. **[p. 9, Table 1]** [arXiv](https://arxiv.org/pdf/2501.12735)

**[직접 비교 불가]** 이 수치와 SEA의 TL;DR 승률은 평가 과제·비교 응답·평가자·예산이 다르므로 직접 비교할 수 없습니다.

#### ActiveDPO: 정책 파라미터 관점의 불확실성

ActiveDPO의 응답 쌍 선택 기준은 다음처럼 표현할 수 있습니다.

```math
g_t(x,y_1,y_2)
=
\nabla_\theta
\left[
r_{\theta_{t-1}}(x,y_1)
-
r_{\theta_{t-1}}(x,y_2)
\right],
```

```math
u_t(x,y_1,y_2)
=
\sqrt{
g_t(x,y_1,y_2)^\top
V_{t-1}^{-1}
g_t(x,y_1,y_2)
}.
```

**기호 설명:** $r_\theta$는 정책으로 매개화된 암묵적 보상, $\nabla_\theta$는 정책 파라미터에 대한 기울기, $g_t$는 두 응답의 보상 차이에 대한 기울기, $V_{t-1}$는 이전에 선택한 표본의 기울기 정보로 구성하는 행렬, $u_t$는 선택 점수입니다. 원문 Eq. 3은 이 점수가 큰 프롬프트·응답 쌍을 고릅니다. **[p. 4]** [ICLR Proceedings](https://proceedings.iclr.cc/paper_files/paper/2026/file/24b4531f1ed8d6581530cfde9f47a80b-Paper-Conference.pdf)

**[해석]** SEA의 다음 발전 방향 중 하나는 “보상 모델이 모르는 비교”를 넘어서 **“그 비교를 학습했을 때 생성 정책이 얼마나 유용하게 바뀌는가”**를 직접 고려하는 것입니다.

다만 ActiveDPO도 정리의 기반은 넓은 완전연결 신경망에 관한 가정이며, Transformer로의 완전한 이론 확장은 후속 과제로 남겨 둡니다. 따라서 최신 연구라는 이유로 이론·구현 간 간극이 해결되었다고 말해서는 안 됩니다. **[p. 15, Appendix A.2]** [ICLR Proceedings](https://proceedings.iclr.cc/paper_files/paper/2026/file/24b4531f1ed8d6581530cfde9f47a80b-Paper-Conference.pdf)

### 8.3 이 연구가 이후 연구에 미치는 영향

**[외부 문헌에서 확인되는 사실]** ActiveDPO는 SEA를 관련 능동적 선호 선택 연구로 직접 인용하면서, 이론적 근거와 정책 자체를 고려하는 선택 기준의 필요성을 논의합니다. 따라서 SEA가 후속 연구의 비교·문제 설정에 포함된다는 것은 확인할 수 있습니다. [arXiv](https://arxiv.org/html/2505.19241)

**[해석]** SEA의 지속적인 영향은 특정 승률 기록보다, **온라인 갱신 주기, 데이터 선택, 보상 불확실성, 합성 데이터 재사용을 함께 통제해야 한다는 연구 설계**에 있을 가능성이 큽니다. 이후 연구는 새 선택 함수의 성능만 제시하기보다, 일반화·평가자 편향·계산 예산까지 함께 검증해야 합니다.

## 10. 결론과 후속 연구 방향

### 10.1 저자들이 제시한 시사점과 후속 계획

**[저자 보고]** 저자들은 온라인 상호작용과 능동적 탐색을 결합하고, 내부 보상 모델을 활용해 외부 피드백을 재사용하면 정렬의 표본 효율을 개선할 수 있다고 결론 내립니다. 또한 공개한 `oat` 시스템이 완전 온라인 실험과 공정한 알고리즘 비교를 촉진하기를 기대합니다. **[p. 11, Conclusion]** 2411.01493v2

명시적으로 남긴 후속 과제에는 **비정상적 데이터에서의 파국적 망각**과 **비동기 데이터 수집을 통한 시스템 활용도 개선**이 있습니다. **[p. 17, Appendix B; p. 18, Appendix C]** 2411.01493v2 2411.01493v2

> **용어 — 비정상적 데이터:** 시간에 따라 데이터나 선호의 성격이 바뀌는 상황입니다.  
> **용어 — 파국적 망각:** 새 데이터를 학습하면서 이전에 배운 능력을 크게 잃는 현상입니다.  
> **용어 — 비동기 학습:** 생성과 학습을 완전히 번갈아 기다리지 않고 일부 병렬로 진행하는 방식입니다. 속도를 높일 수 있지만 조금 오래된 정책의 데이터가 사용될 수 있습니다.

저자들이 언급한 “적절한 양의 인간 피드백으로 초인간적 능력을 이끌어낼 수 있다”는 전망은 **연구 동기와 장기적 기대**이지, 이 논문에서 입증한 실험 결과는 아닙니다. 2411.01493v2

### 10.2 추가 후속 연구 제안: 일반화를 우선해야 한다

#### 우선순위 1 — 독립 평가자와 새 도메인에서 이득이 남는지 검증

**[제안]** 동일한 학습 모델을 그대로 두고, 학습에 관여하지 않은 인간 평가자와 독립 모델 평가자로 재평가해야 합니다. 동시에 TL;DR→CNN/DM처럼 명확한 도메인 전이, 장문·희귀 주제·다국어 조건을 포함해야 합니다. 평균 승률뿐 아니라 사실성, 핵심 내용 누락, 길이, 소수 집단별 성능도 분리해 평가하는 것이 좋습니다.

이 방향의 선례는 2020년 인간 피드백 요약 연구의 도메인 전이 및 길이 통제 평가입니다. SEA의 일반화 주장을 강화하려면 이런 검증 축을 추가하는 것이 단순한 모델 크기 확대보다 직접적입니다. [arXiv](https://arxiv.org/pdf/2009.01325)

#### 우선순위 2 — 불확실성과 합성 선호를 검증 가능한 방식으로 관리

**[제안]** 외부 라벨을 받기 전의 불확실성 점수가 실제 오류와 얼마나 관련되는지 측정하고, 그 신뢰도에 따라 외부 질의 비율을 조절하는 방식이 유망합니다. 익숙하지 않은 도메인이나 헤드들의 공통 오류가 의심되는 영역에서는 합성 선호 비중을 줄이고, 실제 피드백을 더 요청할 수 있습니다.

단, “불확실성 점수가 높으면 무조건 합성 라벨을 버린다”처럼 단일 규칙을 바로 채택하기보다, 불확실성 보정·도메인 다양성·정책 기울기 기반 선택을 분리해 비교해야 합니다. ActiveDPO의 정책 중심 선택과 DoRA의 분포 보정은 결합 후보이지만, **SEA와 결합했을 때의 이득은 아직 별도 실험이 필요한 제안**입니다. [ICLR Proceedings](https://proceedings.iclr.cc/paper_files/paper/2026/file/24b4531f1ed8d6581530cfde9f47a80b-Paper-Conference.pdf)

#### 우선순위 3 — 라벨 효율, 계산 효율, 일반화 효율을 따로 보고

**[제안]** 후속 실험은 동일 외부 질의 수, 동일 생성 토큰 수, 동일 정책 업데이트 수, 동일 GPU 시간의 비교를 각각 제공해야 합니다. 그래야 “피드백이 비싼 환경에서는 유리하지만 계산이 비싼 환경에서는 불리한가” 같은 실용적 질문에 답할 수 있습니다.

또한 미리 정한 목표 승률에 도달하기까지의 질의 수를 여러 실행에서 측정하고, 목표에 도달하지 못한 실행도 포함해야 합니다. 평가 프롬프트별 결과와 실행별 결과를 공개하면, 작은 차이에 대한 통계적 검증도 가능해집니다.

#### 우선순위 4 — 실제 근사 알고리즘을 포함하는 이론과 안전한 지속 학습

**[제안]** 사후분포 근사 오차, 유한 후보 검색 오차, 합성 선호 오류, 정책 최적화 오차가 최종 성능에 어떻게 누적되는지 분석해야 합니다. E&E 환경에서는 평균 품질뿐 아니라 드물지만 매우 나쁜 응답의 위험과 사용자 집단별 손실을 함께 다루어야 합니다. 선호 변화와 망각 문제도 고정된 단일 보상 가정을 넘어서는 지속 학습 설정에서 시험할 필요가 있습니다.

### 최종 판단

**SEA는 제한된 외부 평가 예산에서 온라인 선호 학습을 개선하는 설계로서 유망하며, 특히 생성 정책과 불확실성 기반 탐색을 함께 갱신한 실험적 기여가 분명합니다.** 그러나 첨부 버전이 뒷받침하는 결론은 **“특정 요약 과제에서 오라클 선호를 더 효율적으로 학습한다”**는 수준입니다. 앞으로 가장 중요한 질문은 **같은 평가·계산 예산에서 얻은 이득이 독립 인간 평가와 새로운 도메인에서도 유지되는가**입니다.
