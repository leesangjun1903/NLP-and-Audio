## 1. Executive summary — 8문장

1. **[저자 보고]** NFT는 모델이 스스로 생성한 정답뿐 아니라 오답에서도 학습하도록 만들어, 외부 교사의 풀이 없이 수학 추론 능력을 개선하려는 지도학습 기반 방법이다. **[pp. 1–2]** 2505.18116v3
2. 기존 RFT가 정답만 남기고 오답을 버리는 것과 달리, NFT는 학습 대상 모델로부터 **암묵적 오답 정책**을 구성하고 정답·오답 양쪽에 최대우도 학습을 적용한다. **[pp. 2–5, Figures 2–3, 식 (7)–(10)]** 2505.18116v3 2505.18116v3
3. 여기서 “외부 교사가 없다”는 말은 교사 모델이 작성한 풀이가 필요 없다는 뜻이지, **정답이나 검증기까지 필요 없다는 뜻은 아니다**. **[p. 7, §5.1]** 2505.18116v3
4. 저자는 이상적인 데이터·모델 용량 조건에서 오답 정책을 학습하는 것만으로도 목표 정답 분포를 회복할 수 있음을 보이고, 특정 가중치와 엄격한 on-policy 조건에서는 NFT와 GRPO의 기울기가 같음을 증명한다. **[pp. 4, 6, 14–16, Theorem 3.1, Proposition 4.2]** 2505.18116v3 2505.18116v3
5. 6개 수학 벤치마크 평균에서 NFT는 7B 모델의 RFT 대비 **3.4%p**, 32B 모델의 RFT 대비 **6.4%p** 높은 정확도를 기록한다. **[p. 7, Table 1; 차이는 표에서 계산]** 2505.18116v3
6. DAPO와 비교하면 NFT는 7B 평균에서 **0.5%p 높고**, 32B 평균에서 **0.7%p 낮으므로**, 모든 규모와 과제에서 강화학습을 능가했다고 해석해서는 안 된다. **[p. 7, Table 1]** 2505.18116v3
7. **[해석]** 오답 활용과 출력 다양성 유지가 일반화에 도움이 될 가능성은 있지만, 엔트로피 곡선과 벤치마크 정확도만으로 그 인과관계나 새로운 추론 능력의 출현을 확정할 수는 없다. **[pp. 8–9, Figures 6–8, §5.3]** 2505.18116v3 2505.18116v3
8. **[검증 한계]** 실제 기본 설정은 GRPO보다 Dr. GRPO와의 기울기 대응에 가깝고, 32B 비교에서는 문맥 길이가 다르며, 통제된 분포 밖 평가와 충분한 통계 검증이 부족하므로 일반화 우월성은 후속 연구가 필요한 가설이다. **[pp. 16–18, Appendix C]** 2505.18116v3 2505.18116v3

> **용어**
> - **지도학습·SFT**: 제공된 학습 예시를 더 잘 재현하도록 모델을 조정하는 학습.
> - **RFT, Rejection Fine-Tuning**: 생성 결과 중 정답만 골라 다시 학습하는 방식.
> - **정책**: 여기서는 “주어진 문제에 어떤 답변·토큰을 얼마나 높은 확률로 생성하는가”를 나타내는 모델의 확률분포.
> - **암묵적 정책**: 별도 신경망으로 만들지 않고, 기존 모델과 수식으로 정의한 정책.
> - **on-policy**: 데이터를 생성한 정책과 현재 업데이트할 정책이 일치하는 조건.
> - **엔트로피**: 출력 확률분포가 얼마나 퍼져 있는지 나타내는 값으로, 그 자체가 정답 다양성이나 추론의 질을 뜻하지는 않음.

## 2. 연구의 목적·필요성과 핵심 주장

### 2.1 무엇을 해결하려는가?

**[저자 보고]** 연구의 출발점은 “모델이 스스로 답을 생성하고, 검증기가 맞고 틀림만 알려주는 상황에서 어떻게 학습할 것인가?”입니다.  
RFT는 정답을 재학습하므로 간단하지만, 이미 맞힌 풀이를 강화하는 데 집중하고 오답에서 제공되는 정보를 직접 활용하지 않습니다.  
NFT는 이 손실을 줄이는 것을 목표로 합니다. **[p. 2, §1]** 2505.18116v3

**[해석]** 연구의 필요성은 다음과 같이 이해하는 것이 정확합니다.

**데이터 측면에서는**, 모델이 이미 생성해 둔 오답을 버리지 않고 학습 신호로 재활용하려는 시도입니다.  
**알고리즘 측면에서는**, “지도학습인가 강화학습인가”라는 이름보다 정답·오답의 기울기를 어떻게 구성하는지가 성능 차이를 설명하는지 검토합니다.  
다만 이것은 **지도학습에서 부정적 예시를 활용한 최초의 연구라는 뜻은 아닙니다**.  
뒤에서 비교할 Unlikelihood Training과 DPO에도 관련 선행 아이디어가 있습니다. **[NFT pp. 2, 9; 외부 비교는 §7]** 2505.18116v3 2505.18116v3 [ICLR](https://iclr.cc/virtual_2020/poster_SJeYe0NtvH.html)

### 3.1 모델 구조: 새로운 신경망보다 새로운 학습 목적함수

### 3.2 정답 정책과 오답 정책의 분해

**[저자 보고: 식 (5)–(7)]** 이전 모델이 생성한 답변을 정답 여부로 조건화하면 다음 두 분포가 생깁니다.

```math
\pi^+(a\mid q)
=
\frac{
\pi_{\text{old}}(a\mid q)\,p(r=1\mid q,a)
}{
r_q
},
```

```math
\pi^-(a\mid q)
=
\frac{
\pi_{\text{old}}(a\mid q)\,[1-p(r=1\mid q,a)]
}{
1-r_q
},
```

```math
r_q
=
\sum_a
\pi_{\text{old}}(a\mid q)\,p(r=1\mid q,a).
```

여기서 $\pi^+$는 **정답이라는 조건을 만족하는 출력 분포**, $\pi^-$는 **오답이라는 조건을 만족하는 출력 분포**, $p(r=1\mid q,a)$는 답변이 정답으로 판정될 확률입니다. 이진 결정형 검증기라면 마지막 값은 0 또는 1입니다. **[pp. 3–4, 식 (5)–(6)]** 2505.18116v3 2505.18116v3

따라서 다음 혼합 관계가 성립합니다.

```math
\boxed{
\pi_{\text{old}}(a\mid q)
=
r_q\pi^+(a\mid q)
+
(1-r_q)\pi^-(a\mid q)
}
```

**기호 설명:** $r_q$와 $1-r_q$는 각각 정답 분포와 오답 분포가 전체 생성 분포에서 차지하는 비중입니다. **[p. 4, 식 (7), Figure 3]** 2505.18116v3

**[해석]** 이는 “전체 생성 결과 = 정답 생성 결과 + 오답 생성 결과”라는 확률적 분해입니다. NFT의 핵심은 이 관계를 뒤집어, **오답 분포를 잘 맞추는 일이 목표 정답 분포를 제약하도록 만드는 것**입니다.

### 3.3 암묵적 오답 정책과 최대우도 학습

목표 모델 $\pi_\theta^+$를 이용해 오답 정책을 다음과 같이 정의합니다.

```math
\boxed{
\pi_\theta^-(a\mid q)
=
\frac{
\pi_{\text{old}}(a\mid q)-r_q\pi_\theta^+(a\mid q)
}{
1-r_q
}
}
```

**기호 설명:** $\pi_\theta^-$는 독립적인 신경망이 아니라 $\pi_\theta^+$, $\pi_{\text{old}}$, $r_q$로 정의되는 암묵적 분포입니다. **[p. 4, §3.2]** 2505.18116v3

오답에 대한 학습은 다음 최대우도 문제입니다.

$$
\max_\theta
\mathbb{E}_{q\sim p(q),\,a\sim\pi^-(\cdot\mid q)}
\left[
\log \pi_\theta^-(a\mid q)
\right].
$$

**기호 설명:** $p(q)$는 문제의 분포이고, $\mathbb{E}$는 해당 분포에서의 평균입니다. 최대우도 학습은 관측한 데이터에 모델이 높은 확률을 주도록 학습하는 것입니다. **[p. 4, 식 (8)]** 2505.18116v3

**왜 이것이 오답을 덜 생성하게 만드는가?**  
위 식에서 오답 $a^-$에 대한 $\pi_\theta^+(a^-\mid q)$가 커지면, 암묵적 오답 확률 $\pi_\theta^-(a^-\mid q)$는 작아집니다. 따라서 오답 데이터의 암묵적 확률을 높이는 학습은, 목표 모델이 그 오답에 부여하는 확률을 낮추는 방향으로 작동합니다. **[해석: 위 재매개변수화에서 직접 도출]**

**[저자 보고]** Theorem 3.1은 무한 데이터와 충분한 모델 용량을 가정할 때 최적해가 $\pi_\theta^+=\pi^+$가 된다고 주장하며, Appendix A에서는 최대우도와 KL 발산 최소화의 관계를 이용합니다. **[pp. 4, 14]** 2505.18116v3 2505.18116v3

> **용어 — 재매개변수화·KL 발산**  
> 재매개변수화는 새로운 모델을 따로 학습하는 대신 기존 변수의 함수로 표현을 바꾸는 것입니다. KL 발산은 두 확률분포의 차이를 재는 양으로, 일반적인 거리와 달리 방향에 따라 값이 달라질 수 있습니다.

### 3.4 정답·오답을 함께 사용하는 손실

전체 답변의 확률비를 다음과 같이 놓겠습니다.

```math
R_\theta(q,a)
=
\frac{\pi_\theta^+(a\mid q)}
{\pi_{\text{old}}(a\mid q)}.
```

그러면 논문 식 (9)의 개별 예시 손실은 다음처럼 정리됩니다.

```math
\boxed{
\ell_{\text{NFT}}(q,a,r)
=
-r\log R_\theta(q,a)
-
(1-r)
\log
\left[
\frac{1-r_qR_\theta(q,a)}{1-r_q}
\right]
}
```

**기호 설명:** $R_\theta$는 “현재 모델이 이전 모델보다 해당 답변을 얼마나 더 자주 생성하려 하는가”를 나타내는 확률비입니다. $r=1$이면 첫 항만, $r=0$이면 둘째 항만 사용합니다. 이전 정책의 로그확률은 $\theta$와 무관하므로 기준값으로 빼더라도 기울기는 변하지 않습니다. **[p. 5, 식 (9)]** 2505.18116v3

**[해석]** 이 손실은 단순히 “오답의 로그확률에 음수를 붙이는 것”과 다릅니다. **문제별 정답률과 이전 정책에 대한 상대적 변화량**을 함께 사용한다는 점이 중요합니다.

### 3.5 실제 구현: 토큰 단위 손실, 클리핑, 문제 가중치

전체 시퀀스 확률은 길이가 길어질수록 매우 작아질 수 있기 때문에, 저자는 토큰별 확률비를 사용합니다.

```math
R_\theta^t(q,a)
=
\frac{
\pi_\theta^+(a_t\mid q,a_{ < t})
}{
\pi_{\text{old}}(a_t\mid q,a_{ < t})
},
\qquad
\hat r_q
=
\frac{1}{K}\sum_{i=1}^{K}r(q,a^{(i)}).
```

**기호 설명:** $K$는 문제당 생성 수이며, 실험에서는 16입니다. $t$는 토큰 위치입니다. **[p. 5, 식 (10); p. 17, Appendix C]** 2505.18116v3 2505.18116v3

실제 NFT 목적함수는 다음과 같습니다.

```math
\boxed{
\mathcal{L}_{\text{NFT}}
=
-\sum_{(q,a,r)\in D}
\omega(q)
\sum_{t=1}^{T}
\left[
r\log R_\theta^t
+
(1-r)
\log
\text{max}_v
\left(
\frac{1-\hat r_qR_\theta^t}{1-\hat r_q},
\epsilon
\right)
\right]
}
```

**기호 설명:** $\omega(q)$는 문제별 학습 가중치이고, $\epsilon>0$은 암묵적 오답 확률비의 하한입니다. $\text{max}_v$는 값은 제한하되 기울기를 통과시키는 연산입니다. **[pp. 5–6, 식 (10)]** 2505.18116v3

그 연산은 Algorithm 1에서 다음과 같이 정의됩니다.

```math
\text{max}_v(x,\epsilon)
=
\text{stopgrad}\!\left(\max(x,\epsilon)-x\right)+x.
```

**기호 설명:** $\text{stopgrad}$는 해당 항을 역전파할 때 상수로 취급하는 연산입니다. 따라서 순전파에서는 $\max(x,\epsilon)$를 사용하지만, $x$에 대한 역전파 기울기는 유지됩니다. **[p. 5, Algorithm 1, lines 2–3]** 2505.18116v3

> **용어 — 클리핑·straight-through 기울기**  
> 클리핑은 값이 일정 범위를 벗어나지 못하게 제한하는 것입니다. Straight-through 방식은 실제 함수의 미분 대신 학습에 사용할 대체 기울기를 통과시키는 방법입니다. 따라서 **표시되는 손실값과 역전파 규칙을 함께 보아야** 알고리즘을 정확히 이해할 수 있습니다.

**실제 기본값은 중요합니다.** Appendix C에서 NFT의 기본 설정은 다음과 같습니다.

$$
\omega(q)=1-\hat r_q,
\qquad
\epsilon=1.
$$

또한 정답 또는 오답만 나온 문제 그룹은 제외하고, 정답과 오답이 섞인 그룹만 학습합니다. **[p. 5, Algorithm 1; p. 17, Appendix C]** 2505.18116v3 2505.18116v3

### 3.6 GRPO와 정확히 어떤 조건에서 같은가?

논문이 비교 대상으로 사용하는 GRPO 손실은 보조 정규화 항을 제외하면 다음과 같습니다.

```math
\mathcal{L}_{\text{GRPO}}
=
-\sum_{q,a,t}
\min
\left[
R_\theta^t\hat A_{q,a},
\;
\text{clip}(R_\theta^t,1-\epsilon',1+\epsilon')
\hat A_{q,a}
\right].
```

```math
\hat A_{q,a}
=
\frac{r(q,a)-\hat r_q}
{\sqrt{\hat r_q(1-\hat r_q)}}.
```

**기호 설명:** $\hat A_{q,a}$는 같은 문제의 다른 답변들과 비교한 상대적 보상인 **어드밴티지**입니다. $\epsilon'$는 GRPO의 확률비 제한 폭으로, NFT의 $\epsilon$과는 다른 매개변수입니다. 둘째 식은 이진 보상이고 그룹 내 정답률이 0과 1 사이일 때의 형태입니다. **[p. 3, 식 (3)–(4); pp. 14–15]** 2505.18116v3 2505.18116v3

> **용어 — 어드밴티지**  
> 절대 점수 대신 “같은 문제에서 나온 평균적인 답보다 얼마나 나았는가”를 나타내는 값입니다.

정답과 오답의 어드밴티지는 각각 다음과 같습니다.

```math
A_q^+
=
\sqrt{\frac{1-\hat r_q}{\hat r_q}},
\qquad
A_q^-
=
-\sqrt{\frac{\hat r_q}{1-\hat r_q}}.
```

NFT에서 문제 가중치를 다음과 같이 설정하면,

```math
\omega(q)
=
\sqrt{\frac{1-\hat r_q}{\hat r_q}},
```

엄격한 on-policy 조건에서 아래 관계가 성립합니다.

```math
\boxed{
R_\theta^t=1,\quad 0<\hat r_q<1,\quad 0<\epsilon\leq1
\quad\Longrightarrow\quad
\nabla_\theta\mathcal{L}_{\text{NFT}}
=
\nabla_\theta\mathcal{L}_{\text{GRPO}}
}
```

**기호 설명:** $\nabla_\theta$는 모델 파라미터에 대한 기울기입니다. 여기서는 동일한 데이터와 손실 집계 방식 등 논문의 비교 설정을 전제합니다. **[p. 6, Propositions 4.1–4.2]** 2505.18116v3

**중요한 구분:** 논문의 **실험 기본값**인 $\omega(q)=1-\hat r_q$는 위 제곱근 가중치가 아닙니다. 저자는 이 설정이 표준편차 정규화를 제거한 **Dr. GRPO**와 대응한다고 설명합니다. 따라서 “실제로 사용한 NFT는 모든 조건에서 원래 GRPO와 같다”는 요약은 부정확합니다. **[p. 16, Remark A.3; p. 17]** 2505.18116v3 2505.18116v3

## 4. 이론이 보장하는 것과 실제 알고리즘 사이의 간격

### 4.1 암묵적 정책이 진짜 확률분포여야 한다

**[해석: 정리의 적용 조건 점검]** Appendix A의 KL 발산 논증을 적용하려면 $\pi_\theta^-$가 유효한 확률분포여야 합니다. 특히 모든 답변에 대해 다음 비음수 조건이 필요합니다.

$$
\pi_{\text{old}}(a\mid q)-r_q\pi_\theta^+(a\mid q)\geq0.
$$

**기호 설명:** 이 조건은 암묵적 오답 확률의 분자가 음수가 되지 않아야 한다는 뜻입니다. 정리의 분포 수준 논증과, 학습 중 일부 값이 음수가 되는 것을 막기 위한 실용적 클리핑은 구별해야 합니다. **[pp. 6, 14]** 2505.18116v3 2505.18116v3

**[검증 한계]** 실제 토큰별 클리핑과 straight-through 업데이트가 **전체 답변 공간에서 이 조건을 보장하면서 원래 정리의 최적해를 보존한다는 증명**은 제시되지 않습니다. 그러므로 Theorem 3.1을 실제 유한 데이터 학습의 수렴 보장으로 그대로 읽으면 안 됩니다.

### 4.2 시퀀스 수준 분해와 토큰 수준 분해는 자동으로 같지 않다

**[해석: 식 (7)과 식 (10)의 차이]** 전체 답변을 정답·오답으로 나누었을 때의 혼합 비중은 $r_q$입니다. 그러나 생성 중간 상태 $h_t=(q,a_{<t})$에 조건화하면, 정확한 혼합 비중은 일반적으로 다음과 같습니다.

```math
r_{h_t}
=
p(r=1\mid q,a_{ < t}).
```

**기호 설명:** $r_{h_t}$는 “현재까지 생성한 풀이를 보고, 최종적으로 정답이 될 확률”입니다. 이미 잘못된 계산을 한 경우와 올바른 풀이를 진행한 경우에는 이 값이 달라질 수 있습니다.

NFT의 실제 손실은 모든 토큰에 문제 수준 추정치 $\hat r_q$를 사용합니다. 따라서 **토큰별 목적함수는 전체 시퀀스 최대우도를 단순히 똑같이 펼친 식이라고 볼 수 없으며**, 실용적 변경을 포함합니다. 원문은 시퀀스 확률의 분산과 수치적 불안정성을 이유로 토큰 단위 전환을 설명합니다. **[p. 5, §3.3]** 2505.18116v3

### 4.3 “오답에서 학습”과 “잘못된 추론 단계를 찾아 수정”은 다르다

**[저자 보고]** NFT는 답변 전체의 정답·오답 판정을 토큰별 손실에 사용합니다. **[p. 5, 식 (10)]** 2505.18116v3

**[해석]** 오답 풀이에도 올바른 중간 계산, 적절한 문제 분해, 유용한 표현이 포함될 수 있습니다. NFT는 **최초 오류 지점을 명시적으로 찾아 그 이후만 교정하는 알고리즘은 아닙니다**. 따라서 저자가 사용하는 “실수를 반성한다”는 표현을 인간과 같은 오류 진단 능력이 검증되었다는 뜻으로 받아들여서는 안 됩니다.

> **용어 — 신용 할당, credit assignment**  
> 최종 성공·실패가 나왔을 때, 중간의 어떤 행동에 공로 또는 책임을 배분할지 결정하는 문제입니다.

### 6.6 특히 중요한 병목: 너무 어려운 문제는 학습에서 빠질 수 있다

**[저자 보고]** Algorithm 1은 $0<\hat r_q<1$인 문제 그룹만 유지합니다. **[p. 5]** 2505.18116v3

**[해석·직접 계산]** 한 문제에 대한 독립 생성의 실제 성공 확률을 $p$, 생성 수를 $K$라 하면, 정답과 오답이 모두 나와 학습에 포함될 확률은 다음과 같습니다.

```math
P_{\text{keep}}
=
1-p^K-(1-p)^K.
```

**기호 설명:** $p^K$는 전부 정답일 확률이고, $(1-p)^K$는 전부 오답일 확률입니다. 독립 생성과 고정된 $p$를 가정한 계산입니다.

논문의 $K=16$에서 실제 성공 확률이 1%인 문제는 학습에 포함될 확률이 약 **14.85%**입니다. 따라서 어려운 문제에 높은 가중치를 주더라도, **너무 어려워 한 번도 맞히지 못한 문제는 그 라운드에서 직접 학습하지 못합니다**. 다른 문제를 학습한 효과가 전이될 수는 있지만, 이것이 자동으로 보장되지는 않습니다.

또한 정답률 추정의 표준오차는 같은 가정하에 다음과 같습니다.

```math
\text{SE}(\hat r_q)
=
\sqrt{\frac{p(1-p)}{K}}.
```

**기호 설명:** $\text{SE}$는 표본으로 추정한 정답률의 불확실성입니다. $K=16$에서 최대값은 0.125, 즉 **12.5%p**입니다. 이는 **실험에서 측정한 오차가 아니라 단순 확률모형에서 계산한 값**이며, $\hat r_q$를 손실과 가중치 양쪽에 사용하는 설계의 민감도를 보여줍니다.

### 7.2 수식으로 보는 차별점

#### Unlikelihood: 원치 않는 토큰의 확률을 직접 낮춘다

```math
\mathcal{L}_{\text{UL},t}
=
-\sum_{c\in C_t}
\log\left[1-\pi_\theta(c\mid h_t)\right].
```

**기호 설명:** $C_t$는 원치 않는 토큰 후보 집합이고, $h_t$는 현재까지의 문맥입니다. 이 식은 후보의 확률이 작아질수록 감소합니다. **[Unlikelihood 원문 p. 4, 식 (3)]** [arXiv](https://arxiv.org/pdf/1908.04319)

**[비교 해석]** NFT도 실패 생성의 확률을 낮추지만, 이전 정책과 문제별 정답률을 이용해 그 업데이트를 구조화합니다. 따라서 “오답 확률 감소”는 공통점이고, **분포 분해와 기울기 대응 이론**이 NFT의 더 구체적인 기여입니다.

#### DPO: 두 응답의 상대적인 선호를 학습한다

```math
\mathcal{L}_{\text{DPO}}
=
-\mathbb{E}
\left[
\log \sigma
\left(
\beta\log
\frac{\pi_\theta(a_w\mid q)}
{\pi_{\text{ref}}(a_w\mid q)}
-
\beta\log
\frac{\pi_\theta(a_l\mid q)}
{\pi_{\text{ref}}(a_l\mid q)}
\right)
\right].
```

**기호 설명:** $a_w$는 선호되는 응답, $a_l$은 덜 선호되는 응답, $\pi_{\text{ref}}$는 기준 정책, $\beta$는 제약의 강도를 조절하는 값, $\sigma$는 값을 0과 1 사이로 변환하는 시그모이드 함수입니다. **[DPO 원문 p. 4, 식 (7)]** [arXiv](https://arxiv.org/pdf/2305.18290)

**[비교 해석]** DPO의 정보 단위는 “둘 중 어느 것이 더 좋은가”이고, NFT의 정보 단위는 “이 응답이 정답인가 오답인가”입니다. 두 방법을 비교할 때에는 선호 쌍 구성 비용과 문제별 생성 수까지 통제해야 합니다.

#### DFT: 정답 예시에 대한 토큰 업데이트를 재가중한다

```math
\mathcal{L}_{\text{DFT}}
=
-\mathbb{E}_{(q,a^*)\sim D}
\sum_t
\text{stopgrad}
\left[
\pi_\theta(a_t^*\mid q,a_{ < t}^*)
\right]
\log \pi_\theta(a_t^*\mid q,a_{ < t}^*).
```

**기호 설명:** $a^*$는 학습용 정답 응답이고, 토큰 확률을 가중치로 사용하되 그 가중치 자체로는 역전파하지 않습니다. **[DFT 원문 p. 4, 식 (9)]** [arXiv](https://arxiv.org/pdf/2508.05629v3)

**[비교 해석]** NFT가 실패 정보의 추가 활용을 강조한다면, DFT는 성공 예시만 있더라도 학습 가중치를 바꾸는 것의 중요성을 보여줍니다. 따라서 일반화 연구에서는 **부정적 데이터의 유무와 정답 학습의 가중 방식**을 별개의 축으로 평가하는 편이 더 유익합니다.

### 7.3 “새 능력인가, 기존 능력의 재배치인가?”에 대한 균형 잡힌 해석

Yue et al.은 조사한 설정에서 RL이 기존 모델의 해결 가능 영역을 넓히지 못하는 경우를 보고했고, ProRL은 더 긴 학습과 다른 설계 아래에서 해결 범위 확장에 대한 증거를 제시했습니다. **따라서 어느 한쪽을 모든 모델·알고리즘에 적용되는 보편 법칙으로 받아들여서는 안 됩니다.** [arXiv](https://arxiv.org/abs/2504.13837)

NFT의 이론적 목표는 기존 정책을 정답 여부로 재가중한 분포입니다. **[해석]** 이상적인 한 번의 재가중만 보면, 기존 정책이 정확히 확률 0을 주는 답변에 새 확률질량을 만들지는 않습니다. 그러나 실제 신경망의 파라미터 공유, 문제 간 전이, 매우 작지만 0은 아닌 확률, 반복 학습 때문에 이것을 **“NFT는 절대로 새 추론 능력을 얻을 수 없다”는 주장으로 확장할 수는 없습니다**. NFT가 이 논쟁에서 어디에 위치하는지는 별도의 해결 범위 실험이 필요합니다. **[NFT p. 3, 식 (5)]** 2505.18116v3

> **용어 — pass@k·해결 범위**  
> `pass@k`는 여러 번 시도했을 때 적어도 한 번 정답을 생성하는 능력을 측정합니다. 해결 범위는 모델이 충분한 시도 아래에서 풀 수 있는 문제들의 집합을 뜻하며, 한 번의 성공률과는 구별됩니다.

### 9.2 추가 제안: 일반화 가능성을 검증하기 위한 우선순위

아래는 **저자의 계획이 아니라 제안하는 후속 연구**입니다.

| 우선순위 | 제안 실험 | 확인하려는 질문 |
|---|---|---|
| **1. 오답 효과를 독립적으로 분리** | 오답 손실 사용 여부 × 세 가지 문제 가중치를 교차하고, 생성 데이터·토큰 예산·길이·검증기를 통일 | NFT의 이득이 오답 자체에서 오는가, 어려운 문제에 더 많은 학습을 배분해서 오는가? |

### 최종 평가

**NFT는 “지도학습 대 강화학습”이라는 이분법을, “어떤 데이터를 사용하고 어떤 기울기로 업데이트하는가”라는 더 구체적인 연구 문제로 바꾸는 데 의미가 있습니다.** 정답·오답을 함께 활용하는 목적함수의 설계와 조건부 기울기 동등성은 분명한 기여입니다. **[pp. 4–6, 10]** 2505.18116v3 2505.18116v3 2505.18116v3

다만 **일반화에 관한 가장 정확한 결론은 “개선 가능성을 보여주었다”이지 “일반화 우월성을 입증했다”가 아닙니다.** 다음 연구의 핵심은 평균 정확도 상승을 다시 확인하는 것을 넘어, **동일한 연산 예산에서 새로운 문제 구조의 해결 범위가 실제로 확장되는지, 그리고 그 확장이 오답 활용 때문에 발생하는지**를 분리해 검증하는 것입니다.
