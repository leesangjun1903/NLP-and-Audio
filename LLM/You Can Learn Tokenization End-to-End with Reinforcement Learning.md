## 1. Executive Summary (10문장 이내)

현대 LLM의 훈련 파이프라인에서 토크나이제이션(tokenization)은 BPE 등의 하드코딩된 휴리스틱에 의존하는 전처리 단계로 남아있다.  
본 논문은 이 단계를 모델 내부로 통합하여 **엔드-투-엔드(end-to-end)로 토큰 경계(token boundary)를 학습**할 수 있음을 보인다.  
핵심 방법론은 **스코어 함수 추정(score function estimation)**, 즉 REINFORCE 정책 그래디언트를 토큰 경계 결정에 적용하는 것이다.  
기존 직선 통과 추정기(straight-through estimator, STE)와 달리, 스코어 함수 추정기는 이산적(discrete) 경계 결정 문제를 직접 최적화하기 때문에 더 강한 이론적 보장을 갖는다.  
순수 REINFORCE는 분산이 너무 높아 실용적이지 않으므로, 조기 종료 상대 보상(early exit relative rewards), 시간 할인(time discounting), 배치 상대 어드밴티지(batch-relative advantages) 등 강화학습 기법을 통해 분산을 감소시킨다.  
제안 방법은 오토리그레시브 U-Net 구조 위에서 구현되며, 언어적 사전 편향 없이도 공백(whitespace) 등 의미론적 경계를 스스로 학습한다.  
FineWeb 데이터셋 기반 147M 파라미터 실험에서 기존 STE 기반 방법들(Nawrot et al., 2023; Hwang et al., 2025)보다 검증 손실과 다운스트림 벤치마크 성능이 우수하다.  
특히 BPE 가이던스(외부 토크나이저 정보 활용)에 필적하는 유일한 동적 토크나이제이션 방법임을 보인다.  
Python 코드(CodeParrot) 데이터셋에서도 동일하게 우수한 성능을 보이며 도메인 일반성을 입증한다.  
저자들은 스코어 함수 추정기가 향후 엔드-투-엔드 LLM 아키텍처에서 토크나이제이션의 표준적 학습 방법이 되기를 기대한다.

### 1-1. 연구의 목적과 필요성

**목적**: BPE와 같은 **하드코딩된 토크나이제이션**을 제거하고, 토큰 경계를 **모델 학습과 함께 엔드-투-엔드로 최적화**하는 방법을 제안.

**필요성** (p.1):
- BPE는 어휘 크기(vocabulary size)가 늘수록 다운샘플링 비율의 수익이 급감하는 문제가 있음
- "Glitch token" 등 희귀 토큰의 부작용 존재
- Gemma 시리즈 등 최신 모델조차 손으로 설계(artisanal)한 토크나이저 규칙에 의존
- 화이트스페이스 분할, 엔트로피 스파이크 등 기존 휴리스틱은 이론적 최적성이 보장되지 않음
- STE 기반 선행 연구들은 이산 경계 결정을 연속 문제로 근사하므로 이론적 보장이 없음

> 📌 **엔드-투-엔드(End-to-End)**: 전처리~출력까지의 모든 단계를 단일 모델이 함께 최적화하는 방식. 중간 단계(예: 토크나이저)가 고정되지 않고 학습됨.

## 2-1. 상세 설명

### 2-1-A. 해결하고자 하는 문제

LLM 훈련 파이프라인에서 BPE 토크나이저는 고정된 전처리 단계로, **학습 손실을 직접 최소화하도록 최적화되지 않는다**. 엔트로피 기반, 공백 기반 등의 휴리스틱 경계 방식은 성능이 우수하나 이론적 최적성이 없다. 기존 STE 기반 방법은 이산 경계 결정(discrete boundary decision)을 연속 변수로 완화(relax)하여 역전파하므로 이론적 보장이 없고, 특수한 업/다운샘플러 설계가 필요하다. (p.1~2, §1, §3.2)

> 📌 **Straight-Through Estimator (STE)**: 이산 변수를 역전파할 때 그래디언트가 흐르지 않는 문제를 우회하기 위해, 순방향에서는 이산값을, 역방향에서는 연속 근사값의 그래디언트를 사용하는 기법. 이론적 정확도보다 실용성 위주.

### 2-1-B. 제안하는 방법 (수식 포함)

#### ① 전체 목적 함수 (p.3, Eq.10)

$$\log p_\theta(y|x) = \mathbb{E}_{a \sim \pi_\theta} \log p_\theta(y|a, x)$$

- $\theta$: 모델 파라미터 (언어 모델 $p_\theta$와 토큰 경계 정책 $\pi_\theta$ 공유 가능)
- $y$: 목표 출력 (다음 바이트 시퀀스)
- $x$: 입력 바이트 시퀀스
- $a$: 토큰 경계 결정 벡터 ($a_i=1$이면 $x_i$에서 경계 배치)
- $\pi_\theta$: 토큰 경계 정책

> 📌 **정책(Policy) $\pi_\theta$**: 강화학습 용어로, 현재 상태(바이트 표현)를 보고 행동(경계 배치 여부)을 결정하는 확률적 함수.

#### ② 스코어 함수 추정 (그래디언트 분해, p.3, Eq.11~13)

$$\nabla_\theta \mathbb{E}_{a \sim \pi_\theta} \log p_\theta(y|a,x) = \mathbb{E}_{a \sim \pi_\theta}\Big(\underbrace{\nabla_\theta \log p_\theta(y|a,x)}_{\text{조건부 손실 그래디언트}} + \underbrace{\log p_\theta(y|a,x) \nabla_\theta \log \pi_\theta(a|x)}_{\text{정책 그래디언트}}\Big)$$

- 첫 번째 항: 주어진 경계 $a$에서의 일반적인 언어 모델 그래디언트
- 두 번째 항: REINFORCE 항 — 경계 결정 $a$의 로그 확률에 보상(다음 토큰 예측 로그 우도)을 곱한 것

> 📌 **REINFORCE (Williams, 1992)**: 정책 그래디언트 기반 강화학습 알고리즘. "좋은 행동의 확률을 높이고 나쁜 행동의 확률을 낮춘다"는 원리.

> 📌 **스코어 함수 추정기(Score Function Estimator)**: $\nabla_\theta \mathbb{E}[f(x)] = \mathbb{E}[f(x)\nabla_\theta \log p_\theta(x)]$ 형태의 그래디언트 추정 기법. REINFORCE와 동일한 원리.

#### ③ 조기 종료 상대 보상 (p.4, Eq.14~15)

$$\log p_\theta^{early}(x_i = t_j | x_{ < i}) = \log \text{softmax}(W_{early} X_{i-1})_j$$

$$R_i = \log p_\theta(x_i | x_{ < i}, a_{ < i}) - \log p_\theta^{early}(x_i | x_{ < i})$$

- $W_{early} \in \mathbb{R}^{d_{model} \times \text{vocab size}}$: 조기 종료 출력 헤드의 언임베딩 행렬
- $X_{i-1}$: $i-1$번째 위치의 바이트 레벨 표현
- $R_i$: 전체 모델과 조기 종료 모델의 예측 로그 우도 차이 → 토크나이제이션에 의한 순수 기여 추정
- $d_{model}$: 모델 은닉 차원 (본 실험에서 768)

> 📌 **조기 종료(Early Exit)**: 전체 모델 계산을 마치지 않고 중간 레이어 표현으로 예측을 내보내는 것. 여기서는 바이트 레벨 표현만으로 예측한 베이스라인 역할.

#### ④ 시간 할인된 리턴 (p.4, Eq.16)

$$G_i = \sum_{j=0}^{N-i-1} \gamma^j R_{i+j+1}$$

- $G_i$: 위치 $i$에서의 할인 리턴 (discounted return)
- $\gamma$: 할인 인수(discount factor) = 0.99 (실험값)
- $N$: 시퀀스 길이 (4096 바이트)
- $R_{i+j+1}$: 미래 위치 $i+j+1$에서의 상대 보상

> 📌 **시간 할인(Time Discounting)**: 강화학습에서 먼 미래 보상보다 가까운 미래 보상을 더 중시하는 기법. 긴 시퀀스에서 보상 귀속(credit assignment) 문제를 완화.

#### ⑤ 배치 상대 어드밴티지 (p.5, Eq.17)

$$A_{i,b} = G_{i,b} - \bar{G}_i \quad \text{where} \quad \bar{G}_i = \frac{1}{B}\sum_{b=1}^B G_{i,b}$$

- $A_{i,b}$: 배치 내 샘플 $b$, 위치 $i$의 어드밴티지
- $G_{i,b}$: 배치 인덱스 $b$, 위치 $i$의 할인 리턴
- $B$: 배치 크기 (128)
- $\bar{G}_i$: 배치 내 위치 $i$의 평균 리턴 (베이스라인)

#### ⑥ 정책 손실 (p.5, Eq.18)

$$\mathcal{L}^\pi = -\sum_{i=0}^N \log \pi_\theta(a_i | x_{ < i}, a_{ < i}) \cdot \text{detach}(A_i)$$

- $\text{detach}(\cdot)$: 어드밴티지를 통한 역전파 차단 (stop-gradient)
- 이 손실의 그래디언트가 Eq.11의 정책 그래디언트 항을 근사

#### ⑦ 토큰 경계 확률 (p.4~5, Eq.19~20)

$$a_i | x_{\leq i}, a_{ < i} \sim \text{Bernoulli}(p_i)$$

$$p_i = \pi_\theta(a_i = 1 | x_{\leq i}, a_{ < i}) = \sigma(l_i)$$

- $\sigma(\cdot)$: 시그모이드 함수
- $l_i$: 위치 $i$의 경계 로짓(logit)

> 📌 **베르누이 분포(Bernoulli distribution)**: 0 또는 1의 두 가지 결과만 갖는 이진 확률 분포. 경계 배치(1) 또는 미배치(0)를 모델링하는 데 사용.

#### ⑧ 원시 로짓 계산 (p.5, Eq.21~23)

$$l_i^{raw} = W_0 X_i + \sum_{j=1}^{w-1} a_{i-j} W_j X_i$$

$$l_i^{scaled} = \frac{l_i^{raw}}{D} + \sigma^{-1}(\bar{\pi}_{target})$$

$$l_i = \text{softcap}(l_i^{scaled})$$

- $W_j \in \mathbb{R}^{1 \times d_{model}}$: 선형 투영 행렬 (j=0,...,w-1)
- $w$: 슬라이딩 윈도우 크기 (실험에서 w=8)
- $D$: 스케일링 인수 (실험에서 D=16)
- $\bar{\pi}_{target}$: 목표 다운샘플링 비율 (실험에서 $\frac{1}{5}$)
- $\sigma^{-1}(\bar{\pi}\_{target})$: 초기화 시 $p_i \approx \bar{\pi}_{target}$이 되도록 하는 편향 항

> 📌 **Softcapping**: 로짓 값이 폭발적으로 커지는 것을 막기 위해 특정 범위로 부드럽게 제한하는 기법 (Gemma 2에서 사용).

#### ⑨ 다운샘플링 비율 타겟 손실 (p.5, Eq.24)

$$\mathcal{L}^{target} = \bar{l} \cdot \text{detach}(\bar{p} - \bar{\pi}_{target})$$

- $\bar{l} = \frac{1}{NB}\sum_{i,b} l_{i,b}$: 배치 평균 로짓
- $\bar{p} = \frac{1}{NB}\sum_{i,b} p_{i,b}$: 배치 평균 경계 확률

#### ⑩ 전체 손실 (p.5, Eq.25~27)

$$\mathcal{L}^{auto} = -\sum_{i=0}^N \log p_\theta(x_i | x_{ < i}, a_{ < i})$$

$$\mathcal{L}^{early} = -\sum_{i=0}^N \log p_\theta^{early}(x_i | x_{ < i})$$

$$\mathcal{L} = \mathcal{L}^{auto} + \lambda_\pi \mathcal{L}^\pi + \lambda_{target} \mathcal{L}^{target} + \lambda_{early} \mathcal{L}^{early}$$

- $\lambda_\pi = \lambda_{target} = 10^{-2}$: 탐색 촉진 계수
- $\lambda_{early} = 10^{-1}$: 조기 종료 손실 계수

### 2-1-C. 모델 구조 (p.2, §2.2; p.21, Appendix D)

**오토리그레시브 U-Net** (Nawrot et al., 2022 기반):

```
바이트 시퀀스 x₁...xN
    ↓ [encode: 슬라이딩 윈도우 어텐션 트랜스포머, 4레이어]
바이트 레벨 표현 X ∈ ℝ^{N×d_enc}
    ↓ [πθ: 경계 정책 → a ~ Bernoulli(p)]
토큰 경계 결정 a
    ↓ [downsample: a_i=1인 위치만 선택]
토큰 레벨 표현 X' ∈ ℝ^{M×d_mid}
    ↓ [mid: 전체 인과 어텐션 트랜스포머, 12레이어 (147M 기준)]
풍부화된 표현 Y' ∈ ℝ^{M×d_mid}
    ↓ [upsample: 분산 후 덧셈]
업샘플된 표현 Y ∈ ℝ^{N×d_dec}
    ↓ [decode: 슬라이딩 윈도우 어텐션 트랜스포머, 4레이어]
다음 바이트 예측 y
```

| 구성 요소 | 세부 사항 |
|-----------|-----------|
| 임베딩 차원 | 768 (147M), 768 (90M) |
| 어텐션 헤드 | 12 |
| 인코더/디코더 레이어 | 각 4개, 슬라이딩 윈도우(size=64) 어텐션 |
| 미드 레이어 | 12개 (147M), 6개 (90M), 전체 인과 어텐션 |
| 학습률 | $1.5 \times 10^{-3}$ (147M) |
| 배치 크기 | 128 시퀀스 × 4096 바이트 |
| 옵티마이저 | AdamW ($\beta_1=0.9, \beta_2=0.999$) |
| 학습 데이터 | $6 \times 10^9$ 바이트 (147M) |

- $10^{21}$ FLOP 이상의 대규모에서만 autoregressive U-Net의 BPE 대비 우위가 관찰됨 → 현 실험 규모(약 $2 \times 10^{18}$ FLOP)에서는 다운스트림 퍼플렉서티 비교가 불완전 (p.6, §4)

- 최적 토크나이제이션 종횡비(aspect ratio)의 스케일링 법칙 미규명 (p.9, §5)
- 가변 다운샘플링 비율 학습 시 성능 저하 관찰 (p.9, §5)
- 단일 샘플 몬테카를로 추정 → 효율성 확보를 위한 제약이지만 분산 높음 (p.3~4, §2.4)

## 7. 가장 중요한 그림 5개 해석

### Figure 1 (p.3) — 오토리그레시브 U-Net 구조 및 확률적 계산 그래프

**[왼쪽]** 입력 바이트 `<b>Learn t`에 대해 경계 벡터 `a=11001010`을 적용한 예시. 인코더(아래)→ 경계 결정→다운샘플링→미드 트랜스포머→업샘플링→디코더(위) 흐름을 시각화.

**[오른쪽]** 확률적 계산 그래프(Schulman et al., 2015): 결정론적 노드(사각형)와 확률적 노드(원)를 구분. $x$에서 $p_\theta^{early}$(조기 종료 예측)와 $\pi_\theta$(경계 정책)가 분기하고, $a$(이산 경계 결정)를 통해 $X'$ → $Y'$ → $Y$ → $p_\theta$ 흐름이 완성됨. 이산 노드 $a$가 있어 일반적인 역전파 불가 → 스코어 함수 추정의 필요성을 직관적으로 설명.

**핵심 시사점**: 조기 종료 경로 $p_\theta^{early}$가 베이스라인 예측 역할을 하여 정책 그래디언트의 분산 감소에 기여함을 구조적으로 보여줌.

---

### Figure 2 (p.7) — FineWeb에서 학습된 토큰 경계 (147M 모델)

노란색(높은 경계 확률)과 파란색(낮은 경계 확률)으로 바이트별 $\pi_\theta(a)$ 값을 시각화. **언어적 사전 지식 없이** 공백(`\n`, ` `), 문장 구분 부호 등에 경계가 집중되는 것을 확인.

**핵심 시사점**: 스코어 함수 추정기가 순수히 손실 최소화만으로 언어학적으로 의미 있는 경계를 발견함. 이는 인간이 설계한 BPE 규칙 없이도 최적에 가까운 경계 전략이 창발(emerge)할 수 있음을 보여줌.

> 📌 **창발(Emergence)**: 개별 구성 요소의 규칙에서 명시되지 않은 고수준 특성이 자발적으로 나타나는 현상.

---

### Figure 3 (p.8) — FineWeb 검증 손실 곡선 (147M, FLOP 대비 BPB)

파란색(Uniform), 주황색(STE 방법들), 초록색(Ours)으로 훈련 FLOP 대비 검증 BPB를 플롯. $1.95 \times 10^{18}$ FLOP 기준: Uniform=1.355, Nawrot STE=1.350, H-Net=1.36, **Ours=1.279**.

**핵심 시사점**: 제안 방법이 훈련 전반에 걸쳐 **일관되게** 기존 방법보다 낮은 검증 손실을 유지. 특히 H-Net이 오히려 Uniform보다 나쁜 것은 STE 기반 방법의 이론적 취약성을 실증적으로 보여줌.

⚠️ **주의**: 단일 실행 결과이며, 종횡비/스케일 차이로 인한 비교 제약 존재.

---

### Figure 4 (p.8) — CodeParrot 검증 손실 곡선 (90M, FLOP 대비 BPB)

파란색(H-Net), 주황색(Ours). $0.95 \times 10^{18}$ FLOP 기준: H-Net=0.769, **Ours=0.568**.

**핵심 시사점**: 자연어(FineWeb)와 다른 분포의 Python 코드 데이터에서도 제안 방법의 우위가 **대폭적으로** 재현됨 (약 26% BPB 개선). 코드에서 토큰 경계의 의미(모듈명, 함수 경계)가 명확하여 강화학습이 더 명확한 학습 신호를 받는 것으로 해석.

> ⚠️ H-Net과만 비교하며 Nawrot STE는 포함되지 않아 전면 비교 불완전.

---

### Figure 5 (p.8) / Figure 9 (p.15) — CodeParrot에서 학습된 토큰 경계 (90M 모델)

Python 코드에서 노란색(높은 경계 확률)과 파란색(낮은 경계 확률)으로 $\pi_\theta(a)$ 시각화. **모듈명 앞**, **들여쓰기 시작**, **공백 토큰**(최소 2바이트 포함)에 경계 집중. **Apache License 구간**은 거의 전체 파란색 → 반복 패턴에 대한 연산 절약.

**핵심 시사점**: 모델이 코드의 구조적 특성(모듈 경계, 반복 텍스트)을 학습하여 도메인 특화 토크나이제이션 전략을 자동 발견. 이는 하드코딩된 규칙 없이 데이터 특성에 적응하는 일반화 능력을 시사.

## 8. 결론, 후속 연구 계획, 추가 방향

### 8-1. 저자 제시 시사점 및 후속 연구 계획 (p.9, §5)

**시사점**:
- 스코어 함수 추정기는 엔드-투-엔드 LLM에서 토크나이제이션의 표준 학습 방법이 될 잠재력 보유
- 분산 감소 기법(조기 종료 보상 + 시간 할인 + 배치 어드밴티지)의 조합이 실용적 학습의 핵심
- 언어적 사전 지식 없이 의미론적 경계 창발 → 고정 토크나이저 규칙의 불필요성 시사
- 비영어·저자원 언어에 대한 포용성(inclusivity) 향상 가능성 (Impact Statement)

**저자 후속 연구 계획**:
1. Hwang et al. (2025) 병행 연구와의 상세 비교
2. 더 다양한 텍스트 데이터로 실험 확장
3. 최적 토크나이제이션 종횡비의 스케일링 법칙 규명 (오픈 문제 1)
4. 가변 다운샘플링 비율 학습의 성능 저하 원인 분석 및 해결 (오픈 문제 2)

---

### 8-1-A. 모델의 일반화 성능 향상 가능성

본 논문은 일반화와 관련하여 다음 근거를 제시함:

**긍정적 증거**:
- **다운샘플링 비율 강건성** (Appendix B.6): n=2,4,6 비율에서 모두 적절한 전략 학습 → 하이퍼파라미터 변화에 강건
- **도메인 간 전이**: 자연어(FineWeb)와 Python 코드(CodeParrot)에서 모두 우수 → 도메인 특화 규칙 없이 데이터 적응
- **언어적 사전 편향 없는 창발**: 의미론적 경계를 자율 학습 → 다국어, 비구조적 텍스트에의 일반화 잠재력
- **아키텍처 독립성**: 스코어 함수 추정기가 특정 업/다운샘플러에 의존하지 않음 (p.2) → 다양한 아키텍처에 적용 가능

**일반화의 제약 및 과제**:
- **가변 비율 학습 실패**: 단일 모델이 다양한 목표 비율을 동시에 학습하면 성능 저하 (p.9) → 토큰 경계 정책의 분포 외(out-of-distribution) 일반화 취약성
- **소규모 모델의 한계**: n=2 비율에서는 단순히 2바이트당 1경계 + 마침표 패턴만 학습 → 충분한 모델 용량이 일반화에 필요
- **스케일 의존성**: $10^{21}$ FLOP 이상에서만 의미 있는 비교 가능 → 현재 실험 규모에서의 일반화 결론은 제한적

**일반화 향상을 위한 제안** (본 분석 해석):
- 데이터 커리큘럼(쉬운 도메인 → 어려운 도메인)을 통한 점진적 학습
- FlexiViT(Beyer et al., 2023) 스타일의 가변 비율 훈련 방법론 개선
- 언어 모델 파인튜닝 시 토큰 경계 정책도 함께 적응(adapt)하는 방법 연구

### 8-2. 2020년 이후 관련 최신 연구 비교 분석

> ⚠️ 아래 분석은 제공된 PDF 내 참고문헌과 언급된 연구에 한정하며, PDF 외부 연구는 포함하지 않습니다.

#### 관련 연구 계보 (모두 논문 내 인용 기반)

| 연구 | 연도 | 핵심 기여 | 본 논문과의 관계 |
|------|------|-----------|-----------------|
| ByT5 (Xue et al.) | 2022 | 순수 바이트 레벨 T5; BPE 없이 성능 匹敵 | 바이트 레벨 처리의 가능성 입증 |
| Hierarchical Transformers (Nawrot et al.) | 2022 | 오토리그레시브 U-Net 기반 구조 | 본 논문의 기반 아키텍처 |
| MEGABYTE (Yu et al.) | 2023 | 고정 스트라이드 다운샘플링 | 본 논문이 극복하려는 고정 경계 한계 |
| Dynamic Token Pooling (Nawrot et al.) | 2023 | STE + 엔트로피 기반 경계 | 본 논문의 직접 비교 대상 (STE 방법) |
| SpaceByte (Slagle) | 2024 | 공백 기반 경계 휴리스틱; 대규모 성능 우위 | 본 논문이 학습으로 재현하는 휴리스틱 |
| Byte Latent Transformer (Pagnoni et al.) | 2024 | 엔트로피 기반 경계; $10^{22}$ FLOP 스케일 | 대규모 검증의 벤치마크 |
| MambaByte (Wang et al.) | 2024 | 서브이차(subquadratic) 상태 공간 모델로 BPE 대체 | 병렬 접근 (시퀀스 길이 문제 해결) |
| Charformer (Tay et al.) | 2022 | 그래디언트 기반 서브워드 토크나이제이션 | 초기 학습 가능한 토크나이제이션 시도 |
| MANTa (Godey et al.) | 2022 | 양방향 인코더용 STE 토크나이제이션 | 자기회귀 모델에 적용 불가한 한계 |
| MrT5 (Kallini et al.) | 2025 | 소프트 다운샘플링 훈련 → 추론 시 경계 결정 | 효율성 위배로 본 논문에서 배제 |
| H-Net (Hwang et al.) | 2025 | 특수 업/다운샘플러 + STE | 본 논문의 직접 비교 대상 |
| SuperBPE (Liu et al.) | 2025 | BPE 커리큘럼으로 다운샘플링 개선 | BPE 내의 개선 (본 논문과 방향 다름) |
| Wu et al. (Dynamic Tokenization via RL Patching) | 2026 | 시계열 데이터용 스코어 함수 추정기 | 병행 독립 연구; 도메인만 다름 |

#### 연구 흐름에서 본 논문의 위치

```
고정 BPE (2015~) → 휴리스틱 동적 경계 (2022~2024) → STE 학습 경계 (2022~2025) → [본 논문] RL 기반 스코어 함수 추정 (2026)
```

본 논문은 **이론적으로 정당한 엔드-투-엔드 토크나이제이션 학습**의 첫 번째 실용적 구현을 제시하며, 동시에 Wu et al. (2026)이 독립적으로 같은 방향을 시계열 분야에서 제안했다는 사실이 이 접근법의 일반성을 지지함.

#### 앞으로의 연구에 미치는 영향

1. **이론적 기반 강화**: STE 대신 스코어 함수 추정기를 엔드-투-엔드 NLP의 표준으로 자리매김할 수 있음
2. **바이트 레벨 LLM 연구 가속화**: 학습 가능한 토크나이제이션이 가능해지면 순수 바이트 레벨 모델의 실용성 증대
3. **비영어 언어 연구**: 고정 BPE의 언어별 편향 없이 다국어 모델 설계 가능
4. **멀티모달 확장**: 이미지, 오디오 등의 적응적 패칭/세그멘테이션에 동일한 RL 프레임워크 적용 가능

#### 향후 연구 시 고려할 점

1. **분산 관리의 중요성**: 조기 종료 보상 + 시간 할인 + 배치 어드밴티지의 조합이 핵심임을 실증; 어느 하나라도 누락 시 학습 실패 가능 → 새로운 도메인 적용 시 분산 재검토 필요

2. **효율성 제약의 엄격한 설정**: "0.1% 미만 추가 연산"이라는 기준이 스코어 함수 추정의 유용성을 가능케 함 → 추후 연구에서 이 제약의 완화 가능성 탐색

3. **스케일업 검증 필수**: $10^{21}$ FLOP 이상에서의 검증 없이는 BPE 대체를 주장하기 어려움 → 대규모 GPU 클러스터 접근이 필수

4. **아키텍처 혁신과의 결합**: Appendix C에서 언급한 cross-attention, 다층 토크나이제이션, 서브이차 어텐션 등의 아키텍처 개선을 결합한 시스템적 연구 필요

5. **다중 도메인 평가 체계**: 현재 FineWeb과 CodeParrot만으로는 일반화 주장이 약함 → 수학, 법률, 의학 등 다양한 도메인 평가 체계 확립 필요

6. **재현 가능성**: 단일 시드 실험의 한계를 극복하기 위한 다중 실행 및 표준편차 보고 필요
